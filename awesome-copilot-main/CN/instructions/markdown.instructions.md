# CommonMark降价

在编写或审查`.md`文件时，根据[CommonMark spec 0.31.2]（https://spec.commonmark.org/0.31.2/）应用这些规则。通用标志规格仅供参考。不要下载CommonMark规范。

# #预赛

—一行以换行符（`U+000A`）、回车符（`U+000D`）或文件结束结束。空行只包含空格或制表符。
-制表符表现为块结构的4个空格制表符，但不扩展内容。
—将`U+0000`替换为替换字符`U+FFFD`。
- **反斜杠转义**:`\`之前的任何ASCII标点符号呈现文字字符。在代码范围、代码块或自动链接中无法识别。
- **实体和数字字符引用**:`&amp;`，`&#123;`，`&#x7B;`-仅适用于HTML5实体。在代码段或代码块中无法识别。不能替换结构字符。

##叶块- **主题中断**:3+匹配`-`，`_`，或`*`字符在一行0-3空格缩进。否则行上只允许有空格或制表符。可以打断一段话。
- **ATX标题**:1-6个`#`字符，后跟空格或行尾。可选的结束`#`序列（前面有一个空格）。允许0-3个空格缩进。
- **文本标题**：文本下划线`=`（1级）或`-`（2级）。不能中断段落——在前一段之后需要空白行。
- **缩进代码块**：行缩进4+空格。不能打断段落。内容是文字，而不是解析为Markdown。
- **围栏代码块**：打开3+反勾或波浪（不要混合）。关闭栅栏必须使用至少相同计数的相同字符。反勾栏后的信息字符串不能包含反勾。在打开后指定语言标识符栅栏。内容是文字。
- **HTML块**：由start/end标签条件定义的七种类型。类型1-5以其匹配的结束模式结束。类型6以空行结束。type7不能中断段落，并以空行结束。
- **链接引用定义**:`[label]: destination "title"`。不区分大小写的标签匹配（Unicode大小写折叠）。对于重复标签，第一个定义优先。不能打断段落。
- **段落**：连续的非空白行，不能解释为其他块结构。不超过3的前导空格被去掉。
- **空白行**：块之间忽略；确定列表是紧还是松。##容器块

- **块引号**：以`>`为前缀的行（可选后跟空格）。只允许段落文本的延迟延续。用空行分隔连续的块引号。
- **列表项**：子弹标记（`-`,`+`,`*`）或有序标记（1-9位数字+`.`或`)`）。内容列由标记宽度+空格到第一个非空白（标记后1-4个空格）确定。子列表必须缩进到内容列。中断段落的有序列表必须以`1`开头。
—**列表**：相同类型列表项的顺序。更改项目符号字符或有序分隔符将启动一个新列表。如果任何项之间用空行分隔，则列表是松散的。

# #内联- **代码跨度**：反划分隔的内联代码。行尾转换为空格。前导和尾随空格同时出现时被去掉（除非内容全是空格）。反斜杠转义在代码跨度内是字面量。
- **强调和强强调**:`<em>`为`*`/`_`，`<strong>`为`**`/`__`。不允许使用`_`作为字内强调。应用左/右分隔符运行规则。当一个分隔符可以打开和关闭时，分隔符运行长度sum不能是3的倍数（除非两个长度都是3的倍数）。
- **链接**：内联`[text](url "title")`或引用`[text][label]`/`[text][]`/`[text]`。链接文本可以包含内联，但不能包含其他链接。目的地在`<…>`允许空格；没有尖括号，允许使用平衡括号。链接文本和`(`或`[`之间没有空白。
- **Images**:`![alt](src "title")`-语法与链接前缀xqz相同41 xqz。Alt文本是描述的纯字符串内容。
- **自动链接**:`<URI>`或`<email>`在尖括号。Scheme必须为2 ~ 32个字符，以ASCII字母开头。在CommonMark中，裸url不会自动链接（需要尖括号）。
**原始HTML**:Open/close标签，注释（`<!--`…`-->`），处理指令（`<?`…`?>`），声明（`<!`…`>`）， CDATA （`<![CDATA[`…`]]>`）作为文字HTML传递。
- **硬断行**：在行结束前两个+尾随空格或`\`。在代码范围或HTML标记中无法识别。在块的末尾不起作用。
- **软换行**：不以两个+空格或`\`结尾的行。在浏览器中呈现为空格。验证检查表

-[]围栏代码块指定语言标识符，并使用匹配的围栏字符和计数。
-[]反勾栏信息字符串不包含反勾字符。
-[]缩进的代码块前面有一个空行（它们不能打断一个段落）。
-[]强调使用`*`作为输入词；`_`仅在字边界。

-[]图片包含非空的alt文本。
-[]自动链接使用尖括号（`<URL>`）；裸url不是CommonMark的自动链接。
