# Markdown内容规则

以下标记内容规则在验证器中强制执行：1. **标题**：使用适当的标题级别（H2， H3等）来构建您的内容。不要使用H1标题，因为它将根据标题生成。
2. **列表**：使用项目符号或编号列表。确保适当的缩进和间距。
3. **代码块**：对代码片段使用隔离的代码块。指定语法高亮显示的语言。
4. **链接**：对链接使用适当的标记语法。确保链接有效且可访问。
5. **图像**：使用适当的标记语法的图像。包括所有文本的可访问性。
6. **表**：对表格数据使用降价表。确保正确的格式和对齐。
7. **行长度**：将行长度限制为400个字符，以提高可读性。
8. **空格**：使用适当的空格分隔各节，提高可读性。
9. **首页内容**：包括YAML首页内容在文件的开头与requi红色元数据字段。格式和结构

遵循以下准则来格式化和组织你的降价内容：- **标题**：使用`##`为H2和`###`为H3。确保标题以层次化的方式使用。如果内容包含H4，建议重组，更强烈建议包含H5。
**列表**:`-`用于项目符号，`1.`用于编号列表。用两个空格缩进嵌套列表。
- **代码块**：使用三个反引号（' '`) to create fenced code blocks. Specify the language after the opening backticks for syntax highlighting (e.g., `csharp '）。
—**链接**：链接使用`[link text](URL)`。确保链接文本是描述性的，并且URL是有效的。
—**Images**：使用`![alt text](image URL)`。在所有文本中包含对图像的简要描述。
—**Tables**：使用`|`创建表。确保列正确对齐并包含标题。
- **行长度**：在80字符换行，以提高可读性。对于长段落，使用软换行。
—**空格**：使用空白行分隔各节，提高可读性。避免过多的空白。验证检查表
