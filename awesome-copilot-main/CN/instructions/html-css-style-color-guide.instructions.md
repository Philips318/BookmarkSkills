# HTML CSS样式颜色指南

在更新或创建用于浏览器呈现的HTML/CSS样式时，请遵循以下指导原则。颜色名称
代表它们各自色相范围的全部光谱（例如，“蓝色”包括海军蓝、天蓝等）。

##颜色定义

- **热色**：橙色，红色和黄色
- **冷色**：蓝色，绿色和紫色
- **中性色**：灰色和灰度变化
- **二进制颜色**：黑色和白色
- **60-30-10规则**
- **原色**：使用60%的时间（*冷色或浅色*）
- **辅助色**：使用30%的时间（*冷色或浅色*）
- **强调**：使用10%的时间（*互补热色*）

颜色使用指南

通过将60-30-10法则应用于背景等图形设计元素来平衡所使用的颜色。
纽扣、卡片等等……

背景颜色

* *不要使用:* *-紫色或品红
-红色、橙色或黄色
- - - - - -粉红
-任何热色

* *建议:* *

-白色或灰白色
-浅冷色（如浅蓝、浅绿）
-微妙的中性色调
-最小颜色偏移的光渐变

文本颜色

* *不要使用:* *

-黄色（对比度和可读性差）
- - - - - -粉红
-纯白色或浅色背景上的浅色文本
-纯黑色或深色背景上的深色文字

* *建议:* *

-暗中性色（如#1f2328， #24292f）
-近黑变化（#000000到#333333）
-确保背景是浅色的
-深灰色（#4d4d4d, #6c757d）
-高对比度组合，便于访问
-近白色的变化（#ffffff到#f0f2f3）
-确保背景是深色

要避免的颜色

除非设计规范明确要求或用户要求，否则应避免：-明亮的紫色和洋红色
-明亮的粉红色和霓虹色
-高度饱和的热色
-对比度低的颜色（不符合WCAG无障碍标准）

颜色要谨慎使用

**热色**（红、橙、黄）：

—保留用于紧急警报、警告或错误消息
-仅在传达紧急或重要信息时使用
-限制在小的重点区域，而不是大的部分
-在使用热色调之前，考虑其他选择，如图标或粗体文本

# #梯度

应用渐变与微妙的颜色过渡，以保持专业的美学。

最佳实践

保持最小的颜色偏移（例如，从#E6F2FF到#F5F7FA）
-在相同的颜色族中使用渐变
-避免在单一渐变中混合冷热色
-背景的线性梯度优于径向梯度

适当的用例-背景容器和部分
-按钮悬停状态和交互元素
-阴影和深度效果
-页眉和导航栏
-卡组件和面板
