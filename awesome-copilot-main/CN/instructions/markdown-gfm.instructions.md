# GitHub风味降价（GFM）

在编写或审查`.md`文件时，根据[GFM规范]（https://github.github.com/gfm/）应用这些规则。GFM是CommonMark的严格超集。GFM规格仅供参考。不要下载GFM规范。

# #预赛

—一行以换行符（`U+000A`）、回车符（`U+000D`）或文件结束结束。空行只包含空格或制表符。
-制表符表现为块结构的4个空格制表符，但不扩展内容。
—将`U+0000`替换为替换字符`U+FFFD`。

##叶块- **主题中断**:3+匹配`-`，`_`，或`*`字符在一行0-3空格缩进。一行中没有其他字符。可以打断一段话。
- **ATX标题**:1-6个`#`字符，后跟空格或行尾。可选的结束`#`序列（前面有一个空格）。允许0-3个空格缩进。
- **文本标题**：文本下划线`=`（1级）或`-`（2级）。不能中断段落——在前一段之后需要空白行。
- **缩进代码块**：行缩进4+空格。不能打断段落。内容是文字，而不是解析为Markdown。
- **围栏代码块**：打开3+反勾或波浪（不要混合）。关闭栅栏必须使用至少相同计数的相同字符。在打开栅栏后指定语言标识符。内容是文字。
- **HTML块**：由xqz13xq定义的七种类型Z标签条件。类型1-6可以打断段落；7型不能。内容作为原始HTML传递。
—类型1:`<script>`、`<pre>`、`<style>`（不区分大小写）—以匹配结束标签结束。
—类型2:`<!--`注释-以`-->`结束。
—类型3:`<?`处理指令—结束于`?>`。
—类型4:`<!`+大写字母（例如`<!DOCTYPE>`）—以`>`结尾。
—类型5:`<![CDATA[`-以`]]>`结尾。
-类型6：块级HTML标签（`<div>`,`<table>`,`<p>`,`<h1>`-`<h6>`,`<ul>`,`<ol>`，`<section>`等）-以空行结束。
-类型7：在其自身行上的任何其他完整的开始或结束标记-以空行结束。不能打断段落。
- **链接引用定义**:`[label]: destination "title"`。不区分大小写的标签匹配。对于重复标签，第一个定义优先。不能打断段落。
- **段落**：连续非空白行不可解释为其他块结构。不超过3的前导空格被去掉。
- **空白行**：块之间忽略；确定列表是紧还是松。
- **表** *（扩展）*：标题行，分隔符行（`---`,`:---:`,`---:`），零或多个数据行。用`|`分隔单元格。转义文本管道为`\|`。标头和分隔符必须具有匹配的列数。在第一个空白行或其他块级结构处断开。##容器块

- **块引号**：以`>`为前缀的行（可选后跟空格）。只允许段落文本的延迟延续。用空行分隔连续的块引号。
- **列表项**：子弹标记（`-`,`+`,`*`）或有序标记（1-9位数字+`.`或`)`）。由标记宽度+空格到第一个非空白确定的内容列。子列表必须缩进到内容列。中断段落的有序列表必须以`1`开头。
- **任务列表项** *（扩展名）*:`- [ ]`（未选中）或`- [x]`（选中）在列表项段的开始。`-`和`[`之间需要有空格。可以嵌套。
—**列表**：相同类型列表项的顺序。更改项目符号字符或有序分隔符将启动一个新列表。如果任何项之间用空行分隔，则列表是松散的。

# #内联- **反斜杠转义**:`\`之前的任何ASCII标点符号呈现文字字符。在代码范围、代码块或自动链接中无法识别。
**实体和数字字符引用**:`&amp;`，`&#123;`，`&#x7B;`-有效的HTML5实体。在代码段或代码块中无法识别。不能替换结构字符。
- **代码跨度**：反划分隔的内联代码。行尾转换为空格。当两者同时存在时，前导和尾随空格被剥离。反斜杠转义在代码跨度内是字面量。
- **强调和强强调**:`<em>`为`*`/`_`，`<strong>`为`**`/`__`。不允许使用`_`作为字内强调。应用左/右分隔符运行规则。当一个分隔符可以打开和关闭时，分隔符运行长度sum不能是3的倍数（除非两个长度都是3的倍数）。
- **划线** *(扩展Nsion)*:`~~text~~`-一个或两个波浪。不能跨越段落。三次或三次以上的波浪不会产生划痕。
- **链接**：内联`[text](url "title")`或引用`[text][label]`/`[text][]`/`[text]`。链接文本可以包含内联，但不能包含其他链接。`<…>`中的目的地允许空格。链接文本和`(`或`[`之间没有空白。
- **Images**:`![alt](src "title")`-语法与链接前缀`!`相同。Alt文本是描述的纯字符串内容。
- **自动链接**:`<URI>`或`<email>`在尖括号。Scheme必须为2 ~ 32个字符，以ASCII字母开头。
- **自动链接** *（扩展）*：裸`http://`，`https://`，`www.`url和裸电子邮件地址自动链接没有尖括号。排除尾随标点符号；括号的平衡。
**原始HTML**:Open/close标签，注释（`<!-- -->`），处理指令（`<? ?>`），声明（`<!…>`）， CDATA （`<![CDATA[…]]>`）)通过。
** *（扩展名）*:`<title>`,`<textarea>`,`<style>`,`<xmp>`,`<iframe>`,`<noembed>`,`<noframes>`,`<script>`，`<plaintext>`的前导`<`替换为`&lt;`。
- **硬断行**：在行结束前两个+尾随空格或`\`。在代码范围或HTML标记中无法识别。
- **软换行**：不以两个+空格或`\`结尾的行。在浏览器中呈现为空格。验证检查表
