#贡献者契约行为准则

##我们的承诺

为了营造一个开放和友好的环境，我们将
贡献者和维护者承诺参与我们的项目和
我们的社区为每个人提供无骚扰的体验，无论年龄、身体
体型、残疾、种族、性别认同和表达、经验水平、
国籍、个人外貌、种族、宗教或性别认同
取向。

我们的标准

有助于创造积极环境的行为例子
包括:

*使用欢迎和包容的语言
尊重不同的观点和经验
优雅地接受建设性的批评
*关注对社区最有利的东西
*对其他社区成员表示同情

参与者不可接受的行为包括：*使用色情化的语言或意象以及不受欢迎的性关注或
进步
*喷子，insulting/derogatory评论，以及个人或政治攻击
*公开或私下骚扰
*发布他人的私人信息，如实物或电子信息
地址，未经明确许可
*其他可被合理认为不适当的行为
专业设置

##我们的责任

项目维护者有责任澄清可接受的标准
行为和期望采取适当和公平的纠正措施
对任何不可接受的行为做出反应。项目维护者有权利和责任删除、编辑或修改文件
拒绝评论、提交、代码、维基编辑、问题和其他贡献
不符合本行为准则的行为，或暂时禁止的行为
任何他们认为不合适的行为的贡献者，
威胁的、冒犯的或有害的

# #范围

本行为准则适用于项目空间和公共空间
当个人代表项目或其社区时。的例子
代表一个项目或社区包括使用官方项目电子邮件
地址，通过官方社交媒体账户发布，或作为指定
在线或离线活动的代表。一个项目的代表可以是
由项目维护者进一步定义和澄清。

# #执法虐待，骚扰，或其他不可接受的行为的实例可能是
通过<opensource@github.com>联系项目组上报。所有
投诉将被审查和调查，并将导致一个回应
被认为是必要和适当的。项目团队是
有义务对事件的报告人保密。
具体执行政策的进一步细节可另行公布。

没有遵循或执行良好行为准则的项目维护者
信仰可能面临由他人决定的暂时或永久的影响
项目领导的成员。
