#前端Web开发插件

现代前端web开发的基本提示、说明和聊天模式，包括React、Angular、Vue、TypeScript和CSS框架。

# #安装```bash
# Using Copilot CLI
copilot plugin install frontend-web-dev@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/frontend-web-dev:playwright-explore-website`|网站探索测试使用剧作家MCP |
|`/frontend-web-dev:playwright-generate-test`|基于剧作家MCP |的场景生成剧作家测试
