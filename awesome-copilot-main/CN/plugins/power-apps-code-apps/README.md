# Power Apps Code Apps Development Plugin

Power Apps Code Apps开发的完整工具包，包括项目脚手架，开发标准和专家指导，用于构建具有Power Platform集成的代码优先应用程序。

# #安装```bash
# Using Copilot CLI
copilot plugin install power-apps-code-apps@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/power-apps-code-apps:power-apps-code-app-scaffold`|搭建一个完整的Power Apps Code App项目，包括PAC CLI设置、SDK集成和连接器配置|

# # #代理

|代理|描述||-------|-------------|
|`power-platform-expert`|电源平台专家，提供有关代码应用程序，画布应用程序，Dataverse，连接器和电源平台最佳实践的指导|

# #源

这个插件是[Awesome Copilot]（https://github.com/github/awesome-copilot）的一部分，这是一个社区驱动的GitHub Copilot扩展集合。
