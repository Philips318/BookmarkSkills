# OpenAPI to Application - Go Plugin

根据OpenAPI规范生成生产就绪的Go应用程序。包括项目搭建、处理程序生成、中间件设置和REST api的Go最佳实践。

# #安装```bash
# Using Copilot CLI
copilot plugin install openapi-to-application-go@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/openapi-to-application-go:openapi-to-application-code`|从OpenAPI规范生成一个完整的、生产就绪的应用程序|

# # #代理

|代理|描述||-------|-------------|
|`openapi-to-application`|根据OpenAPI规范生成工作应用程序的专家助手|

# #源

这个插件是[Awesome Copilot]（https://github.com/github/awesome-copilot）的一部分，这是一个社区驱动的GitHub Copilot扩展集合。
