# CAST成像代理插件

使用CAST Imaging进行软件分析、影响评估、结构质量咨询和架构审查的专门代理的综合集合。

# #安装```bash
# Using Copilot CLI
copilot plugin install cast-imaging@awesome-copilot
```
包含的内容

# # #代理

|代理|描述||-------|-------------|
|`cast-imaging-software-discovery`|专门代理，通过使用CAST Imaging的静态代码分析进行全面的软件应用程序发现和体系结构映射
使用CAST Imaging在软件系统中进行全面变更影响评估和风险分析的专门代理
|`cast-imaging-structural-quality-advisor`|专用代理，用于使用CAST Imaging |识别、分析和提供代码质量问题的修复指导

# #源

这个插件是[Awesome Copilot]（https://github.com/github/awesome-copilot）的一部分，这是一个社区驱动的GitHub Copilot扩展集合。
