# Copilot SDK插件

使用GitHub CopilotSDK跨多种编程语言构建应用程序。包括c#， Go，Node.js/TypeScript和Python的全面说明，以帮助您创建ai驱动的应用程序。

# #安装```bash
# Using Copilot CLI
copilot plugin install copilot-sdk@awesome-copilot
```
包含的内容

# # #技能

|技能|描述||-------|-------------|
使用GitHub CopilotSDK构建代理应用程序。在应用程序中嵌入AI代理，创建自定义工具，实现流响应，管理会话，连接到MCP服务器或创建自定义代理时使用。触发器上的Copilot SDK， GitHub SDK，代理应用程序，嵌入Copilot，可编程代理，MCP服务器，自定义代理。|

# #源

这个插件是[Awesome Copilot]（https://github.com/github/awesome-copilot）的一部分，这是一个社区驱动的GitHub Copilot扩展集合。
