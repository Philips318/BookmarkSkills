# Doublecheck

ai生成输出的三层验证管道。提取可验证的声明，通过网络搜索找到来源，对幻觉模式进行对抗性审查，并生成带有来源链接的结构化报告，以便人们在采取行动之前进行验证。

##为什么存在

人工智能幻觉是一个模型层面的问题。没有插件可以修复它们。但幻觉的“后果”——根据捏造的引证行事、依赖捏造的统计数据、引用不存在的判例法——可以通过快速而有条理的验证来减轻。

反复检查并不能告诉你什么是真的。它从人工智能输出中提取每一个可证实的说法，搜索你可以独立检查的来源，并标记任何符合已知幻觉模式的东西。你做最后的决定。

包含的内容

|组件名称|类型|描述||-----------|------|-------------|
|`doublecheck`|技能|核心验证管道。运行三层并生成结构化报告。|
|`Doublecheck`| Agent |交互验证模式，用于后续问题和更深入的调查。|

##三层

**层1：自我审计。**批判性地重读目标文本。提取每一个可验证的主张（事实，统计，引用，日期，因果断言）。检查内部矛盾。为下游验证分类索赔。

**第2层：源验证。**对于每个提取的主张，运行网络搜索以找到支持或反对的证据。生成可点击的url，供独立的人工审阅。对引文进行了额外的审查，这是幻觉的最高风险类别。**第三层：对抗性审查。**完全切换姿势——假设输出包含错误并主动尝试找到它们。根据幻觉模式检查表进行检查：捏造的引用，无来源的统计数据，对不确定主题的自信特异性，时间混乱，过度概括和缺少限定词。

##信心评级

每项索赔都有一个最终评级：

|评级|含义||--------|---------|
|已验证|找到支持源并链接|
与一般知识一致，没有发现特定来源的|
|未经证实|找不到支持或反对的证据|
有争议的从可靠来源找到的相互矛盾的证据
伪造风险|符合幻觉模式（例如，在任何地方都找不到的引文）|

# #使用

持久模式（“Always On”）

激活双重检查模式，它会在你接下来的对话中保持打开状态。Copilot的每一个实质性回复都将在底部包含一个内联验证摘要——可信度评级和每个事实主张的来源链接。

要激活，只需说：```
use doublecheck
```
曾经活跃:
-简单的事实查找和单一索赔答案获得自动内联验证摘要
-事实分析、法律分析、法规解释、合规性指导，以及有案例引用或法定参考的内容，自动获得完整的验证报告，而不是内联摘要
-如果在内联验证期间有任何索赔费率争议或捏造风险，则自动生成完整的报告
-跳过代码，创意写作和随意交谈（验证不适用）
-您可以通过说“完整报告”（或遗留短语“运行完整验证”）来要求对任何响应进行全面的深入验证。
-随时关闭它与“关闭双重检查”

随时关掉它：```
turn off doublecheck
```
这是需要准确性的工作会议的推荐模式——法律研究、合规分析、监管指导、执行简报。

一次性验证

如果你不想要持久模式，你可以根据需要验证特定的文本：```
use doublecheck to verify: [paste the text you want checked]
```
这将运行完整的三层管道，并生成详细的验证报告，其中包含每个索赔的提取、评级和来源。

交互代理模式

对于一个来回的对话：```
@doublecheck [paste text or describe what you want verified]
```
代理模式允许您：
-获取完整的验证报告
-询问关于特定标记索赔的后续问题
-要求更深入的调查（“深入挖掘C3”）
-寻求帮助评估消息来源是否可信

###何时使用

-在根据人工智能生成的法律分析、案例引用或监管指导采取行动之前
-在文档中包含ai生成的统计数据或数据点之前
-当审查将与客户，领导或外部各方共享的AI输出时
-在错误会产生实际后果的领域（法律、医疗、金融、安全）工作时
-当你觉得“我应该再检查一下”的时候

###不要使用它-对于“准确性”不是目标的创造性或主观内容
-用于代码审查（使用特定于代码的审查工具代替）
-作为主题专业知识的替代品——该工具可以帮助您更快地进行验证，但它不能取代对领域的了解

# #的局限性

要知道这个工具不能做什么：- **相同的模型，相同的偏差。验证管道使用可能产生原始输出的相同类型的模型。它抓住了许多问题——尤其是缺少引用这样的结构模式——但它也有同样的基本知识限制。
- **网页搜索不全面。**付费内容，最近出版的材料和利基数据库可能不会出现在搜索结果中。“未经证实”的声明可能意味着它在付费墙后面，而不是错误的。
- **VERIFIED是指“找到了来源”，而不是“绝对正确”。**来源本身可能是错误的、过时的或被误解的。支持链接加速您的验证过程；它并没有完成它。
- **工具无法捕捉到它不知道它不知道的东西。**如果幻觉足够复杂，可以通过所有三层，人类专家是你的最后一道防线。诚实框架：该工具提高了验证质量的基础，并显著减少了识别需要人类关注的声明所需的时间。它不会提高上限。关键决策应该总是涉及人类领域的专业知识。
