#电源平台MCP连接器开发插件

完整的工具包，用于开发与模型上下文协议集成的电源平台自定义连接器，用于Microsoft Copilot Studio

# #安装```bash
# Using Copilot CLI
copilot plugin install power-platform-mcp-connector-development@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
为Copilot Studio生成完整的电源平台自定义连接器，并集成MCP -包括模式生成、故障排除和验证|
生成一个完整的MCP服务器实现，为Copilot Studio集成优化，具有适当的模式约束和可流的HTTP支持|
