#自动化

你知道你每周都要做的事情——15次点击，4个应用程序，复制粘贴到电子表格和电子邮件中——这一过程让你想把笔记本电脑扔进大海吗？记录自己做一次，把视频交给Copilot CLI，让它为你写脚本。

##如何工作

1. **记录你的屏幕。**使用QuickTime， OBS，织机，或任何你已经有。按照你平常的方式来做这个过程。如果你想在记录的同时讨论它（“现在我正在下载这份报告，因为财务部门每周一都需要它”），那就更好了——这个插件会记录你的叙述，并用它来理解你为什么要做每一步，而不仅仅是你点击了什么。

2. **将录音放在桌面**（或任何地方-它只需要一个文件路径）。

3. **告诉副驾驶命令行分析：**   ```
   copilot
   > /skills
   > (select automate-this)
   > Analyze ~/Desktop/weekly-report-process.mov and automate it
   ```
4. **检查它发现了什么。**插件每隔几秒钟从您的视频中提取帧，转录任何叙述，并将您的过程重建为编号的步骤列表。在提出任何建议之前，它会要求你确认它是正确的。

5. **选择您的自动化级别。**你最多会收到三个建议，从“这里有一个处理最糟糕部分的一行程序”到“这里有一个包含调度和错误处理的完整脚本”。每个工具都使用您已经安装的工具——毫无疑问是依赖链。

##引擎盖下发生了什么

该插件使用`ffmpeg`从您的录音中拉帧和音频。如果你叙述，它会使用OpenAI的Whisper（在你的机器上本地运行，而不是在云端）来转录你所说的话。这些框架进入人工智能模型，它可以读取屏幕上的文本，识别应用程序，查看你点击的内容，并遵循你的流程。在建议自动化之前，插件会检查您的环境—安装了什么，使用什么shell，可用的脚本语言—因此它只会建议您无需花费一个小时设置即可实际运行的内容。

# #先决条件

- ffmpeg**（必需）-用于从您的录音中提取帧和音频  ```bash
  brew install ffmpeg
  ```
- **低语**（可选）-只有当你的录音有叙述时才需要  ```bash
  pip install openai-whisper
  ```
或者c++版本：`brew install whisper-cpp`如果没有安装Whisper，而你的录音是有音频的，这个插件会告诉你，并提供只进行视觉分析。

copilot plugin install automate-this@awesome-copilot
```
什么被分析得很好

当你的录音清楚地显示你在做什么时，插件的效果最好。下面是一些自动化过程的例子：

- **报告生成** -从仪表板下载数据，过滤，格式化，发送给某人
- **文件组织** -排序下载到文件夹，按日期重命名文件，清理重复
- **数据输入** -从一个应用程序复制信息并将其输入另一个应用程序
- **开发环境设置** -每次启动新项目时运行的命令和配置更改的顺序
- **重复的终端工作流** -使用不同的输入运行相同的命令序列
- **基于电子邮件的工作流程** -从电子邮件中提取数据，处理它，回复结果

##什么保持手动该插件提出自动化的机械步骤。它保留了人类的判断——如果你的录音显示你暂停查看某些东西或根据你所看到的做出决定，那么这一步在自动化系统中仍然是手动的，并提示你输入。

# #的例子

假设你记录下自己每周完成的任务：打开浏览器，导航到内部仪表板，下载三个CSV导出文件，在Excel中打开每个导出文件，过滤标记为“待处理”的行，将它们合并成一个表格，然后通过电子邮件发送给你的经理。

插件将重建该过程，与您确认，并提出如下建议：- **第1层：**一个`curl`命令，下载所有三个csv在一个镜头（如果仪表板有直接下载的url），跳过浏览器完全。
- **第2层：**一个Python脚本，下载csv，使用pandas过滤“pending”行，合并它们，并保存结果-准备附加到电子邮件中。
- **层3:**相同的脚本，加上它发送电子邮件自动通过您的邮件客户端，并运行在每周一上午8点通过`launchd`。

每一层都包括工作代码、通过演练测试代码的说明，以及如何在出错时撤消任何操作。

# #隐私帧提取（ffmpeg）和音频转录（Whisper）完全在您的机器上运行。提取的帧和音频被写入一个安全的临时目录，并在分析完成后删除。提取的帧和文本被发送到驱动您的Copilot CLI会话的AI模型进行分析-这是所有Copilot交互使用的相同模型和数据管道。除了Copilot已经使用的服务之外，它不会向其他第三方服务发送数据。
