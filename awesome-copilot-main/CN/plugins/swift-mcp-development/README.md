# Swift MCP服务器开发插件

使用具有现代并发功能的官方MCP Swift SDK在Swift中构建模型上下文协议服务器的综合集合。

# #安装```bash
# Using Copilot CLI
copilot plugin install swift-mcp-development@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/swift-mcp-development:swift-mcp-server-generator`|使用官方MCP Swift SDK包生成完整的Swift模型上下文协议服务器项目。|

# # #代理

|代理|描述||-------|-------------|
|`swift-mcp-expert`|使用现代并发特性和官方MCP Swift SDK在Swift中构建模型上下文协议服务器的专家协助。|

# #源

这个插件是[Awesome Copilot]（https://github.com/github/awesome-copilot）的一部分，这是一个社区驱动的GitHub Copilot扩展集合。
