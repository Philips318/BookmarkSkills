#结构化自治插件

优质规划，节约执行

# #安装```bash
# Using Copilot CLI
copilot plugin install structured-autonomy@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/structured-autonomy:structured-autonomy-plan`|结构化自治计划|
|`/structured-autonomy:structured-autonomy-generate`|结构化自治生成|
|`/structured-autonomy:structured-autonomy-implement`|结构化自治实现|
