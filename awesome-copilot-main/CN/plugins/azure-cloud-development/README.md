# Azure和云开发插件

全面的Azure云开发工具，包括基础设施即代码、无服务器功能、架构模式和用于构建可扩展云应用程序的成本优化。

# #安装```bash
# Using Copilot CLI
copilot plugin install azure-cloud-development@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/azure-cloud-development:azure-resource-health-diagnose`|分析Azure资源运行状况，从日志和遥测中诊断问题，并为已识别的问题创建修复计划。|
分析应用程序中使用的Azure资源（目标rg中的IaC文件and/or资源）并优化成本-为已识别的优化创建GitHub问题。|

# # #代理

|代理|描述||-------|-------------|
|`azure-principal-architect`|使用Azure良好架构框架原则和微软最佳实践提供专业的Azure首席架构师指导。|
|`azure-saas-architect`|提供专业的Azure SaaS架构师指导，重点介绍使用Azure良好架构SaaS原则和Microsoft最佳实践的多租户应用程序。|
Azure逻辑应用程序开发的专家指导，重点是工作流设计，集成模式和基于json的工作流定义语言。|
使用Azure验证模块（AVM）在Bicep中创建、更新或检查Azure IaC。|
使用Azure验证模块（AVM）在Terraform中创建、更新或查看Azure IaC。|
|`terraform-azure-planning`|作为Azure地形基础设施即代码任务的实施计划者。|
