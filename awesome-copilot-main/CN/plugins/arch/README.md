# Arch插件

用于本地克隆存储库的体系结构和现代化工具包。它从磁盘上的代码生成单个引用的体系结构文档，并生成一个分阶段的现代化计划，当还没有体系结构文档存在时，该计划会自动首先运行Documentation模式。

# #安装```bash
copilot plugin install arch@awesome-copilot
```
包含的内容

# # #技能- **`doc-and-modernize`** -两个互补的工作流程为本地克隆存储库，在一个技能（通过这个插件安装它表面为`arch:doc-and-modernize`）：
-文档模式-为您已经在本地签出的存储库生成一个全面的、可验证的架构文档。本地优先（更喜欢本地签出，将remote/API查找作为标记的最后手段），引用每个声明到文件+行，标记未经验证的事实，解决矛盾，并深入研究最复杂的子系统。理想的入职文档和系统设计地图。
- **现代化模式** -为遗留代码库生成分阶段的现代化计划。如果存在当前的体系结构文档，它将在此基础上进行构建；否则，它首先运行文档模式工作流来生成一个文档，然后继续执行计划。生成每个特性的迁移文档、带有adr的技术堆栈建议和适配包安全阶梯分阶段实施方案。# #源
