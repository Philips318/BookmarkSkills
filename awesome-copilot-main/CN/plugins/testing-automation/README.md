#测试和测试自动化插件

用于编写测试、测试自动化和测试驱动开发的全面集合，包括单元测试、集成测试和端到端测试策略。

# #安装```bash
# Using Copilot CLI
copilot plugin install testing-automation@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/testing-automation:playwright-explore-website`|网站探索测试使用剧作家MCP |
|`/testing-automation:playwright-generate-test`|基于剧作家MCP |的场景生成剧作家测试
|`/testing-automation:csharp-nunit`|获取NUnit单元测试的最佳实践，包括数据驱动测试|
获得JUnit 5单元测试的最佳实践，包括数据驱动测试|
|`/testing-automation:ai-prompt-engineering-safety-review`|全面人工智能提示工程安全审查和改进提示。分析安全性、偏差、安全漏洞和有效性的提示，同时提供详细的改进建议，包括广泛的框架、测试方法和教育内容。|

# # #代理

|代理|描述||-------|-------------|
|`tdd-red`|通过编写失败的测试来指导测试优先的开发，这些测试描述了在实现存在之前从GitHub问题上下文中期望的行为。|
实现最少的代码以满足GitHub问题要求，并使失败的测试通过而无需过度工程。|
提高代码质量，应用安全最佳实践，增强设计，同时保持绿色测试和GitHub问题合规性。|
|`playwright-tester`|剧作家测试模式|
