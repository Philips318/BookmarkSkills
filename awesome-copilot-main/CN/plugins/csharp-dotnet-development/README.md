# c#。. NET开发插件

c#的基本提示、说明和聊天模式。NET开发，包括测试、文档和最佳实践。

# #安装```bash
# Using Copilot CLI
copilot plugin install csharp-dotnet-development@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
获取c#异步编程的最佳实践|
|`/csharp-dotnet-development:aspnet-minimal-api-openapi`|创建ASP. NET最小API端点与适当的OpenAPI文档|
|`/csharp-dotnet-development:csharp-xunit`|获取XUnit单元测试的最佳实践，包括数据驱动测试|
|`/csharp-dotnet-development:csharp-nunit`|获取NUnit单元测试的最佳实践，包括数据驱动测试|
|`/csharp-dotnet-development:csharp-mstest`|获取MSTest3.x/4.x单元测试的最佳实践，包括现代断言api和数据驱动测试|
|`/csharp-dotnet-development:csharp-tunit`|获取unit单元测试最佳实践，包括数据驱动测试|
确保.NET/C#代码符合solution/project.|的最佳实践
|`/csharp-dotnet-development:dotnet-upgrade`|准备使用的提示全面。. NET框架升级分析与执行
