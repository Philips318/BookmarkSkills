#任务由microsoft/edge-ai插件

任务研究员和任务规划器，适用于中级到专家用户和大型代码库-由microsoft/edge-ai为您带来

# #安装```bash
# Using Copilot CLI
copilot plugin install edge-ai-tasks@awesome-copilot
```
包含的内容

# # #代理

|代理|描述||-------|-------------|
|`task-researcher`|综合项目分析任务研究专家-由microsoft/edge-ai|为您带来
创建可执行的执行计划的任务规划器-由microsoft/edge-ai|提供给您

# #源

这个插件是[Awesome Copilot]（https://github.com/github/awesome-copilot）的一部分，这是一个社区驱动的GitHub Copilot扩展集合。
