#开源赞助插件

开源项目办公室（OSPOs）的工具和资源，通过GitHub赞助商，开放集体和其他资助平台识别，评估和管理开源依赖的赞助。

# #安装```bash
# Using Copilot CLI
copilot plugin install ospo-sponsorship@awesome-copilot
```
包含的内容

# # #技能

|技能|描述||-------|-------------|
|`SKILL.md`|查找哪些GitHub存储库的依赖关系是通过GitHub赞助商赞助的。使用deep .dev API解决npm、PyPI、Cargo、Go、RubyGems、Maven和NuGet之间的依赖关系。检查npm资金元数据、FUNDING.yml文件和web搜索。验证每个链接。显示与OSSF记分卡运行状况数据的直接和可传递的依赖关系。通过提供GitHubowner/repo来调用(例如：“在expressjs/express中查找可赞助的依赖项”)。|

# #源

这个插件是[Awesome Copilot]（https://github.com/github/awesome-copilot）的一部分，这是一个社区驱动的GitHub Copilot扩展集合。
