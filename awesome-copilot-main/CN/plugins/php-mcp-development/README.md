# PHP MCP服务器开发插件

使用带有基于属性的发现功能的官方PHP SDK构建模型上下文协议服务器的综合资源，包括最佳实践、项目生成和专家协助

# #安装```bash
# Using Copilot CLI
copilot plugin install php-mcp-development@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/php-mcp-development:php-mcp-server-generator`|使用官方PHP SDK |生成完整的PHP模型上下文协议服务器项目，包括工具、资源、提示和测试

# # #代理

|代理|描述||-------|-------------|
|`php-mcp-expert`| PHP MCP服务器开发的专家助手，使用带有基于属性的发现|的官方PHP SDK

# #源

这个插件是[Awesome Copilot]（https://github.com/github/awesome-copilot）的一部分，这是一个社区驱动的GitHub Copilot扩展集合。
