# Rust MCP服务器开发插件

使用带有async/await、过程宏和类型安全实现的官方rmcp SDK，在Rust中构建高性能模型上下文协议服务器。

# #安装```bash
# Using Copilot CLI
copilot plugin install rust-mcp-development@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/rust-mcp-development:rust-mcp-server-generator`|使用官方rmcp SDK |生成一个完整的Rust模型上下文协议服务器项目，包括工具、提示、资源和测试

# # #代理

|代理|描述||-------|-------------|
Rust MCP服务器开发的专家助手，使用rmcp SDK与tokio异步运行时|
