#技术尖峰插件

用于创建、管理和研究技术峰值的工具，以便在开始规范和实现解决方案之前减少未知和假设。

# #安装```bash
# Using Copilot CLI
copilot plugin install technical-spike@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/technical-spike:create-technical-spike`|创建有时间限制的技术峰值文档，用于在实现之前研究和解决关键的开发决策。|

# # #代理

|代理|描述||-------|-------------|
通过详尽的调查和控制实验，系统地研究和验证技术峰值文件。|

# #源

这个插件是[Awesome Copilot]（https://github.com/github/awesome-copilot）的一部分，这是一个社区驱动的GitHub Copilot扩展集合。
