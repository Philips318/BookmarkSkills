# OpenAPI到应用程序- c#净插件

生成生产就绪。. NET应用程序从OpenAPI规范。包括ASP。. NET Core项目搭建，控制器生成，实体框架集成，以及c#最佳实践。

# #安装```bash
# Using Copilot CLI
copilot plugin install openapi-to-application-csharp-dotnet@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/openapi-to-application-csharp-dotnet:openapi-to-application-code`|从OpenAPI规范生成一个完整的、生产就绪的应用程序|

# # #代理

|代理|描述||-------|-------------|
|`openapi-to-application`|根据OpenAPI规范生成工作应用程序的专家助手|
