# CMS开发插件

用于跨主题、插件、管理工具、媒体工作流、降价呈现和静态导出管道的内容管理系统开发的工具包。

# #安装```bash
# Using Copilot CLI
copilot plugin install cms-development@awesome-copilot
```
包含的内容

# # #技能

|技能|描述||-------|-------------|
跨WordPress、Shopify、Drupal、Webflow和AEM等平台的cms特定工作流。涵盖主题、插件、管理面板、内容模型、媒体管道和静态导出。|
|`markdown-to-html`| Markdown渲染、转换和HTML输出工作流。|
解释网页设计描述，并从速记、准代码和自然语言描述实现代码。|
|`web-coder`| CMS任务通常依赖的前端、浏览器和HTTP工作。|

##何时使用

当工作集中在以下任何一个时安装这个插件：-在任何CMS平台上开发或定制主题和模板
-构建或修改插件，应用程序，模块或扩展
-负责管理或编辑器界面、内容表单或发布流程
-处理媒体上传、资产管道或授权文件存储
-实现或调试降价渲染和内容转换
—构建静态导出、部署或服务器呈现的输出管道
—对内容类型、分类法、段信息、元数据或迁移模式进行建模
