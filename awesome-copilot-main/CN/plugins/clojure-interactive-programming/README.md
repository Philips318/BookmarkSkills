# Clojure交互式编程插件

用于REPL-first Clojure工作流的工具，具有Clojure指令，交互式编程聊天模式和支持指南。

# #安装```bash
# Using Copilot CLI
copilot plugin install clojure-interactive-programming@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/clojure-interactive-programming:remember-interactive-programming`|提醒代理它是一个交互式程序员的微提示符。当Copilot可以访问REPL（可能通过Backseat Driver）时，在Clojure中工作得很好。将与具有代理可以使用的实时REPL的任何系统一起工作。在您的工作流and/or工作区中用任何特定的提醒来调整提示。|

# # #代理

|代理|描述||-------|-------------|
专家级Clojure结对程序员，具有repl优先的方法、架构监督和交互式问题解决。执行质量标准，防止变通，并通过文件修改前的实时REPL评估逐步开发解决方案。|
