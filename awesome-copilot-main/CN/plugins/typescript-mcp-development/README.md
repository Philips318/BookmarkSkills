# TypeScript MCP服务器开发插件

使用官方SDK在TypeScript/Node.js中构建模型上下文协议（MCP）服务器的完整工具包。包括最佳实践的说明、生成服务器的提示以及用于指导的专家聊天模式。

# #安装```bash
# Using Copilot CLI
copilot plugin install typescript-mcp-development@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/typescript-mcp-development:typescript-mcp-server-generator`|用TypeScript生成一个完整的MCP服务器项目，包括工具、资源和适当的配置|

# # #代理

|代理|描述||-------|-------------|
|`typescript-mcp-expert`|在TypeScript中开发模型上下文协议（MCP）服务器的专家助手
