#软件工程团队插件

7个专业代理，涵盖从UX设计和架构到安全性和DevOps的整个软件开发生命周期。

# #安装```bash
# Using Copilot CLI
copilot plugin install software-engineering-team@awesome-copilot
```
包含的内容

# # #代理

|代理|描述||-------|-------------|
|`se-ux-ui-designer`|任务完成分析，用户旅程映射，以及Figma和设计工作流的用户体验研究工件|
|`se-technical-writer`|技术写作专家，用于创建开发人员文档、技术博客、教程和教育内容|
|`se-gitops-ci-specialist`| DevOps专家，负责CI/CD管道、部署调试和GitOps工作流，专注于使部署变得枯燥而可靠|
|`se-product-manager-advisor`|产品管理指南，用于创建GitHub问题，使业务价值与用户需求保持一致，并做出数据驱动的产品决策|
负责任的人工智能专家，确保人工智能通过偏见预防、可访问性合规、道德发展和包容性设计为每个人服务
系统架构审查专家，为AI和分布式系统提供良好的架构框架、设计验证和可伸缩性分析
|`se-security-reviewer`|安全专注于OWASP Top 10、Zero Trust、LLM安全性和企业安全标准|的代码审查专家# #源

这个插件是[Awesome Copilot]（https://github.com/github/awesome-copilot）的一部分，这是一个社区驱动的GitHub Copilot扩展集合。
