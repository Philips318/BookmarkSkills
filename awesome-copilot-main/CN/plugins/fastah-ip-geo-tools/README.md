# IP地理定位工具（Fastah Inc）

此插件适用于希望以RFC 8805格式调整和发布IP地理位置提要的网络操作工程师。它由AI Skill和相关的MCP服务器组成，该服务器将地理位置地名编码为真实城市，以提高准确性。

# #安装```sh
# Using Copilot CLI
copilot plugin install fastah-ip-geo-tools@awesome-copilot
```
包含的内容

# # #技能

|技能|描述||-------|-------------|
|`geofeed-tuner`|按照RFC 8805验证、调整和改进CSV格式的IP地理位置提要，并提供来自实际部署的固执己见的最佳实践。使用Fastah MCP调优数据查找。|

# #先决条件

- **运行生成的验证和调优脚本需要Python 3**。
