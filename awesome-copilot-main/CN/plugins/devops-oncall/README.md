# DevOps随叫随到插件

一组有重点的提示、说明和聊天模式，有助于对事件进行分类，并使用DevOps工具和Azure资源快速响应。

# #安装```bash
# Using Copilot CLI
copilot plugin install devops-oncall@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/devops-oncall:azure-resource-health-diagnose`|分析Azure资源运行状况，从日志和遥测中诊断问题，并为已识别的问题创建修复计划。|
|`/devops-oncall:multi-stage-dockerfile`|为任何语言或框架创建优化的多阶段Dockerfiles |

# # #代理

|代理|描述||-------|-------------|
|`azure-principal-architect`|使用Azure良好架构框架原则和微软最佳实践提供专业的Azure首席架构师指导。|
