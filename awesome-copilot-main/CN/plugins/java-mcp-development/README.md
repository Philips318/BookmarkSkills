# Java MCP服务器开发插件

使用带有响应式流和Spring Boot集成的官方MCP Java SDK在Java中构建模型上下文协议服务器的完整工具包。

# #安装```bash
# Using Copilot CLI
copilot plugin install java-mcp-development@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/java-mcp-development:java-mcp-server-generator`|使用带有响应式流和可选Spring Boot集成的官方MCP Java SDK在Java中生成完整的模型上下文协议服务器项目。|

# # #代理

|代理|描述||-------|-------------|
|`java-mcp-expert`|使用响应式流、官方MCP Java SDK和Spring Boot集成在Java中构建模型上下文协议服务器的专家协助。|

# #源

这个插件是[Awesome Copilot]（https://github.com/github/awesome-copilot）的一部分，这是一个社区驱动的GitHub Copilot扩展集合。
