基于mcp的M365代理插件

为microsoft365 Copilot构建具有模型上下文协议集成的声明性代理的综合集合

# #安装```bash
# Using Copilot CLI
copilot plugin install mcp-m365-copilot@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/mcp-m365-copilot:mcp-create-declarative-agent`| McP-create-declarative-agent |
|`/mcp-m365-copilot:mcp-create-adaptive-cards`| mcp-create- adaptivecards |
|`/mcp-m365-copilot:mcp-deploy-manage-agents`| mcp-deploy- management -agents |

# # #代理

|代理|描述||-------|-------------|
|`mcp-m365-agent-expert`|专家助手，用于为Microsoft 365 Copilot构建基于mcp的声明性代理，并集成模型上下文协议|

# #源

这个插件是[Awesome Copilot]（https://github.com/github/awesome-copilot）的一部分，这是一个社区驱动的GitHub Copilot扩展集合。
