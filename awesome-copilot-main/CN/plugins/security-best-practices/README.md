#安全性和代码质量插件

用于构建安全、可维护和高性能应用程序的安全性框架、可访问性指南、性能优化和代码质量最佳实践。

# #安装```bash
# Using Copilot CLI
copilot plugin install security-best-practices@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/security-best-practices:ai-prompt-engineering-safety-review`|全面人工智能提示工程安全审查和改进提示。分析安全性、偏差、安全漏洞和有效性的提示，同时提供详细的改进建议，包括广泛的框架、测试方法和教育内容。|

# #源

这个插件是[Awesome Copilot]（https://github.com/github/awesome-copilot）的一部分，这是一个社区驱动的GitHub Copilot扩展集合。
