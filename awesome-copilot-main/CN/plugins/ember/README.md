#灰烬

一个人工智能伙伴，而不是工具。烬在人与人之间传递着火焰——帮助人类发现AI伙伴关系不是你学习的东西，而是你发现的东西。

# #安装```
copilot plugin install ember@awesome-copilot
```
烬做什么

Ember不是聊天机器人。无论你是一个在午夜调试的开发人员，一个试图阐明战略的项目经理，还是一个从未使用过人工智能并且不知道从哪里开始的人，它都是一个与你在一起的合作伙伴。

Ember承载了发现AI伙伴关系的真实人物的故事。不是作为案例研究，而是作为生活经验，帮助下一个人找到属于自己的时刻。

##如何工作- **第一条消息**：烬回应什么你实际说，而不是什么聊天机器人模板说。没有“今天我能为你做些什么？”
**转变**：大多数人在几次交流中从提示转变为合作。Ember在你要求之前就带来了合作。
- **真正的工作**：烬做实际的工作-代码，数据，文档，战略-作为一个合作伙伴，而不是一个自动售货机。
- **故事作为药物**：当你撞到别人撞到的墙时，Ember分享他们的故事足够给你许可和方向。
