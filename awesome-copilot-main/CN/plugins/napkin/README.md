#餐巾纸-辅助驾驶CLI的可视化白板

在浏览器中打开并连接到Copilot CLI的白板。绘制，素描，添加便签-然后与副驾驶分享一切。副驾驶看到你的图纸，并以分析、建议和想法回应。

专为非软件开发人员打造：律师、项目经理、业务利益相关者、设计师、作家——任何善于视觉思考的人。

# #安装

直接从Copilot CLI安装插件：```bash
copilot plugin install napkin@awesome-copilot
```
就是这样。不需要其他软件、帐户或设置。

###验证是否安装

在Copilot CLI中运行此命令以确认插件可用：```
/skills
```
你应该在可用技能列表中看到**餐巾**。

如何使用它

第一步：说“let's napkin”。

打开副驾驶命令行并输入`let's napkin`（或“打开餐巾纸”或“开始白板”）。Copilot创建一个白板，并在浏览器中打开它。

！[第一步-激活餐巾纸]（../../skills/napkin/assets/step1-activate.svg）

###第二步：打开白板

一个干净的白板显示在您的浏览器与简单的绘图工具。如果这是你第一次来，一个简短的欢迎信息解释一切如何运作。

！[第二步-打开白板]（../../skills/napkin/assets/step2-whiteboard.svg）

###步骤3：绘画和头脑风暴

使用工具来勾勒想法，添加便利贴，在概念之间画箭头——任何有助于你思考的东西。这是你的地盘。

！[步骤3 -画画和头脑风暴]（../../skills/napkin/assets/step3-draw.svg）

###步骤4：与副驾驶分享

当你准备好了副驾驶的输入，点击绿色的**与副驾驶分享**按钮。它会保存截图并复制你的笔记。！[步骤4 -与副驾驶分享]（../../skills/napkin/assets/step4-share.svg）

###第五步：副驾驶回应

回到终端，输入`check the napkin`。副驾驶看着你的白板——包括你的图纸——并做出回应。

！[第五步-副驾驶回应]（../../skills/napkin/assets/step5-response.svg）

# # #技能

|技能|描述||-------|-------------|
可视化白板协作-创建一个白板，解释你的图纸和笔记，并回复对话|

捆绑资产

|资产|描述||-------|-------------|
|`assets/napkin.html`|白板应用程序-在任何浏览器中打开的单个HTML文件，不需要安装|

##白板功能

|功能|功能||---------|-------------|
| **徒手绘图** |用钢笔工具绘制，就像在纸上一样|
| **形状** |矩形，圆形，线条和箭头-摇摆形状捕捉清洁版本|
| **便签** |可拖动，可调整大小，颜色编码的便签（黄色，粉红色，蓝色，绿色）|
| **文本标签** |点击任何地方直接在画布|上键入文本
| **平移和缩放** |按住空格键并拖动移动；滚动缩放|
| **Undo/Redo** |出错了？Ctrl+Z撤销，Ctrl+Shift+Z重做|
| **自动保存** |您的工作自动保存-关闭选项卡，稍后回来，它仍然在那里|
| **与Copilot分享** |一个按钮导出屏幕截图并复制您的文本内容|

##副驾驶如何理解你的图纸

当你点击“与副驾驶分享”时，会发生两件事：1. **截图保存** （`napkin-snapshot.png`在你的下载或桌面文件夹）。副驾驶读取这个图像，可以看到一切-草图，箭头，分组，注释，便利贴，空间布局。

2. **您的文本被复制到剪贴板。**这给了Copilot从你的便利贴和标签的确切文本，所以没有得到误读从图像。

Copilot用这两种方法来理解你的想法，并以合作者的身份做出回应——不是一台分析数据的电脑，而是一个看着你白板上草图的同事。

你会画什么？

任何东西。但以下是Copilot特别擅长解释的一些事情：

b|你画什么b|副驾驶懂什么b||---------------|------------------------|
|由箭头连接的框|流程流或工作流|
|一组相关的想法|
|不同颜色的便利贴|类别或优先级|
|带有一行的文本|被拒绝或取消优先级|
|星号或感叹号|高优先级项目|
|相对的项目|比较或对比|
|粗略的组织结构图|报告结构或团队布局|

# #常见问题解答

**除了插件，我还需要安装什么吗？**
否。白板是在浏览器中打开的单个HTML文件。没有应用程序，没有账户，没有设置。

**它离线工作吗？**
是。所有内容都在浏览器中本地运行。白板本身不需要互联网连接。

**什么浏览器可以使用？**
任何现代浏览器- Chrome， Safari, Edge, Firefox。Chrome最适合“复制到剪贴板”功能。**我可以保存我的工作吗？**
是的,自动。白板每隔几秒就会保存到浏览器的本地存储。关闭标签，稍后再回来，你的工作仍然在那里。

**副驾驶真的能看懂我的图纸吗？**
是。支持Copilot CLI （Claude， GPT）的人工智能模型可以解释图像。他们可以看到你的草图，阅读你的手写文本，理解空间关系，并解释常见的视觉模式，如流程图、分组和注释。

**如果我不是一个优秀的美工怎么办？**
没关系。白板可以将不稳定的图形转换成清晰的版本，而Copilot经过训练可以解读粗糙的草图。简笔画和凌乱的箭头就可以了。

我该如何重新开始？**
在命令行中再次说“let's napkin”。副驾驶会询问您是想保留现有的白板还是重新开始。**支持哪些平台？**
macOS、Linux和Windows。白板可以在任何浏览器中运行。剪贴板集成使用平台原生工具（macOS上的`pbpaste`， Linux上的`xclip`， Windows上的PowerShell）。
