# Salesforce开发插件

完整的Salesforce代理开发环境，涵盖Apex和触发器、流量自动化、闪电Web组件（LWC）、Aura组件和Visualforce页面。

# #安装```bash
copilot plugin install salesforce-development@awesome-copilot
```
包含的内容

# # #代理

|代理|描述||-------|-------------|
使用Apex类和触发器实现Salesforce业务逻辑，并使用符合Salesforce最佳实践的生产质量代码。|
按照闪电框架的最佳实践，使用闪电Web组件和Aura组件实现Salesforce UI组件。|
遵循声明式自动化最佳实践，使用Salesforce Flow实现业务自动化。|
按照Salesforce MVC架构和最佳实践实现Visualforce页面和控制器。|

# #使用

安装后，根据您正在构建的内容切换到GitHub CopilotChat中的任何Salesforce代理：-使用**`salesforce-apex-triggers`**用于后端业务逻辑，触发器处理程序，实用程序类和测试覆盖率
-使用**`salesforce-aura-lwc`**用于构建闪电Web组件或Aura组件UI
-使用**`salesforce-flow`**用于声明式自动化，包括记录触发，屏幕，自动启动和计划流程
-使用**`salesforce-visualforce`**用于Visualforce页面及其Apex控制器
