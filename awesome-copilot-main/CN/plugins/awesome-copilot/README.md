#了不起的副驾驶插件

元提示，帮助您发现和生成精心策划的GitHub Copilot代理、集合、说明、提示和技能。

# #安装```bash
# Using Copilot CLI
copilot plugin install awesome-copilot@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/awesome-copilot:suggest-awesome-github-copilot-collections`|根据当前存储库上下文和聊天历史，从awesome-copilot存储库中建议相关的GitHub Copilot集合，提供自动下载和安装集合资产，并识别需要更新的过时集合资产。|
|`/awesome-copilot:suggest-awesome-github-copilot-instructions`|根据当前存储库上下文和聊天历史，从awesome-copilot存储库中建议相关的GitHub Copilot指令文件，避免与该存储库中的现有指令重复，并识别需要更新的过时指令。|
|`/awesome-copilot:suggest-awesome-github-copilot-agents`|根据当前存储库上下文和聊天历史，建议来自awesome-copilot存储库的相关GitHub Copilot自定义代理文件，避免与此存储库中的现有自定义代理重复，并识别需要更新的过时代理。|
|`/awesome-copilot:suggest-awesome-github-copilot-skills`|建议相关的GitHub Copilot技能，来自awesome-copilot基于c的存储库当前存储库上下文和聊天历史记录，避免与此存储库中的现有技能重复，并识别需要更新的过时技能。|# # #代理

|代理|描述||-------|-------------|
|`meta-agentic-project-scaffold`|元代理项目创建助手，帮助用户有效创建和管理项目工作流。|
