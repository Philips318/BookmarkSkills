# TypeSpec为微软365副驾驶插件

使用TypeSpec为Microsoft 365 Copilot的可扩展性构建声明性代理和API插件的全面提示、说明和资源。

# #安装```bash
# Using Copilot CLI
copilot plugin install typespec-m365-copilot@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
为microsoft365 Copilot |生成一个完整的TypeSpec声明式代理，带有指令、功能和会话启动器
|`/typespec-m365-copilot:typespec-create-api-plugin`|为Microsoft 365 Copilot |生成一个带有REST操作、认证和自适应卡的TypeSpec API插件
|`/typespec-m365-copilot:typespec-api-operations`|给TypeSpec API插件添加GET、POST、PATCH和DELETE操作，并使用适当的路由、参数和自适应卡|

# #源
