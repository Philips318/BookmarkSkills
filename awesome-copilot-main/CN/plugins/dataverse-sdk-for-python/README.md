# Dataverse SDK for Python Plugin

用于与Microsoft Dataverse构建生产就绪的Python集成的综合集合。包括官方文档、最佳实践、高级特性、文件操作和代码生成提示。

# #安装```bash
# Using Copilot CLI
copilot plugin install dataverse-sdk-for-python@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/dataverse-sdk-for-python:dataverse-python-quickstart`|使用官方模式生成Python SDK设置+ CRUD + bulk +分页片段。|
|`/dataverse-sdk-for-python:dataverse-python-advanced-patterns`|使用高级模式、错误处理和优化技术为Dataverse SDK生成产品代码。|
|`/dataverse-sdk-for-python:dataverse-python-production-code`|使用带有错误处理、优化和最佳实践的Dataverse SDK生成生产就绪的Python代码|
|`/dataverse-sdk-for-python:dataverse-python-usecase-builder`|根据架构建议为特定的Dataverse SDK用例生成完整的解决方案|
