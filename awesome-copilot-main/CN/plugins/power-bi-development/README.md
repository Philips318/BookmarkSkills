# Power BI开发插件

全面的Power BI开发资源，包括数据建模、DAX优化、性能调优、可视化设计、安全最佳实践，以及构建企业级Power BI解决方案的DevOps/ALM指导。

# #安装```bash
# Using Copilot CLI
copilot plugin install power-bi-development@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/power-bi-development:power-bi-dax-optimization`| Power BI DAX公式综合优化提示，提高DAX计算的性能、可读性和可维护性。|
|`/power-bi-development:power-bi-model-design-review`|全面的Power BI数据模型设计审查提示，用于评估模型架构、关系和优化机会。|
|`/power-bi-development:power-bi-performance-troubleshooting`|系统的Power BI性能故障诊断提示，用于识别、诊断和解决Power BI模型、报表和查询中的性能问题。|
Power BI报表可视化设计提示符，用于创建具有最佳图表选择和布局设计的有效、用户友好和可访问的报表。|

# # #代理

|代理|描述||-------|-------------|
Expert Power BI数据建模指南，使用星型模式原则、关系设计和Microsoft最佳实践来实现最佳模型性能和可用性。|
|`power-bi-dax-expert`| Expert Power BI DAX指南，使用Microsoft关于DAX公式和计算的性能、可读性和可维护性的最佳实践。|
|`power-bi-performance-expert`|专家Power BI性能优化指导，用于排除故障、监控和提高Power BI模型、报表和查询的性能。|
Expert Power BI报告设计和可视化指南，使用Microsoft最佳实践创建高效、高性能和用户友好的报告和仪表板。|
