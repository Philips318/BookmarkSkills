# Ruby MCP服务器开发插件

使用官方的MCP Ruby SDK gem与Rails集成支持在Ruby中构建模型上下文协议服务器的完整工具包。

# #安装```bash
# Using Copilot CLI
copilot plugin install ruby-mcp-development@awesome-copilot
```
包含的内容

###命令（斜杠命令）

|命令|描述||---------|-------------|
|`/ruby-mcp-development:ruby-mcp-server-generator`|使用官方的MCP Ruby SDK gem在Ruby中生成完整的模型上下文协议服务器项目。|

# # #代理

|代理|描述||-------|-------------|
使用官方MCP Ruby SDK gem与Rails集成，在Ruby中构建模型上下文协议服务器的专家帮助。|
