#综述

学习你如何沟通的状态简报生成器。

Roundup通过GitHub、电子邮件、Teams、Slack和其他工具查看您的工作，然后以您自己的声音为您定义的任何受众起草状态更新和简报。

##问题

经理和团队领导每周花费数小时从分散的来源收集状态更新：在GitHub上扫描公关活动，阅读电子邮件线程以获取决策，查看Teams或Slack的背景，然后在不同的细节级别上为不同的受众重写所有这些信息。

写这些更新的数据已经存在。工作是收集和包装它。Roundup自动收集和起草。你提供质量控制和点击发送。

##如何工作**第一次（5分钟）：**运行设置技能。它询问你的角色，你的受众，以及你的团队在哪里工作。然后粘贴一两个已经编写好的更新示例。从这些例子中，它了解你的格式、语气、结构，以及你要包括什么和跳过什么。

**每次之后：**告诉roundup你是为哪类读者写的。它从配置好的数据源中提取新数据，对它们进行综合，并起草一份符合您风格的简报。

# #安装```bash
copilot plugin install roundup@awesome-copilot
```
##开始

###首次设置```
use roundup-setup
```
设置流程将引导您完成：
-描述你的角色和团队
-粘贴你已经写好的更新
-定义你的受众（领导、团队、合作伙伴等），以及每个人关心什么
-确定团队的工作和对话发生在哪里

生成简报```
use roundup
```
或者更具体地说：```
use roundup -- generate a leadership briefing covering this past week
```

```
use roundup -- draft a team update since Monday
```
包含的内容

技能|它的作用||-------|-------------|
|`roundup-setup`|交互式登录，了解您的风格、受众和数据源|
|`roundup`|根据需要从你的配置中生成草稿简报|

##它可以从中汲取什么

Roundup适应您环境中可用的任何工具：

|来源|它寻找什么||--------|-------------------|
| GitHub | pr，问题，提交，审查活动在您配置的repos |
| M365 / WorkIQ |电子邮件线程，团队消息，日历事件，共享文档|
| Slack |频道消息、线程、公告|
|谷歌工作区| Gmail，日历，驱动器活动|

在设置过程中，roundup会发现您可以访问哪些文件，并相应地配置自身。如果稍后添加了新工具，请重新运行安装程序以包含它们。

除了在您的Copilot CLI环境中已经配置的内容之外，不需要API密钥或其他设置。

是什么让它与众不同

它从你的例子中学习。** roundup不是强迫您使用模板，而是分析您实际如何编写并复制该样式。你的简报听起来像是你写的。**无论你有什么，它都可以工作。**只有GitHub ？很好。完整的M365套件？好了。Slack和b谷歌的组合？作品。设置流发现您的环境并进行调整。

**多个受众，一个设置。**用不同的细节级别和格式定义不同的受众配置文件。相同的底层数据，每个数据的输出不同。

**你的配置是一个可读的文件。**所有的总结学习生活在`~/.config/roundup/config.md`-简单的标记，您可以随时打开，阅读和手工编辑。没有不透明设置或隐藏状态。

# #重新配置

从头开始设置：```
use roundup-setup
```
它会在覆盖您现有的配置之前询问。

要进行小的调整，只需在任何文本编辑器中打开`~/.config/roundup/config.md`。该文件用简单的英语编写，并按节组织。您的更改将在下次运行时得到尊重。
