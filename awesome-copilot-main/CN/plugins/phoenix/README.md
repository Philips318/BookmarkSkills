#凤凰插件

用于LLM应用程序调试、评估和跟踪的Phoenix AI可观察性技能。包括CLI调试工具、LLM评估工作流和OpenInference跟踪工具。

# #安装```bash
# Using Copilot CLI
copilot plugin install phoenix@awesome-copilot
```
包含的内容

# # #技能

|技能|描述||-------|-------------|
|`phoenix-cli`|使用Phoenix命令行调试LLM应用程序。获取跟踪、分析错误、检查实验、检查数据集和查询GraphQL API。|
使用Phoenix为AI/LLM应用程序构建和运行评估器。|
OpenInference语义约定和工具用于Phoenix AI的可观察性。|
