# 555

[www.fairchildsemi.com] (www.fairchildsemi.com)LM555/NE555/SA555是一种高度稳定的控制器，能够产生精确的定时脉冲。单稳态工作时，延时由一个外接电阻和一个电容控制。工作稳定，频率和占空比由两个外部电阻和一个电容器精确控制。

# #特性

-高电流驱动能力（200mA）
-占空比可调
-温度稳定性为0.005%/℃
—计时单位：μSec ~ Hours
—关闭时间小于2μSec

# #应用程序

-精确定时
-脉冲产生
-延时产生
-时序时序

* *时间公式:* *

-高时间：$t_H = 0.693 \times (R_A + R_B) \times C_1$
-低时间：$t_L = 0.693 \times R_B \times C_1$
-周期：$T = t_H + t_L = 0.693 \times (R_A + 2R_B) \times C_1$
-频率:$ f = \压裂{1.44}{(R_A + 2 r_b) \ * c₁}$
—占空比：$D = \frac{R_A + R_B}{R_A + 2R_B}$

**典型值：** RA = 1kΩ， RB = 1kΩ， C1 = 1μF, Vcc = 5V通过在图1中添加电阻RB并按图5所示进行配置，可以实现稳定的计时器操作。在稳定运行中，将触发端与阈值端连接，形成自触发，作为多振子运行。当定时器输出高时，其内部放电tr关断，VC1随时间常数(RA+RB)*C呈指数函数增加。当VC1或阈值电压达到2Vcc/3时，触发端子上的比较器输出变高，复位F/F并导致定时器输出变低。进而闭合放电Tr， C1通过RB与放电Tr形成的放电通道放电。当VC1低于Vcc/3时，触发端比较器输出变为高电平，定时器输出再次变为高电平。放电开关关闭VC1再次上升。在上述过程中，定时器输出高的部分是VC1从Vcc/3上升到2Vcc/3所花费的时间，定时器输出低的部分是VC1从2Vcc/3下降到Vcc/3.所花费的时间。当定时器输出高时，充电电容C1的等效电路如下：####式1：充电电路等效```mermaid
flowchart LR
    VCC["Vcc"] --> RA_RB["RA + RB"]
    RA_RB --> C1["C1<br/>Vc1(0-)=Vcc/3"]
    C1 --> GND["GND"]
```
**充电方程式：**
$$C_1 \frac{dV_{C1}}{dt} = \frac{V_{CC} - V_{(0-)}}{R_A + R_B} \quad (1)$$

$$V_{C1}(0^+) = \frac{V_{CC}}{3} \quad (2)$$

$$V_{C1}(t) = V_{CC} \left[ 1 - \frac{2}{3} e^{-\frac{t}{(R_A + R_B)C_1}} \right] \quad (3)$$

由于定时器输出高状态（tH）的持续时间是VC1(t)达到2Vcc/3所需的时间量，

＃＃＃＃公式2：高时间计算

$$\frac{2}{3}V_{CC} = V_{CC} \left[ 1 - \frac{2}{3} e^{-\frac{t_H}{(R_A + R_B)C_1}} \right] \quad (4)$$

$$t_H = C_1(R_A + R_B) \ln 2 = 0.693(R_A + R_B)C_1 \quad (5)$$

定时器输出低时放电电容C1的等效电路如下：

＃＃＃＃式3：放电电路等效```mermaid
flowchart LR
    C1["C1<br/>Vc1(0-)=2Vcc/3"] --> RB["RB"]
    RB --> RD["RD<br/>(discharge Tr.)"]
    RD --> GND["GND"]
```
**放电方程：**
$$C_1 \frac{dV_{C1}}{dt} + \frac{1}{R_A + R_B} V_{C1} = 0 \quad (6)$$

$$V_{C1}(t) = \frac{2}{3} V_{CC} e^{-\frac{t}{(R_A + R_B)C_1}} \quad (7)$$

由于定时器输出低状态（tL）的持续时间是VC1(t)达到Vcc/3所需的时间量，

＃＃＃＃公式4：低时间计算

$$\frac{1}{3}V_{CC} = \frac{2}{3}V_{CC} e^{-\frac{t_L}{(R_B + R_D)C_1}} \quad (8)$$

$$t_L = C_1(R_B + R_D) \ln 2 = 0.693(R_A + R_B)C_1 \quad (9)$$

由于RD通常为RB>>RD，虽然与放电Tr的大小有关，但tL=0.693RBC1 （10）
因此，如果定时器工作在稳定状态，则周期与“T=tH+tL=0.693(RA+RB)C1+0.693 rbc1 =0.693(RA+2RB)C1”相同，因为周期是充电时间和放电时间之和。既然频率是周期的倒数，下面就适用了。

＃＃＃＃式5：频率公式$$f = \frac{1}{T} = \frac{1.44}{(R_A + 2R_B)C_1} \quad (11)$$

在图13中，电流源由PNP晶体管Q1和电阻R1、R2和RE产生。

＃＃＃＃式6：电流源计算

$$I_C = \frac{V_{CC} - V_E}{R_E} \quad (12)$$

这里，VE是：

$$V_E = V_{BE} + \frac{R_2}{R_1 + R_2} V_{CC} \quad (13)$$

例如，Vcc=15V， RE=20kΩ， R1=5kW, R2=10kΩ， VBE=0.7V，则VE=0.7V+10V=10.7V Ic=(15-10.7)/20k=0.215mA

当触发器在如图13所示的定时器中启动时，流过电容C1的电流变成由PNP晶体管和电阻产生的恒流。因此，VC是一个线性斜坡函数，如图14所示。线性斜坡函数的梯度S定义如下：

＃＃＃＃公式7：斜坡坡度

$$S = \frac{V_{P-P}}{T} \quad (14)$$这里Vp-p是峰间电压。用电容中积累的电荷量除以电容，得到VC：```
V = Q/C (15)
```
上面的方程两边除以T得到

＃＃＃＃公式8：简化斜坡斜率

$$\frac{V}{T} = \frac{Q/T}{C} \quad (16)$$

可以化简为下式。```
S = I/C (17)
```
换句话说，线性斜坡函数的梯度可以通过使用流过电容器的恒定电流来获得。若通过电容器的恒电流为0.15 ma，电容为0.02μF，则电容器两端斜坡函数的梯度为S =0.215m/0.022μ=9.77V/ms.#机械尺寸
