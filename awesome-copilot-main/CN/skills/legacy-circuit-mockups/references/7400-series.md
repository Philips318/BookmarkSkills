# 7400系列逻辑ic规格

# # 1。概述

**7400系列**是**数字逻辑集成电路**的一大家族**最初实现在**TTL（晶体管-晶体管逻辑）**，后来扩展到包括** cmos兼容的变体**。这些器件提供基本的构建模块，如门、触发器、计数器、多路复用器、解码器和总线收发器。

7400系列集成电路广泛应用于**回溯计算**、**6502/Z80系统**、**粘合逻辑**和教育设计**。

# # 9。连接笔记

* TTL输出可靠地驱动TTL输入
* CMOS输入不能浮动
*使用**74HCT**接口CMOS与TTL信号
*每个IC需要去耦电容器（0.1µF）
