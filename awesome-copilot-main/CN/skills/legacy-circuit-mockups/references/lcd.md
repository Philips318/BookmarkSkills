# DFRobot FIT0127液晶字符显示规范

# # 1。概述

**DFRobot FIT0127**是** hd44780兼容字符LCD模块**系列，常用于嵌入式系统和业余项目。这些显示器使用点阵字符生成器提供字母数字输出，并支持8位和4位并行接口。

FIT0127模块经常与微控制器和8位cpu配对，如**6502**、**AVR**、**PIC**和**Arduino**平台。

---

# # 2。一般特征

|特性|描述|| ----------------- | --------------------------------------------------- |
|显示类型|字符LCD （STN，典型黄绿背光）|
|控制器| HD44780或兼容|
|接口|并行（4位或8位）|
|字符大小| 5 × 8点阵|
|工作电压| 5v逻辑（部分型号支持3.3 V） |
|背光| LED（独立电源引脚）|
|查看方式|反射|

# # 6。接口信号

6.1 RS （Register Select）

| RS |功能|
| -- | -------------------- |
| 0 |指令寄存器|
| 1 |数据寄存器|

6.2R/W|R/W|操作|| --- | ------------- |
|0 00 |写入LCD |
| 1 |从LCD读取|

### 6.3启用(E)

数据被锁存在E的下降沿上
* E必须脉冲高低为每次传输

---

# # 7。数据总线操作

7.1 8位模式

*使用D0-D7
*操作速度更快

7.2 4位模式

*仅使用D4-D7
*数据分两口传输（高的先）
*保存I/O引脚

---

# # 8。内部内存映射

DDRAM（显示数据RAM）

|地址|显示位置|| --------: | ---------------- |
| 0x00-0x0F | Line 1, Col 1-16 |
| 0x40-0x4F | 2号线，Col 1-16 |

8.2 CGRAM（字符生成器RAM）

*支持多达**8个自定义字符**
*每个字符使用8字节
