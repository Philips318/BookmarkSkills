# MOS技术6502微处理器规格

# # 1。概述

MOS Technology 6502**是1975年推出的8位微处理器。它以其低成本，高效的指令集而闻名，并广泛应用于早期的个人电脑和游戏机，包括Apple II， Commodore 64, Atari 2600, NES （Ricoh 2A03变体）和BBC Micro。

---

# # 2。一般特征

|特性|描述|| ------------- | ------------------------ |
|数据宽度| 8位|
|地址宽度| 16位|
|地址空间| 64kb (0x0000 ~ 0xffff) |
| | A、X、Y、SP、PC、P注册|
|端序|小端序|
|时钟速度| ~1 - 3mhz（原NMOS） |
|技术| NMOS |

# # 3。Programmer-Visible寄存器

蓄电池(A)

* 8位寄存器
*用于算术、逻辑和数据传输操作

索引寄存器（X， Y）

* 8位寄存器
*用于索引内存、计数器和偏移量

栈指针（SP）

* 8位寄存器
*指向当前栈的位置
*栈位于`$0100–$01FF`页

程序计数器（PC）

* 16位寄存器
保存下一条指令的地址

处理器状态寄存器(P)|位|名称|描述|
|——：| ---- | ----------------------------- |
| 7 | N | - |
| 6 | V | |溢出
| 5 | - |未使用（总是在push中设置）|
| 4 | B |打破|
| 3 | D |十进制模式|
| 2 | I | Interrupt关闭|
| 1 | Z | 0 |
|0 00 | C |进位|

# # 4。内存映射约定

|地址范围|用途|| ------------- | -------------------- |
|`$0000–$00FF`|零页|
|`$0100–$01FF`|硬件堆叠|
|`$0200–$FFFF`|程序/数据/I/O|

中断向量

|向量|地址|描述|| ------- | ------------- | ---------------------- |
| NMI |`$FFFA–$FFFB`|不可屏蔽中断|
|复位|`$FFFC–$FFFD`|复位向量|
|IRQ/BRK|`$FFFE–$FFFF`|中断请求|

# # 5。寻址模式

|模式|格式|描述|| ---------------- | ------------- | ----------------------- |
|隐含|`CLC`|操作数隐含|
|累加器|`ASL A`|对累加器|进行操作
|即时|`LDA #$10`|固定值|
|零页|`LDA $20`|零页地址|
|零页，X |`LDA $20,X`|零页索引|
|零页，Y |`LDX $20,Y`|零页索引|
|绝对|`LDA $1234`|完整16位地址|
| Absolute，X |`LDA $1234,X`|索引绝对|
| Absolute，Y |`LDA $1234,Y`|索引绝对|
|间接|`JMP ($1234)`|指针跳转|
|索引间接|`LDA ($20,X)`| x索引指针|
|间接索引|`LDA ($20),Y`| y索引指针|
|相对|`BEQ label`|分支偏移|

# # 7。周期定时（一般）大多数指令在** 2-7个周期内执行**
*可能会增加额外的周期：

*页面边界
*取树枝

# # 8。十进制模式

当设置**D标志时：

*`ADC`和`SBC`使用**BCD运算**
*仅在NMOS 6502上有效（在CMOS衍生产品上行为不同）

---

# # 9。已知的硬件怪癖

*`JMP (addr)`间接错误：页面边界环绕

*示例：`JMP ($10FF)`读取`$10FF`和`$1000`*没有专用的乘法或除法指令
*堆栈被固定到`$01xx`页
