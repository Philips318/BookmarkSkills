# AS6C62256 （32K x 8 SRAM）仿真规范

模拟AS6C62256 / 62256系列静态RAM的技术规范，适用于6502系列模拟器，SBC模拟器和内存子系统建模。

---

# # 1。范围

本文档指定用于模拟的功能行为：

*联盟内存**AS6C62256**
*兼容**62256 (32K x 8) SRAM**设备

超出范围的：

*模拟电时序余量
*总线争用和信号rise/fall次
*功耗特性

---

# # 2。芯片概述

核心特征

|特性|值|| -------------- | -------------------- |
|内存类型|静态内存|
|容量| 32,768字节（32kb） |
|数据宽度| 8位|
|地址宽度| 15位（A0-A14） |
|接入类型|异步|
|电源电压| 5v（典型）|

---

# # 3。外部信号（逻辑模型）

|信号|方向|用途|| ------ | --------- | -------------------------- |
| A0-A14 |输入|地址总线|
| D0-D7 |I/O|数据总线|
| ce# |输入|芯片使能（低电平有效）|
| oe# |输入|输出使能（激活低）|
| WE# |输入|写使能（激活低）|

>`#`表示active-low信号。

---

# # 4。地址空间映射

*地址范围：`0x0000-0x7FFF`*地址行选择每个地址一个字节

6502系统映射示例

| CPU地址范围|设备|| ----------------- | -------------- |
|`$0000-$7FFF`| AS6C62256 SRAM |
|`$8000-$FFFF`| ROM / EEPROM |

---

# # 5。读写行为

读周期（逻辑）

条件:

*`CE# = 0`*`OE# = 0`*`WE# = 1`行为:```text
D[7:0]  memory[A]
```
如`OE# = 1`或`CE# = 1`，数据总线为**高阻抗**。

---

写周期（逻辑）

条件:

*`CE# = 0`*`WE# = 0`行为:```text
memory[A]  D[7:0]
```
*`OE#`在写入过程中被忽略
*写入发生在活动的WE#上

---

# # 6。控制信号优先级

| CE# | WE# | OE# | Result || --- | --- | --- | --------------- |
| 1 | X | X |关闭（Hi-Z） |
| 0 | 0 | X |写入|
| 0 | 1 | 0 |读取|
| 0 | 1 | 1 | Hi-Z |

---

# # 7。仿真器接口要求

模拟器必须公开：```text
read(address)  -> byte
write(address, byte)
```
内部存储:```text
uint8_t ram[32768]
```
解决屏蔽:```text
address = address & 0x7FFF
```
---

# # 8。时序模型（摘要）

仿真级别

|级别|描述|| -------------- | ------------------------- |
|功能|瞬时接入|
|周期|每个CPU周期的访问权限|
|循环精确|荣誉使转换|

对于大多数系统，功能仿真就足够了。

---

# # 9。电源和数据保留

*只要通电，SRAM内容就会持续存在
*模拟器将保留内容，直到显式重置

###重置行为

** *复位时无自动清零
*内存内容未定义，除非初始化

---

# # 10。总线争用和Hi-Z建模（可选）

可选高级行为：

跟踪SRAM何时驱动数据总线
检测非法的并发写

大多数仿真器可能会忽略Hi-Z状态。

---

# # 11。错误条件

|条件|仿真器响应|| -------------------- | ----------------------------- |
|超出范围的地址|掩码或忽略|
|禁用时读取|返回最后一个总线值或0xFF |
|禁用时写入|忽略写入|

---

# # 12。集成6502模拟器```text
CPU memory access
  address decode
  if in SRAM range:
      AS6C62256.read/write
```
SRAM访问通常是单周期的
*不需要等待状态
