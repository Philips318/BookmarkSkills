# 6522 VIA（通用接口适配器）仿真规范

模拟MOS技术/ WDC 6522 VIA**的技术标记规范，适用于6502系列模拟器，SBC模拟器和逆向计算软件环境。

---

# # 1。范围

本文档定义了需要模拟的功能行为：

* MOS技术6522 VIA
* WDC 65C22 VIA （CMOS变体，注明）

超出范围的：

*模拟电特性
总线争用和传播延迟
*未记录的硅竞态条件

---

# # 2。芯片概述

核心功能

|特性|描述|| ---------------- | ------------------------------------ |
|I/O接口| 2个8位双向接口（A， B） |
|定时器|两个可编程定时器|
|移位寄存器| 8位串行移位寄存器|
|中断系统|可屏蔽，优先级|
|握手|CA1/CA2，CB1/CB2控制线|

---

# # 3。外部信号（逻辑模型）

|信号|方向|用途|| -------- | --------- | ------------------------ |
| PA0-PA7 |I/O| A口|
| PB0-PB7 |I/O|接口B |
| CA1， CA2 |I/O|控制线A |
| CB1， CB2 |I/O|控制线B |
| IRQ |输出|向CPU |发出中断请求
| CS1， CS2 |输入|芯片选择|
|R/W|输入|读写|
| RS0-RS3 |输入|寄存器选择|

# # 5。数据方向寄存器

* Bit = 1 输出
* Bit = 0 输入```text
output = ORx & DDRx
input  = external & ~DDRx
```
---

# # 6。港口的行为

# # #读

*返回配置为输入的位的输入引脚
*返回配置为输出的位的输出锁存器

# # #写

*仅更新输出锁存器
*实际引脚值取决于DDR

---

# # 7。计时器

定时器1 （T1）

* 16位向下计数器
*可以产生中断
*可选PB7切换

###定时器2 （T2）

* 16位向下计数器
*单次或脉冲计数（CB1）

定时器仿真规则

*每个CPU周期递减一次
*在适当的时候重新装弹
设置下流中断标志

---

# # 8。移位寄存器（SR）

通过ACR控制的模式：

*禁用
*在CB1时钟下移位
*在系统时钟下移出

模拟器要求:

* 8位移位
*正确的位顺序
*可选外部时钟处理

---

# # 9。控制寄存器

辅助控制寄存器（ACR）

控制:

*定时器1模式
*定时器2模式
*移位寄存器模式
* PB7行为外围控制寄存器（PCR）

控制:

*CA1/CB1边缘灵敏度
*CA2/CB2握手/脉冲/输出模式

---

# # 10。中断系统

中断标志寄存器（IFR）

|位|源|| --- | -------------------------- |
| 0 | ca2 |
| 1 | ca1 |
| 2 |移位寄存器|
bbbb3 | cb2 |
| 4 | cb1 |
| 5 |定时器2 |
| 6 |定时器1 |
bbb70 |任意中断（逻辑或）|

Interrupt Enable Register （IER）

*位7 =set/clear模式
*位0-6启用单独的源

IRQ逻辑```text
IRQ = (IFR & IER & 0x7F) != 0
```
---

# # 11。握手线

### ca1 / cb1

*边缘检测输入
*触发中断

### ca2 / cb2

*输入或输出
*脉冲或握手模式

模拟器必须:

*跟踪引脚状态
*检测已配置的边缘

---

# # 12。重置行为

重置:

* DDRx = $00
* ORx = $00
*计时器停止
* IFR已获清除
* IER已清除
* IRQ不活跃

---

# # 13。Read/Write副作用

|注册|副作用|| ----------- | ------------------------ |
|ORA/ORB|清除握手标志|
| T1C-H write |加载并启动Timer 1 |
| IFR write |清除写入位|
| IER write |设置或清除启用|

---

# # 14。仿真时序级别

|级别|描述|| -------------- | ------------------------- |
|功能|正确的寄存器行为|
|基于周期的|每个CPU周期的计时器|
|周期精确|匹配真正的VIA定时|

# # 15。集成6502模拟器```text
CPU cycle  VIA tick  update timers  update IRQ
```
* VIA必须与CPU时钟同步
IRQ线在指令边界被CPU采样
