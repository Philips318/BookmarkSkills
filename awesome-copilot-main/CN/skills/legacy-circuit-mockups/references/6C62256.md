# AS6C62256 32K x 8低功耗CMOS SRAM规格

# # 1。概述

**AS6C62256**是**256 Kbit (32K x 8)**低功耗CMOS静态随机存取存储器（SRAM），由Alliance memory公司生产（并由其他公司二次采购）。它与常见的28引脚SRAM引脚完全兼容，广泛用于**6502**，**Z80**和其他8位微处理器系统的read/write存储器。

该器件提供快速的访问时间，简单的控制逻辑，以及非常低的待机功耗。

|组织| 32,768 × 8比特|

# # 3。引脚配置（逻辑）

3.1地址引脚（A0-A14）

*从32,768个内存位置中选择一个
*地址必须在读或写周期内保持稳定

3.2数据引脚（I/O0-I/O7）

*双向三态数据总线
*未启用时高阻抗

控制引脚

|引脚|描述|| --- | -------------------------- |
| ce# |芯片使能（低电平）|
| oe# |输出使能（低激活）|
| WE# | Write Enable (active low) |
| VCC | + 5v电源|
|接地|接地|

---

# # 4。内存的组织

*线性地址空间从`$0000`到`$7FFF`*每个地址对应一个字节（8位）```text
Address range: 0000h - 7FFFh
Data width:    8 bits
```

# # 8。电源模式

### 8.1激活模式

* CE ?=低
*read/write正常操作

8.2待机模式

* CE ?=高
*保留的资料
*功耗极低

---

# # 9。重置和开机行为

*无需复位引脚
*上电时数据未定义
*仅在VCC存在时保留内存内容
