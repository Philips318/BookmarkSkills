# AT28C256 EEPROM仿真规范

# #概述

本文档详细说明了如何在基于6502的系统模拟器中模拟AT28C256 （32 KB并行EEPROM）。目标是*行为准确性*适用于sbc、监视器和真正的ROM映像，而不仅仅是通用的文件支持存储。

AT28C256通常用作6502系统中的**ROM**，但它是*电可写*并且具有与SRAM不同的定时行为。

---

| |值|| -------------- | ---------------------- |
|容量| 32kb (256kbit) |
|组织| 32,768 × 8 |
|地址线| A0-A14 |
|数据线| D0-D7 |
|电源电压| 5V |
|典型用途| ROM / Firmware存储|

|引脚|名称|功能|| ------ | ------------- | ---------------------- |

|接地|接地|参考|

---

##读周期行为

读取发生在：```
/CE = 0
/OE = 0
/WE = 1
```
###读取规则

在断言`/OE`之前，地址必须是稳定的
*数据在访问时间后出现在D0-D7上（在大多数模拟器中忽略）`/OE = 1`或`/CE = 1`时输出**高阻抗**

仿真器行为```text
if CE == 0 and OE == 0 and WE == 1:
    data_bus = memory[address]
else:
    data_bus = Z
```
---

写周期行为

写发生在：```
/CE = 0
/WE = 0
```
（在写操作期间，`/OE`通常为HIGH）

重要的EEPROM特性

*写**不是即时的**
*每次写入触发**内部编程周期**
在编程过程中，读操作可能返回未定义的数据

---

写定时模型（简化）

真正的硬件

| |典型|| --------------- | -------- |
写时间| ~200µs |
|页面大小| 64字节|
|页写时间| ~ 10ms |

模拟器简化选项

####选项A -即时写入（普通）

*写入立即更新内存
*无繁忙状态
*推荐用于早期模拟器

####选项B -基于周期的忙状态（高级）

*跟踪“写入进度”计时器
*读期间写返回最后值或`0xFF`*忽略写入直到循环完成

---

页面写仿真（可选）

*页面大小：**64字节**
*在超时提交之前写入同一页
*页内跨页边界换行（硬件问题）

简化的规则:```text
page_base = address & 0xFFC0
page_offset = address & 0x003F
```
---

##写保护行为

有些系统在编程后把EEPROM当作只读存储器。

模拟器可能支持：

*只读模式（忽略写入）
*可编程模式（允许写入）
*运行时切换（模拟编程跳线）

---

##通电状态

EEPROM保留内容
*没有未定义的通电数据

模拟器:

*从图像文件加载内容
*在重置时保留数据

---

总线争用规则

|条件|行为|| ------------------- | ----------------- |
| /CE = 1 |数据总线= Z |
| /OE = 1 |数据总线= Z |
| /WE = 0 and /OE = 0 |未定义（avoid） |

模拟器可以:

*优先考虑写入
*或标志无效状态

    bool write_enabled;
    bool busy;
    uint32_t busy_cycles;
