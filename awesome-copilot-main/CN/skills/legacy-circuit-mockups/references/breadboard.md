#无焊面包板

一个实用的Markdown规范和参考**常见无焊面包板**，用于电子样机，教育，和业余爱好者的发展。

---

# # 1。概述

无焊面包板是一种可重复使用的原型设计平台，允许电子元件在没有焊接的情况下相互连接。通过内部弹簧夹进行连接。

###典型用途

*快速电路原型设计
*教育实验室
*逻辑和微控制器实验
*低功耗模拟和数字电路

不适合

*大电流（>1A）
*高压（>36V）
* RF /高频设计
*易震动或永久性装置

# # 2。物理结构

# # #的材料

* ABS或聚苯乙烯阀体
*磷青铜或镀镍弹簧触点
*背胶（可选）

标准孔间距** *2.54毫米（0.1英寸）** -与DIP ic和标准头兼容

接触特征

| |典型值|| ------------------ | ------------- |
|接触电阻| 10-50 mΩ |
|插入周期| ~ 5000 |
线规| 20-28 AWG |

# # 3。内部电气连接

终端带（主区域）

*行**5互连孔**
*横向连接
*中间壕沟隔离左右两半```
A B C D E | F G H I J
──────────┼──────────
Connected | Connected
```
电源导轨

*两边都是垂直的公交车
通常在中间分裂（不总是连续的）
*通常标记**红色(+)**和**蓝色(-)**```
+  +  +  +  +   (may be split)
-  -  -  -  -
```
>吗?一定要用万用表检查连续性

# # 7。最佳实践

###配电

*跑**地面和Vcc**到两边
*桥分裂电源轨道，如果需要
*0.1µF陶瓷电容的去耦ic **

# # #布线

*保持电线短而整齐
*使用彩色编码：

*红色：Vcc
*Black/Blue: GND
*Yellow/White：信号

IC放置

*将DIP ic **放置在中间的沟槽**上
*避免强迫销钉
