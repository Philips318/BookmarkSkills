# MOS Technology 6522通用接口适配器（VIA）

# # 1。概述

**MOS Technology 6522 VIA**是一款通用I/O控制器，旨在将6502系列微处理器与外部外设连接起来。它于20世纪70年代中期引入，提供并行I/O端口、定时器、移位寄存器支持和中断处理。6522广泛用于诸如Commodore PET， VIC-20, Apple II， BBC Micro和许多基于6502的嵌入式设计等系统。

---

# # 2。一般特征

|特性|描述|| -------------- | -------------------------------- |
|数据宽度| 8位|
|寻址|内存映射I/O|
|注册| 16（4位寄存器选择）|
|I/Oports | 2个8位端口（端口A、端口B） |
|定时器|两个16位定时器|
|移位寄存器| 8位串行I/O|
|中断|可屏蔽，多源|
|时钟|系统时钟（φ2） |

---

# # 3。引脚函数（逻辑）

3.1 A口（PA0-PA7）

* 8位双向并行I/O*通过CA1 / CA2支持握手

3.2 B接口（PB0-PB7）

* 8位双向并行I/O*通过CB1 / CB2支持握手
* PB6和PB7可由定时器1控制

控制引脚

|引脚|描述|| --------- | ------------------------------------- |
| CA1 / CB1 |可中断控制输入|
| CA2 / CB2 |握手/脉冲/中断引脚|
| IRQ |中断请求输出（活动低）|
| RESET |复位输入|

---

# # 4。寄存器映射

使用4个地址线（RS0-RS3）选择寄存器。基址是系统定义的。

|偏移量|寄存器|描述|| -----: | --------- | ------------------------------------ |
| $0 | ORB |输出寄存器B |
| $1 | ORA / IRB |输出寄存器A /输入寄存器B |
| $2 | DDRB |数据方向寄存器B |
| $3 | DDRA |数据方向寄存器A |
| $4 | T1C-L |定时器1计数器低|
| $5 | T1C-H |定时器1计数器高|
| $6 | T1L-L |定时器1闩锁低|
| $7 | T1L-H |定时器1锁存高|
| $8 | T2C-L |定时器2计数器低|
| $9 | T2C-H |定时器2计数器高|
| $A | SR |移位寄存器|
| $B | ACR |辅助控制寄存器|
| $C | PCR |外围控制寄存器|
| $D | IFR |中断标志寄存器|
| $E | IER |中断启用注册|
| $F | ORA / IRA |输出寄存器A /输入寄存器A |---

# # 5。数据方向寄存器（DDRA / DDRB）

每个位控制其对应端口引脚的方向：

*`0`=输入
*`1`=输出```text
DDRB bit = 1  PBx is output
DDRB bit = 0  PBx is input
```
---

# # 6。计时器

定时器1 （T1）

* 16位向下计数器
*可一次运行或自由运行
*可以切换PB7超时
*生成中断

定时器2 （T2）

* 16位向下计数器
*支持PB6脉冲计数
*仅一次操作

---

# # 7。移位寄存器（SR）

* 8位移位寄存器
*可以移入或移出数据
*时钟源可通过ACR选择
*常用于串行通信或键盘扫描

---

# # 8。控制寄存器

辅助控制寄存器（ACR）| Bit |功能|
|——：| ---------------------------------- |
| 7 |定时器1控制（PB7输出）|
| 6 |定时器1模式（自由运行/一次性）|
| 5 |定时器2控制|
| 4 |移位寄存器模式|
bbb3 |移位寄存器时钟源|
| 2 | B端口锁定|
| 1 | A口闭锁|
|0 |未使用的|

8.2外围控制寄存器（PCR）

控制CA1， CA2, CB1， CB2行为：

*Input/output模式
*主动边缘选择
*脉冲或握手模式

---

# # 9。中断系统

中断标志寄存器（IFR）|位|源|
|——：| ---------------------------------- |
bbb7 | IRQ状态（任何已启用的中断）|
| 6 |定时器1 |
| 5 |定时器2 |
| 4 | cb1 |
bbbb3 | cb2 |
| 2 |移位寄存器|
| 1 | ca1 |
| 0 | ca2 |

中断使能寄存器（IER）

*位7决定set/clear模式：

*`1`=设置位
*`0`= clear bits```text
Write $80 | mask  enable interrupts
Write $00 | mask  disable interrupts
```
---

# # 10。重置行为

重置:

*清除所有DDR位（端口默认为输入）
*计时器停止
*移位寄存器禁用
*禁用中断

---

# # 11。时间节点

*通过φ2同步访问VIA寄存器
*计时器计数器每φ2周期递减一次
*当reading/writing寄存器时，一些操作有副作用

---

# # 12。常用用例

*键盘和操纵杆界面
*并行打印机接口
*计时器和事件计数
*简单串行通信
*通用GPIO扩展
