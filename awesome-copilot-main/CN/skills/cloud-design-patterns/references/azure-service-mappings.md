# Azure服务映射

每个模式的公共Azure服务

-消息队列：Azure服务总线，Azure存储队列，事件中心
- **缓存**:Azure缓存Redis， Azure前门缓存
- **API网关**:Azure API管理，Azure应用网关
- **身份**:Azure广告，Azure广告B2C
- **配置**:Azure应用程序配置，Azure密钥库
- **存储**:Azure存储（Blob，表，队列），Azure Cosmos DB
- **计算**:Azure功能，Azure容器应用程序，Azure Kubernetes服务
-事件流**:Azure事件中心，Azure事件网格
- **CDN**: Azure CDN， Azure前门
