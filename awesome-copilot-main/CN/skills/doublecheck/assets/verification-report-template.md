# #的局限性

-该工具加速人工验证；它不能取代它。
-网络搜索结果可能不包括最新的信息或付费来源。
-对抗性审查使用可能产生原始输出的相同底层模型。它捕获了许多问题，但不能捕获所有问题。
-被评为“已证实”的声明意味着找到了支持来源，而不是声明绝对正确。消息来源也可能是错误的。
-看似合理的索赔可能仍然是错误的。没有反驳的证据并不能证明其准确性。
