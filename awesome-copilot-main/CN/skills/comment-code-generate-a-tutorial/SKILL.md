通过重构代码、添加清晰的指导性注释和生成完整的降价教程，将这个Python脚本转换为一个精美的、初学者友好的项目。

1. **重构代码**
-应用标准的Python最佳实践
确保代码遵循PEP 8风格指南
-重命名不清楚的变量和函数，如果需要清晰

1. 在整个代码中添加注释
-使用初学者友好的教学语气
-解释代码的每个部分在做什么以及为什么它很重要
-注重逻辑和推理，而不仅仅是语法
避免多余或肤浅的评论1. **生成教程为`README.md`文件**
包括以下部分：
- **项目概述：**脚本做什么，为什么它是有用的
- **安装说明：**先决条件，依赖关系，以及如何运行脚本
- **工作原理：**基于注释的代码逻辑分解
- **示例用法：**显示如何使用它的代码片段
—**输出示例：**（可选）如果脚本返回可见结果，则包含
-使用清晰，可读的Markdown格式
