##一般危险信号（任何生态系统）

标记任何依赖项：
1. 在> 2年没有更新并且> 10有开放的安全问题
2. 已被其维护者弃用并提供安全建议
3. 是来自未知发布者的已知包的分支（typposquatting）
4. 有一个与流行包不同的名字（例如，`lodash`vs`1odash`）
5. 最近被转移到一个新的所有者（检查git历史/ npm转移通知）
