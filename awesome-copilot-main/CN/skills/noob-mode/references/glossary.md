#新手模式词汇表

使用Copilot CLI时，您将遇到的技术术语的简单英语参考。按类别组织。

---

##🗂️Git &版本控制

###仓库（repo）
**一个项目文件夹，它记住了对其文件所做的每一个更改。
**类比：**一个内置时间机器的文件柜——你可以从过去的任何时间点拿出任何版本的任何文件。
**上下文中的例子：** "I'll look at the files in this repository" = “I'll l look at the files in this project folder.”

# # #分支
**简单的英语：**项目的一个单独的副本，您可以在不影响原始的情况下尝试更改。
**类比：**制作一份合同的影印本来测试编辑，但不接触已签署的原件。
**上下文中的例子：“我将创建一个新分支”=“我将创建一个副本，我可以安全地进行实验。”# # #提交
**简单的英语：**保存工作的快照，并注明更改的内容。
类比：在每次工作结束时给你的办公桌拍一张照片，并在便利贴上写下你做了什么。
**上下文中的例子：** "I'll commit these changes" = “I'll save a snapshot of what I just done .”

# # #合并
**简明英语：**将一个副本中的更改合并回原始副本。
**类比：**从你标记过的影印本上进行编辑，并将其写入正式合同。
上下文中的例子：“让我们合并这个分支”=“让我们将这些更改折叠回主版本。”Pull Request （PR）
简单的英语：一个正式的请求，说“我做了这些改变——在我们正式发布之前，有人能检查一下吗？”
**类比：**在提交给客户之前，提交一份划了红线的文件供合伙人审查。
**上下文中的例子：**“我将打开一个pull request”=“我将提交这些更改以供审查。”

# # #克隆
**从服务器下载项目的完整副本到您的计算机。
类比：从公司的服务器上获取你自己的共享案件文件副本。
**上下文中的例子：**“克隆存储库”=“将项目下载到您的计算机。”

# # #叉
简单的说：**在服务器上复制别人的项目。
**类比：**获得自己的模板副本，您可以自定义而不影响原始模板。
**上下文中的例子：** “Fork this repo“ = ”创建你自己的这个项目的副本。”# # # Diff
**简明英语：**比较两个版本之间的变化——添加、删除或修改的内容。
**类比：** Word中的跟踪更改，显示红色划线和蓝色添加。
上下文中的例子：“让我检查一下diff”=“让我看看到底改变了什么。”

暂存区（索引）
**在保存快照之前放置文件的等待区。就像一堆“待承诺”的东西。
类比：办公桌上的发件箱——你决定发送但还没有真正寄出的文件。
**上下文中的例子：**“I'll stage these files”=“我将把这些文件标记为准备保存。”# # #远程
**简单的英语：**你的项目在服务器上的副本（如GitHub），而不是在你的计算机上的副本。
类比：公司云存储中的主副本和你笔记本电脑上的副本。
**上下文示例：** "Push to remote" = “Upload your changes to the server.”

# # #推
**简单的英语：**上传您保存的更改从您的计算机到共享服务器。
**类比：**将您的本地编辑同步回共享驱动器，以便每个人都可以看到它们。
**上下文示例：** "I'll push these commits" = “I'll l upload these saved changes to the server.”

# # #拉
**从共享服务器下载最新的更改到您的计算机。
**类比：**用你的同事所做的任何更新刷新你的本地副本。
**上下文示例：** “Pull the latest changes“ = ”从服务器下载任何更新。”# # #结帐
**切换到项目的不同分支或版本。
**类比：**从文件柜里拿出一份不同版本的文件来处理。
**上下文示例：** "Checkout the main branch" = “Switch back to the main version of project.”

# # #冲突
简单的说：当两个人更改了同一文件的同一部分，计算机不能自动找出该保留哪个版本。
**类比：**两个律师对合同的同一段进行了不同的编辑——需要有人来决定哪个版本胜出。
上下文中的例子：“有一个合并冲突”=“两组更改重叠，我需要你决定保留哪个。”# # #藏
简单的说：**暂时保存当前正在进行的工作，以便您可以切换到其他工作，然后稍后再回来。
类比：**把当前的文件放在抽屉里，这样你就可以为紧急任务清理桌子，然后稍后再把它们拿出来。
上下文中的例子：“I'll stash your changes”=“我将暂时保存你正在进行的工作。”

# # #的头
**简单的英语：**你目前正在看/工作的项目的版本。
**类比：**当前在屏幕上打开的文档。
**上下文中的例子：** “HEAD指向main“ = ”您当前正在查看主版本。”# # #标签
附在特定版本上的永久标签，通常标志着一个发布或里程碑。
**类比：**在合同的特定版本上贴上“最终-由客户签署”的标签。
**上下文中的例子："I'll tag this as v1.0" = “I'll l tag this as official 1.0 release.”

##💻文件系统和Shell

###终端（控制台）
**简单的英语：**基于文本的计算机控制面板。你输入命令而不是点击按钮。
类比：就像给你的电脑发指令，而不是点击。
**上下文示例：**“打开你的终端”=“打开你输入命令的应用程序。”Shell （Bash, Zsh）
**运行在终端内并解释你输入的命令的程序。
类比：在电话另一端执行你请求的接线员。
**上下文示例：** “Run this in your shell“ = ”在你的终端输入这个命令。”

命令行接口（Command Line Interface）
**简单的英语：**一个程序，你通过输入命令而不是点击一个可视化的界面进行交互。
**类比：在餐厅通过与服务员对话（CLI）和点击平板电脑菜单（GUI）来点餐。
**上下文中示例：** “Use the CLI“ = ”键入命令而不是单击按钮。”

# # #目录
简单的说：**你电脑上的一个文件夹。
类比：它就是一个文件夹。我们只是用了一个更花哨的词。
**上下文中的例子：** "Navigate to this directory" = “Go to this folder.”# # #路
**你电脑上文件或文件夹的地址，显示你要经过的每个文件夹。
**类比：**像街道地址：国家/州/城市/街道/建筑-但用于文件。
**上下文示例：** “`~/Desktop/contracts/nda.md`“ = ”一个名为nda.md的文件，在你的桌面上的合同文件夹中。”

###根（/）
**你电脑上最顶层的文件夹——所有其他文件夹都在里面。
类比：大楼的大厅——每一层和每一个房间都可以从这里进入。
**上下文示例：**“根目录”=“计算机上最顶层的文件夹”。

主目录（~）
简单的说：**你电脑上的个人文件夹。在Mac上是`/Users/yourname`。
比喻：你在大楼里的私人办公室。
**上下文示例：** “`~/Desktop`“ = ”个人文件夹中的桌面文件夹”环境变量
简单的英语：**存储在计算机上的程序可以读取的设置。就像你显示器上的便利贴一样，应用程序可以看到。
类比：一个名字徽章，程序可以通过检查来了解你的设置。
**上下文示例：** “设置环境变量” = “保存一个程序可以查询的设置。”

###管道（|）
**将一个命令的输出发送到另一个命令，就像装配线一样。
**类比：**接力将文件从一个人传递给另一个人。
**上下文中的示例：** “`grep 'term' file.txt | wc -l`“ = ”找到该术语，然后计算它出现的次数。”###重定向（>,>,>）
**将输出发送到文件而不是显示在屏幕上。`>`替换文件；`>>`加上它。
类比：**不要大声读报告，而是把它写在纸上。
**上下文中的示例：** “`echo 'hello' > file.txt`“ = ”将‘hello’写入file.txt（替换那里的任何内容）。”

# # #权限
**关于谁可以阅读、编辑或运行文件的规则。如代码`rwx`或数字`755`所示。
**类比：**就像SharePoint中的文档权限——谁可以查看，谁可以编辑，谁可以共享。
上下文中的示例：“更改文件权限”=“更改允许谁读取或编辑此文件”。###符号链接
**指向另一个文件或文件夹的快捷方式。不是复制，只是一个指针。
**类比：**文档中的超链接，将您带到原始文件。
**上下文示例：** “Create a symbol link“ = ”创建一个指向另一个文件的快捷方式。”

###标准输出/标准错误
**简易英语：**两路程序输出。Stdout是正常输出；Stderr是错误消息。
**比喻：** stdout是会议上的主要发言人；Stderr是传递紧急通知的人。
**上下文中的例子：** “Redirect stderr“ = ”将错误消息发送到特定的地方。”

# # #脚本
**一个文件，包含一个自动运行的命令列表，一个接一个。
类比：一个食谱——按照顺序来做，你就会得到结果。
**上下文中示例：** “Run this script“ = ”运行预写的命令列表”。

##🔧发展理念应用程序编程接口
简单的英语：两个程序按照约定的规则进行对话的一种方式。
比喻：餐馆的服务员——把你点的菜送到厨房，然后端回来你要的东西。
上下文中的例子：“调用API”=“向另一个程序发送请求并获得响应。”

# # #端点
** API接受请求的特定URL，如公司的特定电话分机。
类比：**政府办公室中处理一种请求的特定办公桌。
**上下文中示例：** “The /users endpoint“ = ”处理用户相关请求的特定地址”# # #服务器
简单英语：当你要求时提供服务的计算机（或程序）。它等待请求和响应。
**类比：**图书管理员——你要一本书，他们会找到并递给你。
**上下文示例：**“启动服务器”=“打开侦听和响应请求的程序”。

# # #客户
**向服务器发送请求的程序。你的浏览器就是一个客户端。
类比：在图书馆向图书管理员要书的顾客。
上下文中的例子：“客户端发送一个请求”=“你的程序向服务器请求一些东西。”# # #数据库
**程序可以搜索、添加、更新和删除的有组织的数据集合。
类比：一个非常复杂的电子表格，多个程序可以同时读取和写入。
**上下文中示例：** “Query the database“ = ”在数据存储中查找信息”。

# # #的依赖
**简单的英语：**一个预构建的工具或库，一个项目需要为了工作。
比喻：你书架上做研究需要的参考书。
**上下文示例：** “Install dependencies“ = ”下载这个项目需要的所有工具和库。”# # #包
简明英语：别人写的一堆代码，打包起来供别人使用。
**类比：**从硬件商店预先构建的工具包-节省您自己构建工具。
**上下文中的示例：** “Install the package“ = ”下载并将此预构建的工具包添加到您的项目中。”

# # #模块
简单的英语：一段独立的代码，处理一件特定的事情。
类比：一本书中的一章——它涵盖了一个主题，可以独立阅读。
**上下文中的例子：** "Import the auth module" = “Load那段处理login/security.的代码”# # #框架
简单的说：一个预先构建的基础，它提供了一个可以构建的结构，以及关于如何组织代码的规则。
**类比：**法律摘要模板——它给你结构，你填写实质内容。
上下文中的例子：“我们正在使用React框架”=“我们正在构建一个叫做React的预制结构。”

# # #构建
**简单的英语：**将源代码转换成可以实际运行的东西。
**类比：**将Word文档转换为最终的PDF文件——内容是一样的，但格式现在已经准备好分发了。
**上下文中的例子：**“运行构建”=“将代码转换为完成的，可运行的形式。”# # #编译
**通俗英语：**将代码从人类写的语言翻译成计算机能理解的语言。
**类比：**将一份合同从英语翻译成日语，以便对方能够阅读。
**上下文中的例子：** “编译代码” = “将其翻译成计算机可读的形式。”

### Lint / Linter
**一个工具，检查你的代码的常见错误，风格问题，和潜在的问题-不运行它。
类比：代码的拼写检查器和语法检查器。
**上下文中的例子：** “Run the linter“ = ”检查代码中的错误和风格问题。”测试（单元测试，集成测试）
**简明英语：**自动检查其他代码是否正常工作的代码。
**类比：** QA检查清单—“登录页面是否有效？搜索是否返回结果？保存按钮真的能保存吗？”
**上下文中示例：** “运行测试” = “自动验证一切仍正常运行”。

# # #运行时
**代码实际运行的环境。还指代码活跃运行的时间段。
类比：表演戏剧的舞台（与剧本相反，剧本是代码）。
**上下文中的例子：**“运行时错误”=“程序实际运行时出错了。”# # #部署
简单地说：把完成的代码放到人们可以使用的地方（服务器、网站、应用商店）。
类比：出版一本完成的书——把它从作者的书桌上搬到书店的书架上。
**上下文中的示例：**“部署到生产环境”=“使其可供实际用户使用”。

##🌐Web & Networking

URL（统一资源定位符）
**简单的英语：**网址。你在浏览器地址栏中输入的文本。
**类比：**街道地址，但用于网站。
**上下文示例：** "`https://github.com/settings`" = “ GitHub网站上的设置页面。”### HTTP / HTTPS
**简单的英语：** web浏览器和服务器用来相互交流的语言。HTTPS是安全（加密）版本。
**类比：** HTTP发送一张明信片（任何人都可以阅读）；HTTPS发送的是一个密封的、锁定的信封。
**上下文示例：**“发出HTTP请求”=“向web服务器发送消息”。

JSON （JavaScript Object Notation）
**简明英语：**构建数据的标准格式，易于人类和计算机阅读。
类比：一个带有标签字段的非常有组织的表单，如：`{ "name": "Jane", "role": "Attorney" }`。
**上下文示例：**“API返回JSON”=“响应返回为结构化的标记数据。”# # #令牌
**简单的英语：**一个数字钥匙或通行证，证明你的身份，而不是每次输入密码。
**类比：**一个建筑物的访问徽章-你刷它，而不是每次显示你的ID。
**上下文示例：**“您的身份验证令牌”=“证明您已登录的数字密钥”。

###状态码
** web服务器返回的一个数字，告诉你你的请求是否有效。常见的:
- **200** = Success（“这是你想要的”）
- **404** = Not Found （“Thatpage/thing不存在”）
- **500** =服务器错误（“我们这边有东西坏了”）
- **401** =未经授权（“您需要先登录”）
**403** =禁止（“你登录了，但没有权限”）# # # Localhost
**简单的英语：**指的是你自己的电脑，就好像它是一个web服务器。用于测试。
类比：在会议室演讲之前，先在自己的办公室排练。
**上下文示例：** “`http://localhost:3000`“ = ”在您自己的计算机上运行的网站，在3000频道上。”

# # #端口
简单的英语：计算机上的一个数字通道。不同的服务使用不同的端口，就像不同的电视频道一样。
**类比：**无线电频率-每个电台在自己的频率上广播，所以他们不会干扰。
**上下文中的例子：**“运行在端口3000上”=“在您的计算机上使用通道3000。”REST （RESTful API）
**构建web api的通用风格，使用标准的web地址和操作（GET， POST等）与数据交互。
类比：一个标准化的表单系统——每个人都同意如何提交、检索、更新和删除记录。
**上下文中的示例：**“RESTful端点”=“遵循数据访问标准约定的web地址”。

##🤖Copilot CLI Specific

MCP服务器（模型上下文协议）
**简单的英语：**一个附加组件，给Copilot CLI额外的能力-像一个web浏览器的插件。
**类比：**在你的手机上安装一个新的应用程序，增加一个以前没有的功能。
**上下文示例：**“配置MCP服务器”=“设置一个附加组件，为副驾驶提供新功能。”工具调用
**简单的英语：**当副驾驶要求使用其内置功能之一（读取文件，运行命令，搜索网络等）。
类比：助理在开始工作前问：“我能打开这个文件柜吗？”
**上下文中的例子：**“批准这个工具调用”=“允许我使用这个特定的能力。”

审批提示
**简单的英语：**副驾驶在做某事之前停下来征求你的许可的时刻。
类比：你的助理说：“在我发这封邮件之前，你能看一下吗？”
上下文中的例子：“我需要你的批准”=“我做这件事之前征求你的同意。”###上下文窗口
**简明英语：**副驾驶一次能记住的对话和信息总量。当它填满时，旧的部分被总结或遗忘。
**类比：**办公桌的大小——在你需要归档一些文件之前，你只能把这么多文件摊开。
**上下文中的例子：**“上下文窗口已满”=“我的工作内存不足，可能需要总结我们之前的对话。”

# # #模型
简单地说：**驱动副驾驶的人工智能大脑。不同的模式（十四行诗，GPT，双子座）有不同的优势。
**类比：**不同的搜索引擎（b谷歌，必应）——它们都在搜索网络，但它们的工作方式不同，给出的结果也略有不同。
**上下文中的例子：**“切换到不同的模型”=“使用不同的AI大脑”# # #令牌
**简而言之：**人工智能模型处理的文本单位。粗略地说，1个token≈一个单词的3 / 4。
**类比：**如果AI阅读的是音节而不是整个单词，那么每个音节都是一个标记。
上下文中的例子：“这使用了1000个token”=“这是大约750个单词的AI处理价值”。

# # #技能
**简单的英语：**一个专门的能力，你可以添加到副驾驶CLI的特定类型的任务。
类比：你可以找一个专家——比如找一个税务专家和一个合同专家。
**上下文中的例子：**“激活技能”=“开启特殊能力”。

# # #插件
**简单的英语：**扩展什么Copilot CLI可以做的附加组件，由第三方提供。
**类比：**一个浏览器扩展-别人建立了它，你安装它来添加功能。
**上下文示例：**“安装插件”=“向Copilot添加第三方功能”。# # #会话
**简单的英语：**一个连续的对话与副驾驶CLI，从你开始，当你关闭它。
类比：一通电话——所有讨论的内容都是那一次通话的一部分，直到你挂断电话。
上下文中的例子：“Resume a session”=“继续之前的对话。”

自定义指令
**简单的英语：**一个文件，告诉副驾驶如何行为-你的喜好，规则和风格要求。
类比：你给新同事的简要说明是：“我希望我的备忘录格式是这样的，优先顺序是这样的。”
**上下文中的例子：**“切换自定义指令”=“打开或关闭副驾驶的一组特定行为规则。”
