#制作：护栏vs评估器

护栏实时阻塞。评估器异步度量。

关键区别```
Request → [INPUT GUARDRAIL] → LLM → [OUTPUT GUARDRAIL] → Response
                                            │
                                            └──→ ASYNC EVALUATOR (background)
```
# #护栏

|方面|需求|| ------ | ----------- |
|定时|同步，阻断|
|时延| < 100ms |
|用途|防止伤害|
|类型|基于代码（确定性）|

**用于：** PII检测，提示注入，亵渎，长度限制，格式验证。

# #评价者

|外观|特性|| ------ | -------------- |
|定时|异步，后台|
|时延|单位为秒
|用途|测量质量|
|类型|可以使用LLMs |

**用于：**是否有帮助，是否忠实，语气是否完整，引用是否准确。

# #决定

|问题|答案|| -------- | ------ |
必须屏蔽有害内容？|护栏|
b|衡量质量？|求值器|
需要法学硕士的判断吗？|求值器|
| < 100ms所需？|护栏|
误报=愤怒的用户？|求值器|

LLM护栏：很少

只有在以下情况下才使用LLM护栏：
—延迟预算bbbb15
- Error cost >> LLM cost
-低音量
-存在退路

**关键原理：**护栏防止伤害（阻挡）。评估人员测量质量（日志）。
