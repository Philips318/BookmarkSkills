#目视检查清单

本文档是一份全面的清单，列出了在网页设计视觉检查过程中需要验证的项目。

---

# # 1。布局验证

结构完整性

-[]标题正确的fixed/positioned在屏幕的顶部
-[]页脚位于屏幕底部或内容末尾
-[]主内容区居中对齐，宽度适当
[]侧边栏（如果存在）位置正确
—[]导航显示在指定位置

# # #溢出

-[]水平滚动条不会自动显示
-[]内容不会从父元素溢出
-[]图像适合父容器
-[]表不超过容器宽度
-[]代码块自动换行或滚动

# # #对齐-[]网格项均匀分布
- [] Flex项目对齐正确
—[]文本对齐（left/center/right）保持一致
-[]图标和文字垂直对齐
—[]表单标签和输入字段位置正确

---

# # 2。字体设计验证

# # #可读性

-[]正文字体大小足够（建议最小16px）
-[]行高合适（推荐1.5-1.8）
—[]每行字符数为宜（建议40-80个字符）
-[]段落之间要有足够的间距
-[]标题大小层次清晰

文本处理

-[]长词适当换行
—[]正确处理url和代码
-[]没有文本剪切发生
—[]省略号（…）正确显示
-[]特定语言的断行规则工作正常

# # #字体-[]网页字体加载正确
—[]备用字体合适
—[]字体大小与实际情况一致
-[]特殊字符和表情符号显示正常

---

# # 3。颜色和对比度验证

可访问性（WCAG标准）

-[]正文：对比度4.5:1或更高（AA）
[]大字体（18px+粗体或24px+）： 3:1或更高
-[]交互元素边框：3:1或更高
-[]焦点指标：与背景有足够的对比

颜色一致性

-[]品牌颜色统一
—[]链路颜色一致
-[]错误状态红色统一
—[]成功状态绿色为统一
- []Hover/active状态颜色适当

色彩视觉多样性

-[]通过形状和文字传达信息，而不仅仅是颜色
-[]图表和图表考虑色觉多样性
-[]错误信息不完全依赖于颜色

---

# # 4。响应验证###移动（~640px）

-[]内容适合屏幕宽度
-[]触摸目标是44x44px或更大
—[]文本为可读大小
-[]无水平滚动
-[]导航是移动友好的（汉堡包菜单等）
-[]表单输入易于使用

平板电脑（641px~1024px）

-[]布局优化平板电脑
-[]两列布局显示适当
—[]图片大小合适
-[]边栏show/hide是合适的

###桌面（1025px~）

[]设置最大宽度，在超大屏幕上不会断裂
—[]间距足够
-[]多栏布局功能正常
-[]实现悬停状态

断点转换

-[]布局平滑过渡时，屏幕大小的变化
[]中等大小的布局不会中断
-[]没有内容消失或重复

---

# # 5。交互元素验证

# # #按钮-[]默认状态为清除
-[]悬停状态存在（桌面）
-[]焦点状态直观清晰
-[]激活（按下）状态
—[]禁用状态可区分
-[]加载状态（如果适用）

# # #的链接

—[]链接具有视觉可识别性
-[]访问的链接是可区分的（如果需要）
-[]存在悬停状态
—[]“焦点状态”为“clear”

###表单元素

-[]输入框边界清晰
-[]占位符文本对比度合适
-[]焦点视觉反馈
-[]显示错误状态
-[]必选字段指示
—[]下拉菜单功能正常

---

# # 6。图片及媒体验证

# # #图片

-[]图像显示在适当的大小
-[]保持纵横比
-支持高分辨率显示（@2x）
-[]图片加载失败时显示
-[]延迟加载行为

###视频和嵌入-[]视频适合容器
-[]保持纵横比
-[]嵌入式内容响应
- [] iframes不会溢出

---

# # 7。可访问性验证

键盘导航

-[]通过Tab键访问所有交互式元素
-[]焦点顺序符合逻辑
[]焦点陷阱是适当的（情态等）
-[]链接已存在

屏幕阅读器支持

-[]图片有全部文字
—[]表单有标签
-[]正确设置ARIA标签
[]标题结构正确（h1→h2→h3…）

# # #运动

-[]动画不过分
- [] preferences -reduced-motion（如果可能的话）

---

# # 8。与表演有关的视觉问题

# # #加载

-[]字体FOUT/FOIT最小
-[]没有CLS （layout shift）发生
-[]图片加载时不跳转
-[]骨架屏是合适的（如果适用）

# # #动画[]动画平滑（60fps）
-[]滚动时没有性能问题
-[]过渡是自然的

---

优先级矩阵

|优先级|类别|样例||----------|----------|----------|
| P0（临界）|功能破坏|元素完全重叠，内容消失|
| P1（高）|严重的用户体验问题|文本不可读，按钮不可操作|
| P2（中等）|中等问题|对齐问题，间距不一致|
| P3（低）|小问题|定位差异小，颜色变化|
