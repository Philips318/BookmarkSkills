#定位策略

找到并拥有一个可防御的市场地位。将通用的信息转化为明确的差异化——或者至少在付诸行动之前测试一下你的差异化是否真的引起了共鸣。

##何时使用

* *触发:* *
-“我们的信息听起来和竞争对手一模一样”
-“品牌知名度高，但转化率低”
-“销售团队无法解释为什么我们不同”
-“买家认为我们是可以互换的”
-“我们在重塑品牌之前应该重新定位吗？”
“我们如何测试定位声明？”

* *背景:* *
-同类产品的竞争市场
-没有转换的消息
-新产品发布
-重新定位现有产品
-销售团队报告买家困惑

核心框架

# # # 1。一个词可以改变一切（“自主”问题）

* *的模式:* *自主人工智能产品的早期企业对话。定位为“自主AI代理”。

开发者：“很酷，但也很可怕。”
经理们：“这会取代我们的团队吗？”
发牌进程：缓慢。“我们会考虑的。”

* *的变化:* *

一个词：“自主”→“AI队友”

同样的产品。相同的功能。不同的框架。

* *结果:* *

开发者：“这对我有帮助。”
经理：“这让我的团队更有效率。”
交易进程：显著加快。

**为什么重要：**

定位不是你做什么。这是你**没说的**。

我们可以说“取代开发人员”（从技术上讲，对于某些任务是正确的）。会毁了所有的企业交易

**框架：词语选择塑造购买者心理****让企业害怕的词语：**
-自主（暗示：不受控制，取代人类）
-取代（威胁：工作保障）
-完全自动化（去除：人工判断）
- ai优先（意思：不清楚，流行语）

**可转换的单词：**
-队友（暗示：合作、帮助）
-增强（帮助：使人类更好）
-你掌控一切（保证：人为疏忽）
-处理重复性工作（具体：节省时间）

**如何测试选词：**

不猜。测试。

**测试1：出站邮件A/B**
-发送100名潜在客户版本A（“自主代理”）
-发送100名潜在客户版本B（“AI队友”）
-衡量指标：回复率、会议预定率
-信号强度：高（真实买家意向）**测试2：网站首页A/B**
-版本A：当前定位
-版本B：新词选择
-衡量标准：关键cta的点击率
—时间：最少1-2周
-信号强度：中等（有兴趣但没有承诺）

测试3：销售电话脚本
—半数ae使用A定位
—一半使用B定位
-测量：演示到试验的转换
-信号强度：高（实际销售周期）

* *常见的错误:* *

根据内部共识而不是客户反馈来改变定位。你的团队不是买家。

# # # 2。提交前测试（爬行-行走-运行定位Rollout）

* *的模式:* *

定位变化会带来风险。品牌混乱。销售失调。客户流失（如果现有客户不认识你）。

**通过分阶段推出降低风险：**

**爬行阶段（1-2周）：验证**

不提交product/org资源的情况下测试消息传递。* *行动:* *
-A/B测试网站标题（新的vs现有的）
-向潜在客户发送两个出站邮件序列（不同的定位角度）
-询问现有客户：“如果我们将自己描述为（新定位），您还能认出我们吗？”

测量:* * * *
-跟踪网页变体的点击率
-跟踪出站序列的回复率
-记录定性反馈

* *Go/No-Go: * *
-至少有一个定位变体在回复率上超过现任20%以上
现有客户不会说“等等，这不是你该做的”
-如果确定获胜者，继续进行；如果被绑住了，跑更长时间或测试新的角度

**步行阶段（2-3周）：对齐**

如果测试成功，将产品和销售定位于新的定位（但不要公开重塑品牌）。* *行动:* *
-重写网站文案（首页、企业页面、cta）
-创建销售支持：更新演示文稿，电话脚本，电子邮件模板
-更新文档以匹配新的叙述
-构建特定于用例的示例

测量:* * * *
-销售团队对信息可用性的反馈
-网站参与度分析（尚未转化）
-细分分析（谁在回应？）

* *Go/No-Go: * *
销售团队说新的消息传递更容易使用
-点击率指标比现有的有所提高
-没有大客户混淆
-继续运行

**运行阶段（2-3周和持续）：规模**

完整的承诺。这就是品牌重塑。

* *行动:* *
-每个用例启动专用的登陆页面
-每个定位角度的出站活动
更新所有面向客户的资料
对客户成功团队进行新的培训
-宣布重新定位（如适用）测量:* * * *
-按定位角度计算的管道体积
-定位角度胜率
-按通道的CAC效率
-客户留存（我们有流失客户吗？）

* *常见错误:* *
跳过爬行（在没有验证的情况下跳转到完全重塑）
并行运行阶段（如果消息在上线过程中发生变化，会造成混乱）
-等待产品完善后再重新定位（产品应遵循定位，而不是先于定位）
-没有在每个阶段进行测量（不能确定测试是否“赢”）

# # # 3。定位清晰度诊断

* *的模式:* *

如果你的信息与竞争对手的信息非常相似，那么你的问题就在于定位，而不是产品。**定位故障表现为：**
-所有竞争者描述的道具价值几乎相同
-差异化需要解释复杂的技术细节
-买家认为产品是可以互换的
-营销指标（点击率、用户粘性）低于行业基准
-销售对话被比较问题搞得一团糟

**如何执行：**

**第一步：竞争对手消息审计**
-收集5-7个直接竞争对手的主页标题
-确定共享的权利要求（这些是商品化的）
-竞争对手声称独特价值的地图

* *的例子:* *

如果每个人都说“最快”、“最可靠”、“最容易使用”——这些都是赌注，而不是差异化。第二步：评估你的实际优势
如果没有大规模的研发，你能做什么竞争对手做不到的事情？
你最好的客户选择你的原因是什么？(让他们)
-你们有什么结构优势？（部署模型、数据所有权、定价、网络效应等）

**第三步：找到服务不足的职位**
-现有解决方案在哪些方面令用户失望？
-大家都忽视了什么问题？
-哪些买家群体服务不足？

**第四步：明确声明**

必须:
-你现在就可以拥有的东西（不是未来的路线图）
竞争对手无法轻易复制的东西（结构优势）
-与你最好的客户群产生共鸣

* *常见错误:* *
-声称你比别人做的“更好”（难以置信）
-定位竞争对手已经具备的功能
-多个位置同时（选择一个）
-定位移位前等待完美的产品

---# # # 4。市场定位架构（三层）

**第一层：市场背景
——市场出现了什么问题？
为什么现在会出现这个问题？
-如果问题没有解决怎么办？

* *的例子:* *
“基础设施团队在混合环境中管理日益复杂的部署。组织采用微服务和分布式系统。这造成了传统监控工具无法处理的操作复杂性。”

**第二层：定位陈述（1-2句话）**
- **我们的服务对象**：什么样的客户群？
- **我们解决了什么问题**：具体的痛苦
- **我们的不同之处**：为什么我们重要vs替代品
- **证据**：他们为什么要相信我们？

* *的例子:* *
“我们通过实时连接[工作流A]、[工作流B]和[业务结果]的[核心功能]，帮助平台团队更快地交付产品。”

第三层：叙述将定位扩展为故事：
-为什么世界在变化
-为什么现有的解决方案不起作用
-为什么我们的方法更好
-我们的未来是什么样的

**如何执行：**

在测试前编写所有三个层。首先使用爬行-行走-运行方法测试第2层（定位语句）。如果验证，构建第3层。

# # # 5。标题和副标题测试

**原则：**清晰的定位需要可测试的结构：标题（你是什么？）+副标题(为谁？为什么?)。

**主要标题格式：**
-“[形容词][类别][差异化]”
-“[产品]用于[特定用例]”
-“[核心利益]的[产品]”

* *例子:* *
-“可定制的[工作流]平台”
“自治团队的基础设施”
-“[现任]的企业级替代品”* *红旗:* *
-使用竞争对手的名字（防御性，不自信）
-太技术化（买家不会理解的）
-申索多项权益（选择一项）
-模糊（“X的未来”-难以置信）

* *副标题目的:* *

阐明是谁，为什么，如何与现状不同。

* *例子:* *
-“部署到任何地方。立即规模。你的基础设施，你的规则。”
-“对于淹没在重复工作中的团队。自动化处理80%的工作，人工处理20%的工作。”
——“企业级。没有锁定。适用于现有的堆栈。”

**测试方法：**A/B测试标题+副标题组合：
-变体A：当前消息传递
-变体B：新的定位角度
-变体C：不同的差异化主张

衡量点击率、回复率和转化率。

根据数据而不是意见来选择赢家。

# # # 6。定位防御能力评估**原则：**只有当竞争对手无法轻易复制时，定位才有价值。

* *安全性层次结构:* *

* * 1。结构优势（最强）**
-难以复制：独特的数据所有权，部署灵活性，定价模式，网络效应
-示例：“为内部部署的受监管行业构建”（不重建架构就无法复制）

* * 2。市场地位（第一则强）**
-如果你先拥有它并进行扩展，那么它是可防御的
-例子：“针对[特定工作流程]的第一个AI平台”（模仿者看起来是衍生品）

* * 3。产品特点（弱）**
-易于复制：用户体验，特定的能力
-示例：“更快的API调用”（竞争对手在6周内交付速度改进）

**如何评估：**

对于每一个定位要求，问：1. 竞争对手能否以单一产品冲刺复制这一模式？（是=不可辩护）
2. 我们有结构上的优势吗？（否=临时定位）
3. 鉴于目前的产品，这是可信的吗？（No =还不认领）
4. 我们能在竞争对手做出反应之前拥有这个头寸吗？（No =太慢）

* *常见的错误:* *

定位于竞争对手可以轻易匹配的功能。这就造成了定位跑步机——你总是在防守，从不拥有。

---

决策树

我们应该重新定位吗？```
Is brand awareness strong but conversion weak?
├─ Yes → Positioning problem, test new angles
└─ No → Continue...
    │
    Does our messaging sound like competitors?
    ├─ Yes → Positioning problem
    └─ No → Not a positioning issue
```
我们应该测试哪个定位角度？```
Do we have structural advantage competitors can't copy?
├─ Yes → Position on structural advantage
└─ No → Continue...
    │
    Are we first in a category?
    ├─ Yes → Position on category ownership
    └─ No → Find under-served segment/use case
```
我们是否应该从爬行阶段转向行走阶段？```
Did new positioning outperform incumbent by 20%+?
├─ Yes → Move to Walk (alignment phase)
└─ No → Continue...
    │
    Did we run test long enough (2+ weeks)?
    ├─ No → Run longer
    └─ Yes → Try different positioning angle or stay with incumbent
```
---

常见错误

* * 1。声称自己比别人做的“更好”**
——难以置信。寻找不同的角度。

* * 2。定位于易于复制的功能**
-竞争对手会匹配。需要结构性优势。

* * 3。在定位移位前等待完美的产品
-产品工作应遵循定位，而不是先于定位

* * 4。同时测试过多的定位角度**
-不知道什么在起作用。一次测试一个。

* * 5。跳过验证阶段**
-在没有测试的情况下直接进行品牌重塑=风险

* * 6。所有买家角色的一个定位**
不同的角色关心不同的事情

* * 7。没有区别的通用定位
-“一流”、“创新”=毫无意义

##快速参考* * Crawl-Walk-Run测试:* *
-爬行（1-2周）：A/B测试消息，测量回复率
-步行（2-3周）：将sales/product对齐到获胜角度
-运行（正在进行）：完全重新定位，测量pipeline/conversion**可转换的词：**
-✅队友，增强，你保持控制
-❌自主，替代，完全自动化

**定位审计步骤：**
1. 收集竞争对手的信息
2. 确定你的实际优势（询问客户）
3. 寻找服务不足的职位
4. 提出明确的、可辩护的主张

* *安全性层次结构:* *
1. 结构优势（独特的数据、部署灵活性、定价模型）
2. 市场地位（品类所有权）
3. 产品特性（最弱，容易被复制）

**测试层次（信号强度）：**
1. 出站回复率（最高）
2. 销售电话转化率（高）
3. 网站点击率（中等）
