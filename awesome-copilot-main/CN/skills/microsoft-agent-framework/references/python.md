-在代理和工作流操作中使用现代异步模式。
-添加类型提示，甚至在动态代码中保持api显式。
-遵循标准的Python打包和环境实践的依赖关系和工具。
-以适合Python应用程序结构的方式使用中间件、上下文提供程序和编排模式。
-在引入新的api或工作流模式之前，请检查最新的Python示例。
