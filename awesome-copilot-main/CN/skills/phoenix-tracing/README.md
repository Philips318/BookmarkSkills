#凤凰追踪技能

Phoenix的OpenInference语义约定和工具指南。

# #使用

从`SKILL.md`作为索引和快速引用开始。

##文件组织

平面`rules/`目录下所有带有语义前缀的文件：

-跨类（LLM， CHAIN， TOOL等）
-`setup-*`，`instrumentation-*`-入门指南
-`fundamentals-*`，`attributes-*`-参考文档
-`annotations-*`、`export-*`-高级特性
