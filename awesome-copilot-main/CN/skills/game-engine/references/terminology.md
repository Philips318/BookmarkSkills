#游戏开发术语

电子游戏开发术语和概念的综合词汇表，按类别组织，供快速参考。

来源:https://www.gameindustrycareerguide.com/video-game-development-terms-glossary/---

通用开发条款

AAA （AAA级）
这是指由拥有大量预算、大型团队和高制作价值的大型工作室所制作的游戏。比如《使命召唤》、《刺客信条》和《最后生还者》。

# # #独立
是“独立”的缩写。指小团队或个人在没有大型发行商资金支持的情况下开发的游戏。独立游戏通常强调创意和创新，而不是生产规模。

# # #α
在游戏开发的早期阶段，核心功能已经实现，但游戏还不完整，未经过润色，可能存在重大漏洞。Alpha版本用于内部测试和特性验证。# # #β
游戏功能完善但仍在测试和修复漏洞的后期开发阶段。Beta版本可能会发布给有限的受众进行外部测试（封闭测试）或向公众发布（开放测试）。

### Gold / Gone Gold
游戏被批准制作和发行的最终版本。“Going gold”意味着游戏已经完成并准备发布。

# # #构建
在特定的开发阶段，编译的、可运行的游戏版本。团队为测试和里程碑评审生成定期的构建。

# # #的里程碑
在开发时间轴上的预定检查点，必须完成特定的可交付成果。里程碑用于跟踪进度，通常与发行商的资金有关。# # #紧缩
加班一段时间的加班工作，通常发生在项目开发周期接近尾声时，以满足最后期限。紧缩是游戏行业中一个众所周知且经常受到批评的方面。

# # #事后
在项目完成后进行的回顾性分析，检查哪些是好的，哪些是错误的，以及为将来的项目吸取的经验教训。

垂直切片
一个经过优化的、可玩的游戏部分，展示所有学科（美术、设计、编程、音频）的最终质量目标。用于验证游戏愿景并获得资金。

游戏设计术语

游戏设计文件（GDD）
描述游戏概念、机制、故事、美术指导、技术要求和所有其他设计方面的综合性书面文件。作为整个团队的蓝图。游戏机制
定义游戏如何运作以及玩家如何与游戏互动的规则或系统。例子包括跳跃、射击、库存管理、制作和战斗系统。

玩法循环（核心循环）
玩家在游戏中重复的基本动作循环。设计良好的核心循环具有吸引力和奖励性。例如：探索，对抗敌人，收集战利品，升级角色，重复。

关卡设计
创造环境、挑战和玩家导航的空间布局的过程。关卡设计师放置几何图形、敌人、道具、触发器和脚本事件。

进程系统
追踪和奖励玩家进程的系统。包括经验点、技能树、可解锁的能力、装备升级和故事进程。# # #平衡
调整游戏参数（伤害值、生命池、资源成本、难度曲线）以确保公平、具有挑战性和令人愉快的游戏玩法的过程。

难度曲线
随着玩家的进程，游戏变得更具挑战性的速度。精心调整的难度曲线会逐渐引入复杂性，同时配合玩家不断增长的技能。

NPC（非玩家角色）
游戏中不受人类玩家控制的任何角色。npc可以是盟友、敌人、任务提供者、商人或环境背景角色。

HUD（平视显示器）
向玩家呈现游戏信息的屏幕覆盖，如生命条、小地图、弹药计数、分数和目标标记。

UI（用户界面）
所有与玩家互动的视觉元素，包括菜单、库存屏幕、设置面板、对话框和HUD。UX（用户体验）
玩家与游戏互动的整体质量，包括可用性、易用性、直观性和满意度。用户体验设计的重点是使游戏易于学习和玩起来有趣。

刷出/刷出
在特定地点和时间创造或放置游戏实体（游戏邦注：如玩家角色、敌人、道具）到游戏世界中的行为。

# # #重生
玩家角色或实体在被打败或摧毁后重新出现在游戏世界中的过程。

# # # Hitbox
一种附在游戏实体上的不可见的几何形状，用于碰撞检测，特别是用于确定攻击或投射物是否与目标相连。

# # #冷却时间
一种基于计时器的限制，它阻止玩家再次使用某种能力、道具或行动，直到一段特定的时间过去。### Buff / Debuff
对角色属性或能力的临时修改。buff可以增强能力（增加速度，伤害，防御），debuff则会降低能力（减慢移动速度，降低精度）。

# # #闹事
是“恶化”的缩写。指敌人对玩家的敌意程度。“吸引敌人”的意思是吸引敌人的注意力和攻击。

AoE （Area of Effect）
一种攻击、法术或能力，能影响限定区域内的所有实体，而不是单个目标。

DPS（每秒伤害）
衡量角色、武器或技能每秒造成的平均伤害的指标。用于平衡和比较战斗力。RNG（随机数生成）
在游戏机制中使用随机结果，如掉落战利品、暴击几率或程序生成。“RNG”也被通俗地用来指基于运气的结果。

### Proc（程序随机发生）
在游戏过程中由随机机会触发的事件，如基于概率百分比的武器命中激活的特殊效果。

### Meta / Metagame
在游戏竞争社区中最有效的策略、角色构建或战术。当玩家发现最佳方法时，元就会进化。

# # #削弱
降低角色、武器、能力或策略的力量或效力的游戏平衡改变。buff的反义词。# # #沙箱
一种游戏设计方法，允许玩家在没有严格线性进程的情况下自由探索并与游戏世界互动。强调玩家驱动的体验。

程序生成
游戏内容（关卡、地形、道具、任务）在运行时的算法创造，而不是手工创造。通过更少的手动内容创建，可以实现广泛，多样的游戏世界。

# # # Permadeath
一种游戏机制，角色的死亡是永久性的，没有重新加载或重生的选择。玩家必须重新开始，通常是用一个新角色。

Roguelike / Roguelite
以程序生成关卡、永久死亡、回合制或实时战斗为特征的游戏类型。roguelite是一种较轻的变体，可能允许在运行之间进行一些持续的进程。

编程和技术术语游戏引擎
核心软件框架提供了构建游戏的基础系统，包括渲染、物理、音频、输入、脚本和资产管理。例子：Unity，虚幻引擎，Godot，定制引擎。

渲染/渲染器
将游戏的视觉效果绘制到屏幕上的过程和系统。包括2D精灵渲染、3D多边形渲染、光照、阴影和后期处理效果。

帧率（FPS—帧/秒）
每秒渲染和显示的单个图像（帧）的数量。更高的帧率产生更流畅的动画。常见目标：30fps， 60fps, 120fps。

###滴答率
游戏服务器或模拟更新游戏状态的频率，单位为赫兹（Hz）。64-tick服务器每秒更新64次。### Delta时间
当前帧和前一帧之间经过的时间。用于确保游戏逻辑运行一致，无论帧率的变化。

物理引擎
一个模拟物理行为的系统，如重力、碰撞、刚体动力学、软体变形和布娃娃效应。例如：Box2D， Bullet, PhysX, Havok。

碰撞检测
确定两个或多个游戏对象何时相交或接触的过程。方法包括边界框（AABB）、球体、胶囊和基于网格的碰撞。

# # # Raycasting
一种从一个点向指定方向投射不可见光线的技术，以检测与游戏物体的交叉点。用于视线检查，子弹轨迹，鼠标拾取和能见度测试。# # #寻路
为ai控制的角色计算游戏世界导航路线的算法。常用的方法包括A* (A-star)、Dijkstra算法和导航网格（NavMesh）。

状态机（FSM—有限状态机）
一种编程模式，其中实体存在于一组已定义的状态之一，并使用规则管理状态之间的转换。广泛用于AI行为、动画系统和游戏流程管理。

# # #材质
在GPU上运行的程序，用于控制如何渲染顶点和像素。顶点着色器变换几何；片段（像素）着色器计算每个像素的颜色和光照。

LOD（细节层次）
一种通过切换低多边形模型、简单纹理或减少效果来降低远处物体视觉复杂性的技术。提高渲染性能。遮挡剔除
避免渲染隐藏在其他对象后面的对象的优化。如果一个对象完全从相机的视图中被遮挡，它将被排除在渲染管道之外。

截锥体剔除
从渲染计算中排除相机可见锥（视锥）之外的对象的优化。

### Draw Call
发送给GPU的命令，指示它渲染一组几何图形。通过批处理和实例化来减少draw调用是一个关键的优化策略。

# # #雪碧
游戏中使用的2D图像或动画精灵代表2D游戏中的角色、道具、效果和环境元素。

Sprite Sheet / Sprite Atlas
包含以网格或填充布局排列的多个精灵的单个图像文件。减少渲染过程中的绘制调用和纹理交换。# # # Tilemap
一种基于可重复使用的贴图网格构建2D游戏关卡的技术。每个单元格引用一个tileset中的tile类型，从而实现高效的关卡构建和呈现。

应用程序编程接口
用于构建软件和与软件交互的一组已定义的接口和协议。在游戏开发中，api包括图像api (OpenGL, DirectX, Vulkan, Metal)，音频api和平台api。

SDK（软件开发工具包）
为开发特定平台或框架的应用程序而提供的工具、库、文档和代码示例的集合。

# # #中间件
第三方软件库或工具集成到游戏引擎或管道中，以提供特定功能，如物理（Havok），音频（FMOD, Wwise）或动画。# # #序列化
将游戏对象、状态或数据结构转换成适合存储或传输的格式（JSON、二进制、XML）的过程。反序列化是相反的过程。

# # #延迟
一个动作被发起和它的结果被观察到之间的延迟。在网络中，延迟（ping）是数据在客户机和服务器之间传输的往返时间。

# # # Netcode
多人游戏的网络代码和体系结构，包括客户机-服务器通信、状态同步、延迟补偿和预测。

客户端-服务器架构
一种网络模型，其中中央服务器维护权威的游戏状态，客户端发送输入并接收状态更新。减少作弊并确保一致性。点对点（P2P）
一种网络模型，游戏客户端无需中央服务器直接相互通信。设置起来更简单，但更难防止作弊。

滞后补偿
多人游戏中用于减轻网络延迟影响的技术，如客户端预测、服务器协调和实体插值。

橡皮筋
在多人游戏中，由于客户端预测和服务器修正之间的不匹配，玩家或对象似乎会迅速回到之前的位置。

##艺术和视觉术语

# # #资产
游戏中使用的任何内容，包括3D模型、纹理、精灵、声音、音乐、动画、脚本和关卡数据。

# # #纹理
应用于3D模型表面或直接用于2D渲染的2D图像。纹理提供颜色、细节和材料外观。法线贴图
一种存储每像素表面方向数据的纹理，允许平面看起来有深度、凹凸和精细的细节，而不需要额外的几何形状。

# # #网
模型的三维几何结构，由顶点、边和面（多边形）定义。网格形成人物、物体和环境的形状。

###多边形/多边形
一种平坦的几何形状（通常是三角形），形成3D网格的构建块。“多边形数”指的是模型或场景中多边形的总数。

# # #索具
在3D模型中创建骨骼结构（电枢）的过程，以便它可以动画。骨骼被放置和加权以影响网格变形。

# # #剥皮
将3D网格绑定到其骨架上的过程，以便在骨架动画时网格自然变形。每个顶点加权到一个或多个骨骼。关键帧动画
一种动画技术，在特定的时间点（关键帧）定义姿势，系统在它们之间插入运动。

骷髅动画
动画驱动的分层骨结构。移动父骨骼将转换传播到子骨骼，从而实现真实的角色移动。

粒子系统
生成和管理大量小的视觉元素（粒子）来模拟火、烟、雨、火花、爆炸和魔法等效果的系统。

视差滚动
一种2D视觉技术，背景层相对于前景以不同的速度移动，产生深度错觉。

# # #体素
体积像素——3D网格上类似于2D网格上的像素的值。在像Minecraft这样的游戏中用于基于块的世界构建和medical/scientific可视化。# # #抗锯齿
一种沿多边形和高对比度边界平滑锯齿状边缘（混叠）的渲染技术。方法包括MSAA、FXAA和TAA。

# # #后处理
在主场景渲染完成后应用于渲染帧的视觉效果。例子包括绽放，运动模糊，景深，颜色分级和环境遮挡。

##音频条款

SFX（音效）
由游戏内事件（如脚步、武器射击、拾取物品、UI交互和环境声音）触发的短音频剪辑。

BGM（背景音乐）
在游戏玩法、过场动画或菜单中播放的音乐原声。BGM设定了游戏的情绪并强化了游戏的情感基调。自适应音频/动态音乐
根据游戏事件、玩家动作或游戏状态而改变的音乐和声音。例如，战斗音乐会随着更多敌人的出现而加强。

### FMOD / Wwise
行业标准音频中间件工具，用于在游戏中执行复杂的声音设计、混音和自适应音频。

空间音频/ 3D音频
模拟声源在3D空间中的位置和移动的音频处理，为玩家提供方向线索。

平台和分销条款

# # #平台
游戏运行的硬件或软件环境：PC、PlayStation、Xbox、任天堂Switch、手机（iOS/Android）、网页浏览器、VR头显。

# # #跨平台
游戏在多个平台上运行的能力，以及不同平台的玩家一起玩游戏的能力（跨平台）。###端口/移植
将针对一个平台开发的游戏调整到不同平台上运行的过程。可能需要针对不同的硬件功能进行重大的技术返工。

DLC（可下载内容）
额外的游戏内容发布后，首次推出，可供下载。可能包括新的关卡、角色、故事章节、道具或化妆品。

# # # Microtransaction
一种小的游戏内购买，通常用于购买化妆道具、虚拟货币或玩法优势。这是免费游戏中常见的盈利模式。

免费模式（F2P）
一种商业模式，即基础游戏可以免费下载和体验，并通过可选的游戏内置购买获得收益。

游戏即服务（GaaS）
一种游戏随着时间的推移不断更新新内容、事件和功能的模式，通常由订阅或微交易的经常性收入支持。###抢先体验
一种发行模式，即玩家可以在游戏仍处于积极开发阶段时购买并体验游戏，并向开发者提供反馈和资金。

第一天补丁
在正式发行当天或之前发布的游戏更新，以修复漏洞，提高性能或添加物理副本制作时未准备好的内容。

QA（质量保证）
对游戏进行系统测试，以识别漏洞、小故障、性能问题和设计问题。QA测试人员在各种条件下反复玩游戏以确保质量。

# # #错误
游戏代码、设计或内容中的错误、缺陷或意外行为。漏洞的范围从轻微的视觉故障到游戏崩溃。

# # #利用
无意中使用游戏机制或漏洞，给予玩家不公平的优势。漏洞一旦被发现，通常会打补丁。# # #补丁
为修复漏洞、解决漏洞、提高性能、调整平衡或为之前发布的游戏添加新内容而发布的软件更新。

# # #热修复补丁
紧急发布的一种小的、有针对性的补丁，用于修复关键错误或问题，通常在没有常规补丁的完整测试周期的情况下部署。

游戏类型术语

FPS（第一人称射击游戏）
一种玩家以第一人称视角体验游戏并主要参与远程战斗的游戏类型。

第三人称射击游戏
在射击游戏中，镜头位于玩家角色身后或肩膀上方。

RPG（角色扮演游戏）
在这种类型中，玩家扮演一个角色，做出决定，并随着时间的推移通过叙述和战斗发展自己的属性和能力。MMORPG（大型多人在线角色扮演游戏）
大量玩家同时居住在一个持久的在线世界的RPG。

即时战略游戏
这是一款策略游戏，玩家可以实时管理资源、建造建筑和指挥单位，而不是轮流操作。

MOBA（多人在线竞技游戏）
这是一种基于团队的竞争类型，玩家控制具有独特能力的个体角色，共同努力摧毁对方团队的基地。

大逃杀
在这种游戏类型中，大量玩家竞相成为一个不断缩小的游戏区域中的最后一个玩家。

# # # Metroidvania
一种动作冒险游戏的子类型，其特点是相互关联的地图，能力限制的探索，以及使用新获得的能力回溯到以前无法进入的区域。# # # Soulslike
受《黑暗之魂》系列启发的游戏，其特点是具有挑战性的战斗、基于耐力的机制、极少的手把手操作以及强调从失败中学习。
