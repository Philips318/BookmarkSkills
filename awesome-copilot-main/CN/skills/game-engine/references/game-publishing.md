#游戏发行

这篇文章涵盖了发行网页游戏的三大支柱：分销渠道和平台、推广策略和盈利模式。

##游戏推广

游戏推广包括玩家发现和访问游戏的渠道和平台。选择正确的发行策略取决于你的目标用户、游戏类型和商业目标。

###网络商店

**Chrome Web Store:**

-需要一个manifest文件和一个包含游戏资源的压缩包。
-需要最小的游戏修改。
-简单的网上提交表格。

原生手机商店

**iOS App Store:**

-要求严格，审批等待时间为1-2周。
-与成千上万的应用程序极具竞争力。
-一般喜欢付费游戏。
-最突出的手机商店，但最难脱颖而出。

**谷歌Play (Android):**

—要求没有iOS严格。
-每日提交量高。
-首选免费增值模式（带有应用内购买或广告的免费下载）。
大多数付费iOS游戏在Android上都是免费模式。**其他移动平台（Windows Phone， BlackBerry等）：**

-竞争更少，更容易获得知名度。
-较小的市场份额，但不那么拥挤。

平台策略

**移动设备优先：**移动设备占HTML5游戏流量的绝大部分。设计可以用一根或两根手指拿着设备玩的游戏。
- **桌面开发：**在调试移动设备之前，先在桌面上构建和测试。
- **多平台：**支持桌面，即使主要针对移动设备。HTML5游戏具有一次编写，随处部署的优势。
- **多样化：**不要依赖单一商店。分散在多个平台以降低风险。
**即时更新：**网络推广的一个关键优势是，无需等待应用商店批准就能快速修复漏洞。

##游戏推广游戏推广需要一个持续的多渠道策略。大多数推广方法都是免费的，这使得预算有限的独立开发者也可以使用。曝光度和游戏质量一样重要——即使是优秀的游戏，如果没有推广也会失败。

网站和博客

**基本的网站组件：**

-截图和游戏预告片。
-详细说明和可下载的新闻包（使用Presskit（）等工具）。
—系统要求和可用平台。
—支持和联系方式。
-一个可玩的演示，至少基于浏览器。
-搜索引擎优化的可发现性。

* *博客策略:* *

记录开发过程、遇到的bug和经验教训。
-每月发布进度报告。
-随着时间的推移，持续的内容创造可以提高SEO排名。
-建立信誉和社区声誉。

###社交媒体-在Twitter/X.等平台上使用`#gamedev`标签进行社区参与
-保持真实，避免强势广告或枯燥的新闻稿。
-分享开发技巧，行业见解和幕后内容。
-监控可能会报道你游戏的YouTube和Twitch主播。
-参与HTML5GameDevs.com等论坛。
-真诚地参与社区活动。回答问题，给予支持，避免不断的自我推销。
-提供折扣和竞赛奖品来建立良好的信誉。

###媒体宣传-调查那些专门报道你的游戏类型和平台的媒体。
-在联系记者和审稿人时保持谦虚、礼貌和耐心。
-避免大量不相关的提交。仔细定位你的推广目标。
-高质量的游戏与诚实的方法相结合会产生最佳的成功率。
-参考指南，如“如何联系媒体”从像素勘探者详细的策略。

-强制性主题激发创意，推动创新。
-获胜会带来主办方的自动推广和社区的关注。
-非常适合发布早期演示和建立声誉。

教程和教育内容-记录并教授你在游戏中所执行的内容。
-在文章和教程中使用你的游戏作为实际案例研究。
-在Tuts+ Game Development等平台上发布内容，这些平台通常会为内容付费。
-专注于单个方面的细节，为读者提供真正的价值。
-双重好处：推广你的游戏，同时树立你作为一个知识渊博的开发者的形象。

# # #事件

* *会议:* *

-就你在开发过程中克服的挑战进行技术演讲。
-用你的游戏作为一个真实的例子来演示API实现。
-注重知识共享，而不是营销。开发商对强势的推销尤其敏感。

**展览会：**-确保在其他开发者中有一个展位，以便与粉丝直接互动。
-以独特、原创的演讲脱颖而出。
-提供实际用户测试和即时反馈。
-帮助发现bug和问题，玩家发现有机。

##游戏盈利

盈利策略应该与你的游戏类型、目标用户和发行平台保持一致。多样化的收入来源提供了更好的业务稳定性。

付费游戏

**模式：**固定，在玩家获得访问权限之前收取前期费用。-需要大量的营销投资来推动购买。
-价格因市场和质量而异：街机iOS游戏约0.99美元，Steam上的桌面rpg约20美元。
-成功取决于游戏质量、市场调查和营销效果。
-研究市场趋势，从失败中快速学习。

应用内购买（iap）

**模式：**免费游戏获取与付费可选内容和功能。

**可购买内容类型：**

-奖励等级
-更好的武器或法术
-能量补充
-游戏内货币
-高级功能和虚拟商品

**关键指标和考虑因素

-需要数千次下载才能产生可观的收益。
-只有大约1 / 1000的玩家会购买游戏。
收益很大程度上取决于推广活动和玩家数量。
-玩家数量是成功的关键因素。

# # #免费商业模式**模式：**免费游戏与可选的高级功能和付费福利。

-增加游戏的价值，而不是将核心内容限制在付费墙后面。
-避免玩家不喜欢的“付费获胜”机制，这会损害留存率和声誉。
-不要付费墙游戏进程。
-首先专注于提供愉快的免费体验，然后提供高级增强功能。

**插件和dlc:**

-新的关卡设置，新的角色，武器和故事内容。
-需要一个已被证实受欢迎的基础游戏。
-为现有的玩家提供额外的价值。

# # #广告

**模式：**通过广告展示获得被动收益，开发商与广告网络分享收益。

* *广告网络:* *** b谷歌AdSense:**最有效，但不是游戏优化。这对游戏相关账户来说是有风险的。
- **LeadBolt:**以游戏为重点的替代方案，更容易实现。
- **视频广告：**在加载屏幕期间显示的预卷格式越来越受欢迎。

* *放置策略:* *

-在游戏期间或游戏结束屏幕上显示广告。
-平衡广告可见度与玩家体验。
保持广告的微妙性，避免惹恼玩家，损害用户留存率。
-低流量游戏的收益通常非常有限。

**收益分成：**通常70/30或50/50与发行商分成。

# # #许可

**模式：**一次性支付经销权。发行商负责盈利。

* *独家许可证:* *-只卖给一个出版商。
-交易后不能再以任何形式出售。
-价格范围：$2,000至$5,000美元。
-只有在交易利润足以证明排他性的情况下才会继续进行。在销售后停止推广游戏。

* *非排他性许可:* *

-可以同时出售给多个出版商。
发布者只能在他们自己的门户上发布（站点锁定）。
-价格范围：每个发行商大约500美元。
-最流行的授权方式。与多家发行商持续合作。

* *订阅模式:* *

-每场游戏的月被动收益。
-价格范围：每款游戏每月20 - 50美元。
-灵活的付款方式：一次性付款或按月付款。
-风险：发行商可以随时取消。

**广告收入分成：**-发行商驱动流量，收益分成。
-拆分：70/30或50/50交易，每月收集。
-警告：新的或低质量的出版商可能只提供2美元的总额。

**重要的授权说明：**

-发行商可能需要定制API实现（将开发成本考虑到定价中）。
-最好接受知名发行商较低的授权费用，而不是冒着被未知买家欺骗的风险。
-通过发行商的网站或HTML5 Gamedevs论坛联系他们。

品牌和定制工作

**带有品牌的非独家授权：**

-客户端购买代码权和实现自己的图形。
—例如：将游戏食物道具换成客户品牌产品。

* *自由品牌:* *-开发者重用现有的游戏代码并添加客户端提供的图形。
-客户指导实现细节。
-根据品牌、客户期望和工作范围，价格差异很大。

其他盈利策略

**出售数字资产：**

-在Envato Market和ThemeForest等平台上销售游戏图像和艺术资产。
-最适合图形设计师谁可以创建可重用的资产。
-提供被动、适度但稳定的收入。

**撰写文章和教程：**

-在Tuts+ game development等平台上发布游戏开发文章，这些平台为内容付费。
-双重效益：促进你的游戏，同时产生直接收入。
-专注于真正的知识分享与你的游戏作为实际的例子。

* *商品:* *- t恤、贴纸和品牌小玩意。
-高人气、视觉辨识度高的游戏（如《愤怒的小鸟》）最赚钱。
-有些开发商从商品中赚的钱比游戏本身赚的钱还多。
-最好作为一个多元化的二级收入来源。

* *社区捐赠:* *

在游戏页面添加捐赠按钮
-有效性取决于你的社区关系的强度。
-当玩家了解你个人并理解捐赠如何帮助继续发展时效果最好。

盈利总结

|模型|收益类型|最适合|风险等级||-------|-------------|----------|------------|
|付费游戏|一次性|高质量游戏，营销力度强|高|
|应用内购买|每笔交易|高下载量的热门游戏|中等|
|广告|Passive/CPM|休闲、上瘾游戏|中低|
|非独家授权|一次性（约500美元）|所有游戏类型|低|
|独家授权|一次性（2K- 5000美元）|经过验证的高质量游戏|中等|
|订阅|每月被动|有记录的游戏|中等|
|商品|每销售|具有视觉识别的热门特许经营|高|
|Articles/Tutorials|每篇文章|具有专业知识的开发人员| Low |
