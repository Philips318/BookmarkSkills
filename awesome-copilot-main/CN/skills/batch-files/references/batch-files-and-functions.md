批处理文件、脚本和函数

##实用程序脚本

**运行脚本** -使用。CMD扩展名（优先于。bat）。在记事本中编辑，从命令提示符运行或双击。在批处理文件之间使用`CALL`。使用`%CmdCmdLine%`检测启动模式。在CMD:`powershell.exe -command "& {script}"`中运行PowerShell。执行VBScript:`cscript //nologo script.vbs`。

**横幅** -显示文本在大ASCII艺术字母使用SET命令。构建7行字符，每个字母（a-z, 0-9，空格，破折号，句点）具有可变赋值。回显每一行以组成横幅输出。

**Elevate/UAC** -以更高的权限运行。方法：(1)使用快捷方式“以管理员身份运行”复选框，(2)使用命令行VBScript/PowerShell标高，(3)使用`FSUTIL`或`CACLS`测试标高。无标高运行：`SET __COMPAT_LAYER=RunAsInvoker`。修复提升后的当前目录：`pushd "%~dp0"`。

日期和时间**DateMath** -Add/subtract天从任何日期使用儒略历日数计算。正确处理Y2K。支持日期减法（天数差）和日期+天数算术。使用`SETLOCAL`/`ENDLOCAL`可变回传技术。

**GetDate** -获取独立于语言环境的当前日期。方法：(1)PowerShell`get-date -format`, (2) Robocopy时间戳解析（最常见），(3)`date /t`解析，(4)DOFF.exe, (5) VBScript。Robocopy方法创建一个临时文件夹，并从`ROBOCOPY /njh /njs`解析时间戳。

**GetTime** -返回当前时间到一个变量。通过动态检测分隔符来处理任何区域时间分隔符。确保领先零小时的一致格式。

使用`WMIC Win32_LocalTime`和`Win32_UTCTime`计算格林威治标准时间。注意：WMIC在Win10 21H1中已弃用。PowerShell替代品：`(Get-Date).ToUniversalTime()`。**TimeDiff** -计算两个时间值之间的差值。处理午夜翻转。返回HH: MM: ss。hs格式。将时间转换为百分之一秒的算术时间码。

**计时器** -使用临时戳文件测量Start/Stop/Lap模式的运行时间。计算小时:分钟:seconds.hundredths。处理区域时间设置。

字符串和文件处理

**DeQuote** -从字符串中删除引号。最简单的：`%~1`参数扩展。一行:`Set "var=%var:"=%"`。函数方法：`FOR /F`with`%%~A`。可以检测匹配与不匹配的引号。

**空** -检查目录是否为空：`FOR /F %%A in ('dir /b /a "%folder%"') do goto NotEmpty`。可选择使用`dir /A:-D /B`进行仅文件检查。子目录不是递归的。

**GenChr** -生成任意ASCII/Unicode字符（0-255）作为。CHR文件使用`MAKECAB`与`reserveperfoldersize`技巧。使用`CHCP`处理代码页切换。**StampMe** -使用Robocopy时间戳解析重命名带有date/time戳的文件。输出格式：`filename-YYYY-MM-DD@HH-MM-SS.ext`。支持拖放（将文件名传递为%1）。

**StrLen** -计算字符串长度使用二进制搜索与`FOR`循环测试位置4096,2048,1024…O（log n）的性能。通过变量或echo返回长度。

** ** -将字符串转换为upper/lower大小写。方法1:`CALL SET`逐个字母替换（处理umlauts/international字符）。方法2：使用不区分大小写的`SET`替换更简单的`FOR`循环。

##文件系统

**DelOlder** -删除超过n天的文件。方法：(1)`ForFiles /d -7`, (2)`Robocopy /move /minage:7`, (3)DateMath.cmd与Julian Day比较，(4)PowerShell`.AddDays(-7)`。

**IsDirectory** -使用`%~a1`属性展开检查路径是文件还是目录。检查`d`的第一个字符：`Set "_attr=%~a1" & If "%_attr:~0,1%"=="d" (echo Directory)`。如果未找到则抛出ERRORLEVEL 1。**Whereis** -显示任何可执行文件的完整路径。首先测试内部命令，然后搜索PATH+PATHEXT。处理带空格的引用路径。通过变量或echo返回结果。

**xlong** -列出超过MAX_PATH（260字符）的文件。在位置256处使用`DIR /b /s`和子字符串检查：`If not "!name:~256,1!"=="" echo Extra long name: "%%a"`。PowerShell单行替代方案：`cmd /c dir /s /b | where-object{$_.length -gt 256}`。

##系统和配置

**ANSI颜色** -在Windows 1909+中默认可用。前景：`Esc[30m`（黑色）到`Esc[97m`（白色）。背景：`Esc[40m`到`Esc[107m`。格式：`Esc[1m`（粗体），`Esc[4m`（下划线），`Esc[7m`（反向）。重置:`Esc[0m`。保存ESC到变量：`for /f %%a in ('echo prompt $E^| cmd') do set "ESC=%%a"`。在Win10中支持24位RGB。在旧的Win10上通过注册表启用：`[HKCU\Console] VirtualTerminalLevel=dword:1`。**Autoexec和AutoRun** -Autoexec.bat：传统的MS-DOS；在Windows下，在引导时只解析`C:\autoexec.bat`中的SET语句。自动运行命令：设置`HKCU\Software\Microsoft\Command Processor\AutoRun`或`HKLM`等于在CMD打开时运行命令（对DOSKEY宏有用）。启动位置：`%appdata%\Microsoft\Windows\Start Menu\Programs\Startup\`，`HKCU\...\Run`,`HKLM\...\Run`。机器启动：使用任务调度程序与“当我的计算机启动”。禁用自动运行驱动器：`NoDriveTypeAutoRun`注册表项；使用`iniFileMapping`方法完全禁用。

**CMD Shell** -暂停与Ctrl+S，取消与Ctrl+C。默认情况下启用选项卡自动完成。命令历史记录：F7（列表）、F8（搜索）、F9（按数字）。报价处理：CMD在特定条件下剥离leading/trailing报价；使用双引号`""`来保存。最大命令行：8191个字符。最大路径：260个字符。允许UNC路径：`[HKLM\...\Command Processor] DisableUNCCheck=dword:1`。CMD vs . bat：。CMD在每个命令后重置ERRORLEVEL；. bat只适用于错误。`%COMSPEC%`显示正在运行哪个shell。**内部命令** -命令内置到CMD.exe（不需要外部。exe）： ASSOC， BREAK， CALL， CD， CLS， COLOR， COPY， DATE， DEL， DIR， DPATH， ECHO， ENDLOCAL， ERASE， EXIT， FOR， FTYPE， GOTO， IF， KEYS， MD， MKLINK， MOVE， PATH， PAUSE， POPD， PROMPT， PUSHD， REM， REN， RD， SET， SETLOCAL， SHIFT， START， TIME， TITLE， TYPE， VER， VERIFY， VOL.外部命令存储在`C:\WINDOWS\System32`。参数可以传递给内部命令；参数前的空格可以在命令行中省略，但在脚本中包含。

**应用程序兼容性** -设置通过注册表在`HKCU\Software\Microsoft\Windows NT\CurrentVersion\AppCompatFlags\Layers`（每用户）或`HKLM`（所有用户）。语法:`~ [PrivilegeLevel] [Settings] [CompatibilityMode]`。特权:`RUNASADMIN`。设置：`256COLOR`、`16BITCOLOR`、`640X480`、`HIGHDPIAWARE`、`DPIUNAWARE`、`GDIDPISCALING DPIUNAWARE`、`DISABLEDXMAXIMIZEDWINDOWEDMODE`。型号：`WIN95`、`WIN98`、`WINXPSP2`、`WINXPSP3`、`VISTARTM`、`VISTASP1`、`VISTASP2`、`WIN7RTM`、`WIN8RTM`。例子:`REG ADD "HKCU\...\AppCompatFlags\Layers" /V "%ProgramFiles%\app\app.exe" /T REG_SZ /D "~ RUNASADMIN WINXPSP2" /F`。**错误级别和退出代码** -大多数命令返回0表示成功。最大量程：±2147483647。检测方法：(1)`IF ERRORLEVEL n`(legacy，表示>= n), (2)`IF %ERRORLEVEL% EQU 0`（首选）。在循环内部，使用`&&`/`||`条件运算符或为`!ERRORLEVEL!`启用delayeexpand。不影响ERRORLEVEL的命令：BREAK、ECHO、ENDLOCAL、FOR、IF、PAUSE、REM、RD、TITLE。强制错误级别1:`(CALL)`。重置为0:`(call )`。永远不要使用`SET ERRORLEVEL=...`（创建用户变量，使伪变量的影子变得模糊）。CMD脚本在每个内部命令后重置ERRORLEVEL；. bat只在出错时使用脚本。**错误处理** -success/failure的条件运算符分支：`SomeCommand && (echo success) || (echo failed)`。Gotcha：如果成功分支中的最后一个命令错误，则失败分支触发；用`(call )`结束成功块。具体错误：`IF %ERRORLEVEL% NEQ 0 (Echo Error &Exit /b 1)`。即使失败，DEL也返回0；Robocopy成功时返回非零。对于计划任务，使用错误代码退出将记录为失败的任务。

**显示DPI** - DPI =√（W²+ H²）/屏幕尺寸。Win10设置：设置>显示>缩放和布局（100-500%）。终端服务器上通过注册表的每个用户DPI。不要设置DPI低于96（字体中断）。Citrix：每用户DPI仅通过96/120/144DPI的注册表项。**OOBE** -安装Windows 11没有internet/Microsoft帐户。Win11 25H2:`start ms-cxh:localonly`从Shift+F10 CMD提示设置期间。早期Win11:`OOBE\BYPASSNRO`（重新启动“我没有互联网”选项）。手动方法：通过regedit添加`HKLM\...\OOBE BypassNRO=dword:1`。自定义用户文件夹名称（25H2）：在安装时Shift+F10，`cd oobe`，运行`SetDefaultUserFolder.cmd`，输入名称（最多16个字符）。

**恢复环境** -WinRE/SafeMode/WinPE.安全模式：按住Shift + Power >重启，然后排除>启动设置> F4（安全）或F5（安全+网络）。WinRE：重复上电循环（保持上电10s， 3次）。WinPE：从USB引导，自动运行wpeinit。WinPE驱动器检测脚本：循环通过驱动器字母a - z检查是否存在已知文件。从恢复中创建管理帐户：重命名utilman.exe，复制CMD .exe，重新启动，在登录时单击易于访问以获得CMD，`NET user demo-user password1 /add`然后`NET localgroup administrators demo-user /add`。**64位检测** -检测64位操作系统：`IF %PROCESSOR_ARCHITECTURE%==x86 (IF NOT DEFINED PROCESSOR_ARCHITEW6432 Set _os=32)`。在64位上检测32位进程：检查是否定义了`PROCESSOR_ARCHITEW6432`。系统文件夹：32位会话将System32视为32位，SysNative视为64位；64位会话将System32视为64位，SysWOW64视为32位。重新启动为64位：`%SystemRoot%\Sysnative\cmd.exe /C "%~f0" %*`。执行32位命令：`%SystemRoot%\SysWoW64\cmd.exe`。环境：`%ProgramFiles%`= 64位程序，`%ProgramFiles(x86)%`= 32位程序。

网络和安全

**慢的网络浏览** -Desktop.ini解析减慢文件夹列表；检查文件服务器上的`NET FILE | Find "desktop.ini"`。修复：删除非必要的desktop.ini文件或删除READ_ONLY权限。损坏的配置文件权限：从另一个管理帐户重命名`C:\Users\<profile>\AppData\Local\Microsoft\Windows`。当资源不可用时，Desktop/Start菜单上的网络快捷方式导致刷新缓慢；使用`explorer /e, \\Server\Share`快捷键代替。**LAN Manager Authentication** -通过`HKLM\SYSTEM\CurrentControlSet\Control\LSA\LMCompatibilityLevel`控制NTLM认证级别0-5。在Win11 24H2和Server 2025中删除了NTLMv1。当前操作系统默认级别为3。Level 0-1：发送LM+NTLM。Level 2：只发送NTLM。Level 3+：只发送NTLMv2。DC上4-5级：拒绝NTLMv1/LM响应。在服务器上增加超过3会锁定旧客户端。

**登录类型** -事件ID 4624类型：3=网络（远程file/printer访问，凭据未缓存），4=批处理（计划任务，凭据命中磁盘），5=服务（服务帐户，凭据在LSA秘密），7=解锁，8=网络明文（IIS基本认证），9=新凭据（RunAs /netonly）， 10=远程交互（RDP，凭据在lsass）， 11=缓存交互（离线域登录，mscache2格式）。**文件共享组织** -拆分文件夹共享：每个团队两个驱动器映射- S:（共享，对其他团队可见）和T:（仅限团队，通过基于访问的枚举隐藏）。ABE隐藏用户无法访问的文件夹；在几千股范围内运行良好，但在几万股范围内就会退化。每个团队使用两个AD组：一个用于T：驱动器，一个用于S：驱动器访问。主文件夹映射到H:（列表顶部）或U:（底部）。默认子文件夹帮助用户组织：管理、文档、会议、项目、资源、模板。**文件共享模式**—当文件为creating/opening时，选择FILE_SHARE_READ、FILE_SHARE_WRITE、both或neither。两个进程必须具有兼容的共享模式。GENERIC_READ + FILE_SHARE_READ：与任何具有FILE_SHARE_READ的READ进程共享。GENERIC_WRITE + FILE_SHARE_WRITE：与所有具有FILE_SHARE_WRITE的WRITE进程共享。不兼容模式=文件被第一个进程锁定。

**NoDrives** -隐藏驱动器号在资源管理器通过注册DWORD在`HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer\NoDrives`。位掩码值：A=1， B=2， C=4， D=8…Z = 33554432 = 67108863。隐藏的驱动器仍然可以通过在地址栏中键入字母访问。需要logoff/reboot.隐藏磁盘空间颜色条：编辑`HKLM\Software\Classes\Drive\TileInfo`并删除`System.PercentFull;`。**内置组和特殊身份** -关键组：管理员（无限制访问），域管理员（管理域），企业管理员（森林范围内的更改），帐户操作员（有限的帐户创建），备份操作员（backup/restore所有文件），服务器操作员（服务，共享，dc关闭）。特殊身份（隐式）：每个人、认证用户、交互、网络、批处理、服务、创建者所有者、匿名登录。受保护用户组提供额外的凭据保护。KRBTGT为KDC服务帐号。LocalSystem具有完全的系统访问权限。LocalService和NetworkService以有限的权限运行。**Active Directory组** -安全组：控制资源访问。通讯组：仅限电子邮件列表。作用域：全局（以域为中心，嵌套用户）、域本地（分配资源权限）、通用（简单、通用、复制到全局目录）、本地（sam存储、单机）。最佳实践：用户在全局组中，嵌套在域本地组中以获得权限（AGDLP）。单域：全局组可以嵌套其他全局组；资源的“域本地”可以防止错误的权限继承。在登录更改时评估组成员资格需要重新身份验证。命名：使用字母数字、破折号、下划线；为了清楚起见，前面加上G或T。**注册表调整(Win11)** -启动：禁用锁定屏幕`NoLockScreen=1`，详细登录`verbosestatus=1`。浏览器：win10风格的上下文菜单（添加`InprocServer32`键），默认为“此PC”`LaunchTo=1`，禁用Thumbs.db`DisableThumbnailCache=1`，显示隐藏文件`Hidden=1`，显示文件扩展名`HideFileExt=0`。开始菜单：向左移动`TaskbarAl=0`，移除必应搜索`BingSearchEnabled=0`，加速`MenuShowDelay=250`。控制面板：允许appearance/display/screensaver更改，设置锁屏壁纸。遥测：关闭Copilot/Recall`TurnOffWindowsCopilot=1`，关闭诊断`AllowTelemetry=0`。更新：自动下载+时间表`AUOptions=4`，只通知`AUOptions=2`，禁用`AUOptions=1`。

输入验证和安全性**防止代码插入漏洞** -批处理文件是“弱类型”：一切都是字符串，字符串可以是命令，没有办法区分数据和代码。`%CD%`漏洞：当使用不加引号的`%CD%`时，文件夹名称中的&号会导致代码执行。解决方案：双引号`"%CD%"`（安全，因为路径不能包含双引号）。对于可以包含双引号的变量，引号不能解决问题。测试未加引号的`%CD%`批处理文件：`TYPE "%%~A" | FIND /I /N "%%CD" | FINDSTR /R /I /C:"[^""]%%CD[:%%]"`。替代方案：使用`"%CD%"`，使用`.`或`.\`代替`%CD%`，终止&号：`CD | FIND "&" && EXIT /B 1`。**命令行输入验证** -不存在万无一失的命令行验证。最佳方法：`ECHO "%~1"| FIND /I "TEST"`（方法7，得分6/7）或`ECHO "%~1"| FINDSTR /L /X /I """TEST"""`（方法13，得分6.5/7）。缺点：“引号内”——不终止的双引号加上&号可以插入代码。`%1`vs`%~1`：波浪线环绕引号。演示：传递`test1"&test2=`显示通过不匹配的引号插入代码。

**条件中的布尔逻辑** -没有AND/OR/XOR的`IF`条件（只有二进制数学通过`SET /A`）。AND：嵌套的`IF`语句。OR：将临时变量设置为0，每个匹配条件设置为1，然后测试。异或：嵌套IF太复杂。更好的方法是：将每个条件分配给一个二进制变量（0或1），然后使用`SET /A "ResultAND = %C1% & %C2%"`、`SET /A "ResultOR = %C1% | %C2%"`、`SET /A "ResultXOR = %C1% ^ %C2%"`。
