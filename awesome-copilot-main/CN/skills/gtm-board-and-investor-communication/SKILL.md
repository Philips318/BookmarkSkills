#董事会与投资者沟通

组织董事会会议、投资者更新和高管沟通，建立信任并推动决策，而不是没有人看的幻灯片。

##何时使用

* *触发:* *
-“我该如何准备董事会会议？”
-“我们的投资者更新应该包含哪些内容？”
-“我们错过了我们的数字，我们该如何沟通？”
-“甲板结构”
-“我们应该多久向投资者汇报一次情况？”
-“我们的董事会没有成效”

* *背景:* *
-为处于成长期的公司提供种子
-董事会会议的准备和跟进
-Monthly/quarterly投资者更新
-处理失误和坏消息
-从董事会到组织的级联策略

---

核心框架

# # # 1。先讲故事，再展示数据

* *的模式:* *大多数董事会会议都是以数据转储开始的。一张接一张的指标幻灯片，然后是10分钟的问答时间，董事会成员试图弄清楚这一切意味着什么。

翻转。叙事应该起到引导作用；数据应该得到确认。

**工作原理：**

打开你在旅途中的位置。不是“这是我们的ARR”，而是“这是我们在本季度的预期，我们学到的东西，以及我们现在的位置。”然后展示验证叙述的数据。

**董事会结构：**

**预读（48-72小时前发送）**
-财务仪表盘（预收、燃烧、跑道、管道）
-带有运行状况指标的度量计分卡（green/yellow/red）
- 2-3页的叙述性总结，涵盖市场背景和战略更新
-规则：如果可以阅读，就不要呈现

**会议（90-120分钟）**1. **市场背景及预读问题**（15分钟）
-自上次会议以来，市场发生了什么变化？
-董事会询问预读中不清楚的内容
-禁止重表示数据

2. **CEO战略更新-“三件事”**（15分钟）
- **什么在起作用**（2-3个有发展势头的领域）
**什么不是**（1-2个具体的空白，不是模糊的）
**我们正在做什么**（具体的改变，不是承诺）
-这是叙述，而不是数字

3. **决策项目**（30-45分钟）
- 1-3个需要董事会输入或批准的主题
-准备好：“我们在X和Y之间做出决定，董事会的想法？”
带着决定离开，而不是“我们下个季度再来”4. **深潜**（20-30分钟）
-深入探讨一个主题（每次会议轮换）
-带上拥有它的职能领导
-例子：定价策略，竞争格局，组织设计，市场拓展

5. **闭幕**（10分钟）
-总结所做的决定和行动
-闭门会议（无管理层的董事会）
-首席执行官和董事会主席汇报

* *常见错误:* *

-在叙述之前先用数据开场（游戏邦注：在没有背景的情况下，玩家会迷失在数字中）
-多个相互竞争的叙述（董事会无法综合-选择一个弧）
-试图深入讨论太多话题（导致对所有事情都匆忙做出决定）
-不允许深潜（冲浪板变成橡皮图章）
-让会议充满好消息（董事会不相信只分享成果的ceo）

# # # 2。“三件事”叙事模式

* *的模式:* *商业太复杂了，无法用一个标题概括。三个不同的点——什么是有效的，什么是无效的，什么是变化的——让董事会在几分钟内掌握现状和轨迹。

**工作原理（2-3个区域）：**
要具体。不是“销售进展顺利”，而是“完成了第一笔六位数的企业交易，证实了商业动议。”量化势头:
-新产品推出获得采用
-销售动作成熟（第一个大客户，可重复动作出现）
-Community/ecosystem里程碑

**什么不工作（1-2个领域）：**
同样具体。不是“我们遇到了一些挑战”，而是“自助服务的转化率很弱——意识很强，但转化率只有0.1%。”董事会需要了解实际问题，而不是委婉的说法。

**我们正在做的事情（对于每个“不工作”）：**
明确具体的变化。什么产品发生了变化？组织发生了什么变化？时间是什么？投入了哪些资源？**为何有效：**

董事会成员阅读了数十条更新信息。“三件事”模型为他们提供了一个心理归档系统：动力（感觉良好）、风险（关注）、代理（团队处理问题）。没有它，董事会要么过度关注一个错误的指标，要么错过了隐藏在40张幻灯片中的真正问题。

# # # 3。进步是有方向的，不是绝对的

* *的模式:* *

如果你的目标是5万用户，或者你错过了20万用户，那么你是否获得了10万用户并不重要。环境决定一切。展示你朝着目标取得的进展，而不仅仅是数字。

**如何构建进度：**- **正在进行中：**“目标是10万活跃开发者。目前70 k。所有的计划按计划执行。信心:高”。
- **有风险：**“目标是10万活跃开发者。目前50 k。收购成本高于预期。测试新渠道。调整目标：85K。信心:媒介。”
- **未来：**“目标是10万活跃开发者。目前95 k。超出收购预期。新的伙伴关系加速增长。信心：非常高。”

* *规则:* *
1. 预先设定目标（每个指标都需要一个目标）
2. 用实现目标的百分比来显示进度，而不仅仅是绝对数字
3. 承认失误;解释轴心
4. 基于轨迹的状态置信水平

* *常见的错误:* *当你错过目标时，改变目标。董事会跟踪这一点。如果第一季度的目标是10万，而你达到了6万，不要把第二季度的目标定为75万，并称之为“修订后的指导”。陈述想念，解释原因，展示恢复计划。可信度比指标更快。

# # # 4。四层度量体系

* *的模式:* *

太多的指标让董事会感到困惑。错过重要信号的太少了。将你的指标分为四个层次，不要每个季度都改变。

**一级：北极星（1米制）**
最能代表公司健康状况的单一指标。
-示例：ARR，活跃用户，完成的任务
-显示趋势线，而不仅仅是当前状态
-这是董事会应该记住的一个指标，如果他们忘记了其他东西**Tier 2：驾驶员指标（3-5个指标）**
预示你北极星的领先指标。
-用户获取率
留存率曲线（上个月有多少活跃用户本月仍然活跃？）
-功能采用率（使用关键功能的用户百分比）
-DAU/MAU比值
-管道覆盖范围
-为什么跟踪这些：在收入影响之前的早期预警

**第3层：健康度量（3-5个度量）**
团队和操作健康的信号。
-燃烧速率和跑道
-员工人数vs计划
-工程速度/运输速度
- NPS或客户满意度
-为什么要追踪这些：产能制约增长

**第4层：危险信号（2-3个阈值）**
如果这些指标超过阈值，就需要立即采取行动。
流失率在X%以上
- $Y以上的CAC
—保留率下降大于Z%
-为什么要跟踪这些：战略对话的触发器，而不仅仅是监控

**纪律规则：**1. **每个季度都是相同的参数。**建立4-6个季度的业绩记录。可以添加新参数，但不要放弃旧参数。
2. **每个度量标准一个上下文句子。**这个指标告诉我们什么？是好是坏？这意味着什么？
3. **现实vs计划，永远如此。**不要在未显示你的计划的情况下显示指标。delta是对话。
4. **需要时分解。**总使用量隐藏分段。按客户类型、细分市场、产品线进行细分——只要平均值掩盖了现实。
5. **使用健康指标。**Green/yellow/red状态用于快速板评估。让董事会扫描仪表板，放大黄色和红色。

* *常见的错误:* *

根据本季度表现良好的指标来改变你所展示的指标。董事会立即通知。这是让你的数字失去可信度的最快方式。每次都显示相同的仪表盘——当一个指标看起来很糟糕时，这就是对话。---

# # # 5。在董事会要求之前发布坏消息

* *的模式:* *

当坏消息被拖延或粉饰时，董事会的信心就会受到侵蚀。他们能处理坏消息。他们承受不了惊喜。他们讨厌缓慢的决策。

**前简要格式：**

在坏消息传到整个董事会之前，在会议前48-72小时向你的主管做个简报。

- **谁：**董事会主席或最有经验的董事
- **什么：**问题，你的评估，你的计划
- **原因：**董事可以帮助构建整个董事会，避免意外冲击，并且可能以前见过这种模式

然后给全体员工发一封简短的邮件：

“我想在下次见面前提醒你一些事情。(具体问题)。以下是我们目前所知道的，我们还不知道的，以及我们正在采取的措施。我们会在董事会上汇报最新情况。”

**坏消息框架：**

对于每一个坏消息，有四个要素：1. **发生了什么**（具体的，一句话-不是防御）
-“我们没有完成第一季度新增10个企业客户的目标；实现7”

2. **为什么会发生**（根本原因，不是借口）
-“由于我们没有及早诊断出产品差距，客户评估时间表出现了下滑”
承认吧：“我们误读了需求信号”，而不是“市场转移了”。

3. **影响是什么**（诚实对待严重程度）
“影响第一季度ARR约5万美元，使我们低于最初的指导”

4. **我们正在做什么**（具体行动，所有者，时间表）
-“改变销售动议，使产品提前准备就绪；将第二季度目标修改为15个（包括第一季度积压的7个）”

**如何避免与小姐沟通：**
“我们没有达到第一季度的目标，但管道很强大”
“外部因素减缓了交易，但我们对第二季度充满信心”
“我们在执行过程中遇到了一些挑战，但现在已经解决了”所有的模糊。所有的防守。没有人解释根本原因或计划。

* *跟进模式:* *

随后的每次董事会更新都应参考之前提出的问题：“上个季度我提出了（问题）。这里是最新消息：[进展]。状态：[已解决/正在进行/正在升级]。”

这样可以建立一个坚持到底的记录。董事会记得谁跟踪自己的问题。

* *常见的错误:* *

把坏消息夹在好消息中间，希望没人注意到。董事会成员立即看到了这一点。它比坏消息本身更能损害信任。

# # # 6。每月投资者更新

* *的模式:* *

大多数创始人最多每季度向投资者发送一次最新信息。最好的创始人每月都发邮件——即使情况很糟糕。尤其是在事情不好的时候。* *为什么每月:* *
-无需安排电话会议就能让投资者保持参与
-当你需要帮助（介绍、建议、沟通）时，投资者已经有了背景
-一致性表示业务纪律；不规律的更新预示着混乱

* *格式:* *

**主题：**[公司名称]-[月]更新

**开头（1段）：**
一个标题。短暂的上下文。

* * TL;DR（3发子弹）：**
-一个数字（现在最重要的指标）
-一次胜利（具体-客户名称，交易规模，里程碑）
-一个挑战（你正在做的）

**关键指标（每月同表）：**

|指标|本月|上月| 3月平均| vs计划||--------|-----------|------------|----------|---------|
| arr | | | | |
| MRR增长| | | | |
|燃烧率| | | | |
|跑道（月）| | | | |
|管道| | | | |
|客户| | | | |

不要包含上次更新后没有改变的指标——专注于新内容。

**关键更新（2-3个子弹）：**
-主要招聘，产品发布，partnership/customer获胜
-战略支点或航向修正
-具体到足够重要

**要求（1-2个子弹）：**
-你需要什么帮助？介绍，招聘线索，战略建议
具体一点：“寻找[公司类型]的副工程师介绍”而不是“寻找工程人才”

**节奏规则：**
-每月同一天。第一个星期一，最后一个星期五——选一个，永远不要错过
-在一周内发送重大新闻（不要将其保留到下一个计划更新）
-在活跃融资期间：每周更新，以温暖投资者，每月到现有

* *常见的错误:* *只有在一切顺利的时候才会更新。6个月的利好消息过后，投资者就会明白你没有告诉他们什么。

# # # 7。《燃烧是关于纪律》；收益与牵引力有关

* *的模式:* *

向董事会传达财务信息有两个不同的层面。不要把它们混为一谈。

* *燃烧交流:* *
-月增长率，月增长率，年增长率
-效率提升（你削减了什么，优化了什么？）
-资本计划：哪些是有保障的，哪些是有目标的，时间表是什么

烧钱的故事是：“我们是纪律严明的经营者，能让资本走得更远。”

* *收入交流:* *
- MoM增长率，CAC， LTV，投资回收期
-客户细分（自助服务vs企业，是什么组合？）
-盈利计划与时间表

关于营收的故事是：“我们有吸引力，也知道如何扩大吸引力。”* *调和两种:* *
最好的财务沟通方式是：“我们消耗更少，增长更快。”这是经营杠杆的证据，也是董事会能听到的最令人信服的事情。

* *常见的错误:* *

把燃烧和增长混为一谈。当烧钱率攀升时，听到“我们正在快速增长”的董事会认为你在购买增长。当增长停滞时，董事会听到“我们削减了40%的开支”，就会认为你处于生存模式。分别讲述两个故事，然后把它们联系起来。

# # # 8。从董事会到组织的级联策略

* *的模式:* *

如果团队不知情，在董事会会议室里制定的战略就毫无意义。创建一个系统的沟通级联。

**四级：**

**第一级：执行团队（每周）**
——战略重点和新风险
-需要调整的关键决策**第二级：扩展领导力（两周一次）**
-策略如何影响每个功能
-关键优先事项以及如何衡量成功

**三级：全员（每月，60分钟）**
-领导力更新（15分钟）：我们在哪里，发生了什么变化
-胜利庆祝（10分钟）：客户，产品发布，人员
-深潜（20分钟）：一个详细的战略行动
-问答（15分钟）：真正的问题，真正的答案

**第4级：团队特定（持续）**
-团队目标如何与公司战略相联系
-这支球队的成功是什么样子的

测试:* * * *

随便找一个员工。他们能解释公司的战略吗？如果没有，级联就被破坏了。只存在于高管头脑中的战略不是战略——它是秘密。

**连接okr到级联：**
-公司战略okr
-职能okr与公司保持一致
-团队okr与职能保持一致
-个人了解他们如何做出贡献* *常见的错误:* *

不一致的信息。如果不同的领导者对公司的发展方向讲述了不同的故事，那么组织就会针对相互冲突的目标进行优化。把策略写下来。一页。让每个人都使用相同的单词。

---

决策树

董事会会议vs投资者更新```
Is this a full board meeting?
├─ Yes → Full structure: pre-read + Three Things + decisions + deep dive
└─ No → Continue...
    │
    Is this a major event (fundraise close, big miss, key hire)?
    ├─ Yes → Ad-hoc update immediately (don't wait for schedule)
    └─ No → Monthly investor update format
```
如何构建度量标准```
Did you hit the target?
├─ Yes → State it, move on. Don't over-celebrate.
└─ No → Continue...
    │
    Do you understand why?
    ├─ Yes → Root cause + plan + revised timeline
    └─ No → Say "we're diagnosing" + what you're doing to find out
        │
        Is the miss material (affects runway, strategy, or board confidence)?
        ├─ Yes → Pre-brief lead director before board meeting
        └─ No → Include in Three Things narrative, "what's not working"
```
---

常见错误

* * 1。董事会会议作为状态报告**
董事会成员可以阅读。发送预读。将会议用于决策和讨论，而不是数据演练。

* * 2。每季度更改参数**
指标的一致性可以建立信任。当你把一个看起来不好的指标换成一个看起来不错的指标时，你就告诉董事会你的数据不可信。

* * 3。没有明确的问**
每次投资者更新，每次董事会会议都应该提出一个问题。介绍、建议、认可、耐心。投资者想要帮忙——如果你从不开口，他们就会不参与。

* * 4。捍卫而不是描述**
当你用10分钟的时间为失误辩解时，董事会听到的是辩护。说出思念，说出原因，说出计划。继续前进。

* * 5。战略要留在董事会会议室**
如果你的团队无法解释你的战略，那就说明你还没有进行沟通。要么级联，要么就不存在。* * 6。董事会上的意外事件**
坏消息永远不应该第一次出现在董事会上。预先向主管汇报情况。发送标志邮件。让董事会在开会前讨论一下。

##快速参考

**董事会会议流程：**
预读（前48-72小时）→提问（15分钟）→三件事叙事（15分钟）→决策题（30-45分钟）→深度探究（20-30分钟）→闭门（10分钟）

**三件事模型：**
什么是有效的+什么是无效的+我们正在做什么

* *指标层次结构:* *
北极星(1)→司机（3-5）→健康（3-5）→红旗（2-3个阈值）

坏消息协议：**
预先向首席董事汇报（48-72小时）→向全体董事发出电子邮件→发生了什么→为什么→影响→计划→后续每次会议跟进
