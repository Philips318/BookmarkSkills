##状态值

###总体状态

|状态|含义|可视化||--------|---------|--------|
| **通过** |所有检查成功，可以安全部署|✅|
| **有警告通过** |检查成功，但审查警告|⚠️|
| **失败** |检查失败|❌|

###个人检查状态

|状态|含义||--------|---------|
|✅Pass |检查成功完成|
|❌失败|检查发现错误|
|⚠️警告|检查通过，警告|
|⏭️跳过|跳过检查（工具不可用等）|

##格式指南

1. **使用一致的表情符号**进行视觉扫描
2. **引用二头肌错误时包括行号**
3. **针对每个问题提供可操作的补救**
4. **链接到文档**（如果可用）
5. **按严重程度排序**（错误优先，然后是警告）
6. **在“下一步”中包含命令示例**
