#📋自定义说明

针对特定技术和编码实践增强GitHub Copilot行为的团队和项目特定指示。
###如何贡献

请参阅[CONTRIBUTING.md]（../CONTRIBUTING.md# addinginstructions）获取有关如何贡献新指令、改进现有指令和共享用例的指南。

如何使用自定义说明

安装:* * * *
-点击**VS Code**或**VS CodeInsiders**安装按钮，以获取您想要使用的指令
-下载`*.instructions.md`文件并手动将其添加到项目的指令集合中Use/Apply* *: * *
-将这些说明复制到工作空间中的`.github/copilot-instructions.md`文件中
-在工作空间的`.github/instructions/`文件夹中创建特定于任务的`*.instructions.md`文件（例如，`.github/instructions/my-csharp-rules.instructions.md`）
-指令自动适用于副驾驶行为一旦安装在您的工作空间
