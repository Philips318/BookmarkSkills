#🎯座席技能

Agent Skills是包含指令和捆绑资源的独立文件夹，可增强AI执行特定任务的能力。基于[Agent Skills specification](https://agentskills.io/specification)，每个技能包含一个`SKILL.md`文件，其中包含代理按需加载的详细说明。

技能与其他原语的不同之处在于，它支持代理在执行特定任务时可以使用的捆绑资产（脚本、代码示例、参考数据）。
###如何贡献

请参阅[CONTRIBUTING.md]（../CONTRIBUTING.md# addingskills）了解有关如何贡献新的代理技能、改进现有技能和共享用例的指导方针。

如何使用座席技能

* *包括:* *
—每个技能是一个文件夹，包含一个`SKILL.md`指令文件
技能可能包括帮助脚本、代码模板或参考数据
—技能遵循座席技能规范，实现最大兼容性**何时使用：**
-技能是复杂的、可重复的工作流程的理想选择，可以从捆绑的资源中受益
-在需要代码模板、辅助工具或参考数据时使用技能
-技能提供渐进式披露-仅在需要特定任务时加载

* *用法:* *
-浏览下面的技能表，找到相关的能力
-使用GitHub CLI安装技能：`gh skills install github/awesome-copilot <skill-name>`（需要[GitHub CLI v2.90.0+](https://github.blog/changelog/2026-04-16-manage-agent-skills-with-github-cli/)）
—或者手动复制技能文件夹到本地的技能目录
—在提示中引用技能或让座席自动发现技能
