#🤖自定义代理GitHub Copilot的自定义代理，使用户和组织可以通过简单的基于文件的配置轻松地“专门化”他们的Copilot编码代理（CCA）。
###如何贡献

请参阅[CONTRIBUTING.md]（../CONTRIBUTING.md# add-agents）了解有关如何贡献新代理、改进现有代理和共享用例的指导方针。

如何使用自定义代理

安装:* * * *
-点击**VS Code**或**VS CodeInsiders**安装按钮为您想要使用的代理
-下载`*.agent.md`文件并将其添加到存储库中

**MCP服务器安装：**
—每个代理可能需要一个或多个MCP服务器才能运行
-单击MCP服务器在GitHub MCP注册表中查看
—按照指南将MCP服务器添加到存储库中Activate/Use* *: * *
-通过VS CodeChat界面访问已安装的代理，在CCA中分配它们，或通过Copilot CLI（即将推出）
—代理可以访问配置的MCP服务器上的工具
-遵循特定于代理的说明以获得最佳使用
