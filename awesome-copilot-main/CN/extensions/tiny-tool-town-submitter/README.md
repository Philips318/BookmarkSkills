# Tiny Tool Town提交者

检查当前的Git存储库，检查Tiny Tool Town所需的每个字段，并从Copilot画布提交完整的清单问题。

画布还检查公共存储库准备情况，检测缺失的README指南、许可证和展示图像，并可以请求专用的Copilot项目会话来实现选定的建议。

# #行动

- **重新扫描存储库**刷新检测到的元数据和准备结果。
- **生成选项**使用Copilot SDK起草简短，平衡和详细的清单描述，可以在应用前进行审查。
- **开始改进会议**将选定的发现交给新的本地项目会议。
- **提交到Tiny Tool Town**检查所需的确认，搜索现有的提交，并通过GitHub CLI创建公共问题。必须安装GitHub CLI并对其进行身份验证，以验证存储库可见性或提交问题。
