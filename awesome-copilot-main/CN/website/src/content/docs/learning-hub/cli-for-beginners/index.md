#GitHub CopilotCLI初学者

b> **✨学习与人工智能驱动的命令行辅助增压您的开发工作流程GitHub CopilotCLI将AI辅助直接带到您的终端。不需要切换到浏览器或代码编辑器，您可以在不离开命令行的情况下提问、生成功能齐全的应用程序、审查代码、生成测试和调试问题。

可以把它想象成有一个知识渊博的同事24/7，他可以阅读您的代码，解释令人困惑的模式，并帮助您更快地工作！

本课程主要针对以下人群：

- **软件开发人员**谁想要使用AI从命令行
- **终端用户**谁更喜欢键盘驱动的工作流程，而不是IDE集成

##🎯你会学到什么

这个实践课程带您从零到生产与GitHub CopilotCLI。您将在所有章节中使用单个Python藏书应用程序，并使用ai辅助工作流逐步改进它。到最后，您将自信地使用AI来审查代码，生成测试，调试问题和自动化工作流：所有这些都来自您的终端。

**不需要AI经验。**如果你能使用终端，你可以学习这个。

**适用于：**开发人员，学生和任何有软件开发经验的人。

##✅前提条件

在开始之前，确保你有：

- **GitHub帐户**:[创建一个免费](https://github.com/signup)<br>**GitHub Copilot访问**:[免费提供](https://github.com/features/copilot/plans)，[每月订阅](https://github.com/features/copilot/plans)，或[免费为students/teachers](https://education.github.com/pack)<br>- **终端基础知识**：熟悉`cd`，`ls`，运行命令
