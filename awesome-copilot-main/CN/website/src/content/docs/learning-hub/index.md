##开始

对GitHub Copilot不熟悉？从这里开始了解您可用的工具。

**桌面应用程序**：探索[GitHub Copilot应用程序](github-copilot-app/) -一个并行指挥多个代理的控制中心。非常适合代理原生开发和独立工作树的并行工作。

**自动化**：从[在GitHub Copilotapp中使用自动化]（Using -automation -in-copilot-app/）开始获取模板、设置指南和实际示例。

**画布**：学习[与画布扩展工作]（Working -with- Canvas - Extensions /）创建和进化交互式画布与`/create-canvas`。

**终端**：寻找从终端到GitHub Copilot的引导路径？探索[Copilot CLI for Beginners]（CLI for Beginners /）与基于文本的体验或[YouTube视频系列]（https://www.youtube.com/watch?v=BDxRhhs36ns&list=PL0lo9MOBetEHvO-spzKBAITkkTqv4RvNl）。
