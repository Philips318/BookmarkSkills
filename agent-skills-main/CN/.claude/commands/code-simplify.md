description: 为清晰度和可维护性简化代码 — 在不改变行为的前提下降低复杂度
---

调用 agent-skills:code-simplification 技能。

在保持行为完全一致的前提下，简化最近更改的代码（或指定范围）：

1. 阅读 CLAUDE.md 并研究项目约定
2. 确定目标代码 — 除非指定了更大范围，否则使用最近更改
3. 在触碰代码之前，理解代码目的、调用方、边界情况和测试覆盖
4. 扫描简化机会：
   - 深层嵌套 → guard clauses 或提取 helper
   - 长函数 → 按职责拆分
   - 嵌套三元表达式 → if/else 或 switch
   - 泛泛的名称 → 描述性名称
   - 重复逻辑 → 共享函数
   - 死代码 → 确认后移除
5. 增量应用每个简化 — 每次更改后运行测试
6. 验证所有测试通过、构建成功，并且 diff 干净

如果简化后测试失败，回滚该更改并重新考虑。使用 `code-review-and-quality` 审查结果。
