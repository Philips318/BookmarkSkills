description: 将工作拆解为带验收标准和依赖顺序的小型可验证任务
---

调用 agent-skills:planning-and-task-breakdown 技能。

阅读现有 spec（SPEC.md 或等效文件）以及相关代码库部分。然后：

1. 进入计划模式 — 只读，不更改代码
2. 识别组件之间的依赖图
3. 垂直切分工作（每个任务是一条完整路径，而不是水平分层）
4. 编写带验收标准和验证步骤的任务
5. 在阶段之间添加检查点
6. 展示计划供人工审查

将计划保存到 tasks/plan.md，将任务列表保存到 tasks/todo.md。
