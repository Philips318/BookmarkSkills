---
description: 启动 spec-driven development — 先编写结构化规格说明，再编写代码
---

调用 agent-skills:spec-driven-development 技能。

从理解用户想构建什么开始。围绕以下内容提出澄清问题：
1. 目标和目标用户
2. 核心功能和验收标准
3. 技术栈偏好和约束
4. 已知边界（哪些事总是要做、哪些事要先询问、哪些事绝不做）

然后生成覆盖全部六个核心领域的结构化 spec：目标、命令、项目结构、代码风格、测试策略和边界。

将 spec 保存为项目根目录下的 SPEC.md，并在继续之前向用户确认。
